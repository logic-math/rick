# skill:sense_reversal（阶段 4 · 辩证逆转——思考门禁 skill）

> human-loop v8：本文件是 SENSE 五阶段思考门禁 loop 的阶段 4 skill（main agent 会话内执行）。
> 双重目标：① 启发用户深入思考本阶段内容 ② 验证用户的思考是否足以通过本阶段思考门禁。
> SENSE canon（五步权威文本）：`{{sense_skill_path}}`。

## 本阶段思考目标（辩证逆转）

当主要矛盾确认后（两方面 X 和 Y：X 是阻碍而 Y 是期望状态），引导思考：**当 X 是 Y 必然成立的前提时，应当如何做才能实现 Y？**

- 将阻碍变成达成目标的手段——这就是辩证逆转；
- 给出**多个可行的解决方案**供用户自己选择判断；
- 不替用户收敛到单一方案。

```text
subagent({ workflowScript: "return runs.run('orig-stage4', { agent: 'orig', task: '阶段：辩证逆转（阶段 4）。用户当前思考进度：<用户确认的主要矛盾 X/Y 原话摘要>。缺口：<门禁未过时一句话指出，首启略>。给用户返回怎样的内容才能引导他完成本阶段的思考目标？调研素材落盘 <orig_dir>/stage4_{seq}.md（write 首块 + bash 分批追加）' })", timeoutMs: 3600000 })
```

## 启发呈现纪律

- orig 返回的启发内容经教学润色 skill 润色后呈现（每个概念科普讲清楚，见 teacher_polish skill）：所选领域中「把阻碍变手段」的先例与机制（带来源）——**不是答案**。
- 不替用户设计方案；呈现完概念后按 teacher_polish 的收尾引导，引导用户串联概念、用自己的话表达思想（表达将接受门禁判定），用户的方案是本阶段产出。

## 门禁标准（main agent 判定）

用户通过本阶段思考门禁，当且仅当其回答中：

**符合逻辑地回答**：当阻碍 X 是目标 Y 达成的必要条件时，那么应当如何？——用户给出的方案把 X 从阻碍转变为 Y 的前提/手段（不是绕开 X 或削减 Y），且推理链自洽（从前提到方案无逻辑断点）。

## 未过门禁行为

- 一句话指出缺口（如「你的方案绕开了 X——如果 X 必须存在，方案变成什么？」）。
- 按缺口重调 orig 针对性再启发；无重试上限。
- **推进权在用户**：用户说「推进」即进入阶段 5（良质批判），不阻拦。
