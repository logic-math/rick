# skill:sense（系统化思维框架）

在对问题、需求或困境采取行动之前,需要深度分析时使用。SENSE 是五个阶段的首字母缩写,5 阶段允许反向回流,每阶段嵌入批判门禁。

---

## S — 问题确认（Subject）：还原、追问

### 1. 还原
将原始问题还原为三要素形式:
> 现状是___,期望是___,差距是___

### 2. 追问
对三要素持续追问(research 调研现状 + 对 human 假设追问):
- 事实追问:"真实情况是什么?" → 读代码、跑测试、看日志(物)
- 价值追问:"真正想要的是什么?" → 确认需求、确认验收启发方法(人)
- 现场追问:"在实际运行环境下会发生什么?" → 复现问题(场)

### 3. 通过条件
三个追问全部通过批判门禁(think 嵌入)。

**关键原则**:依靠问题品味判断何时停止追问。没有调查就没有发言权,调查就是解决问题。

---

## E — 视角生成（pErspective）：跨领域、原创、确认

**哲学基础**:原创性思考 = 跨领域学习 = 形成偏见。AI/human 思维是对现有信息以不同模式处理,产生偏见性信息。视角形成 = 偏见形成 = 原创。

### 1. 跨领域调研
research subagent 大量调研跨领域理论,引用相关理论,产出多视角候选。

### 2. 候选视角
每个视角含:来源理论 + 事实支撑 + 融贯性(自洽/他洽/续洽)。think subagent 对每个候选执行 4 维打分+top-N。

### 3. human 给出原创视角
human 综合多候选后给出**原创视角**(可能来自候选,也可能是综合后的新视角)。不替 human 选择视角。

**关键原则**:好视角的标准是简单且有效。融贯性如同自然选择,淘汰无法正确预测未来的解释。

---

## N — 矛盾判断（judgmeNt）：N1 矛盾生成、N2 主要矛盾判断

### N1:矛盾生成(系统论描述符)

基于选定视角,用**简化版系统论描述符**描述系统:

| 要素 | 含义 |
|---|---|
| node | 系统组件 |
| input | 系统输入(符号,代表物质/信息/能量) |
| output | 系统输出(同上) |
| inner | 系统内部协作的 input/output |
| edge | node 之间的协作关系,承载 inner_input/inner_output |

分析系统稳态:当前 A → 目标 B 所需控制手段。列举多种相互矛盾的状态供 human 选择。

**系统图必须用 ASCII 文本绘图表达**(不可纯文字列表),格式示例:

```
[系统名 / node_根]
├── input: [系统输入符号]
├── output: [系统输出符号]
├── edge: → [node_A] (协作关系)
│   └── inner_input: [内部输入]
│   └── inner_output: [内部输出]
└── edge: → [node_B] (协作关系)
```

### N2:主要矛盾判断

对每个矛盾状态三维打分(每个 1.0/0.5):
- **根本性**:1.0 触及根本问题 / 0.5 边缘问题
- **全局性**:1.0 影响全局 / 0.5 影响局部
- **决定性**:1.0 系统从 A→B 必经 / 0.5 仅影响部分

think 输出 top-N 矛盾,human 选定主要矛盾(系统从 A 变 B 时表现目标特性的矛盾)。

**关键原则**:主要矛盾具有全局性、根本性、决定性,是系统演化的最大势能差。

---

## S-R — 辩证逆转（reverSe）：阻碍、逆转、路径

> N2 无主要矛盾则必须触发(硬约束,非可选)

### 1. 阻碍
基于系统论描述符的 node/edge,识别矛盾不可调和的根源。

### 2. 逆转
核心追问:**"如果 X 是必然发生的前提,要想实现 Y,我们应当如何?"**

这个问题的回答本身就蕴含对主要矛盾的控制手段。research subagent 对逆转逻辑做尽调,为 human 给出可选项。

### 3. 路径
human 学习后给出判断,在新的系统层次上,通过控制新发现的可控变量,约束系统向期望可能性空间演化。

**关键原则**:辩证逆转的本质是跳出原有系统层次,在更高维度看到矛盾对立统一的可能性。

---

## E — 良知批判（critiquE）：回顾、自判、跃迁

> 必须由 human 自己判断,不替 human 提议跃迁方向

### 1. 回顾
sense_loop 呈现全过程回顾(S/E/N/S-R 各阶段核心判断原话)。**无 subagent 派发**。

### 2. 自判
human 自问:当前思考是否足以形成结论?这是 human 对良质的感觉。

### 3. 跃迁
human 给出跃迁方向:
- **降维**:打开黑箱,深入子系统(还原论)
- **升维**:重新界定真问题,更高层次(整体论)
- **维持**:当前层次足够

升维/降维 → 触发反向回流,回到 S 或 E 阶段。

**关键原则**:批判是打破卡壳状态的工具。人不可能获得所有信息,从黑箱到白箱需逐步通过增强认知来强化对系统的控制能力。

---

## 使用模式

```
S（问题确认）:现状是___,期望是___,差距是___
E（视角生成）:跨领域调研 → 视角候选 → human 给出原创视角___
N1（矛盾生成）:系统描述符 node/input/output/inner/edge → 矛盾状态___
N2（主要矛盾判断）:三维打分(根本性/全局性/决定性) → 主要矛盾___
S-R（辩证逆转,若 N2 无主要矛盾则必须）:若 X 必然,实现 Y 应当___
E（良知批判）:human 自判 → 降维/升维/维持
```
