# skill:research（事实调研树遍历方法论）

当需要尽调事实、澄清事实模糊性到极限时使用。research 是 SENSE 方法论中 S1（还原）、E1（概念地图）、E2（视角选择）、N（判断）、S-R（逆转）的事实调研工具化体现。

---

## 触发场景

- sense_loop 派发 S1/E1/E2/N/S-R 步骤的事实调研部分时
- 任何需要"澄清事实模糊性"的调研场景
- think 选出最高风险假设后，若为事实性，由 research 调研

---

## 调研策略：BFS + 全量收集

```
QUEUE: 初始为任务派发中识别的所有事实性假设

LOOP:
  1. 出队：从 QUEUE 取一个事实性假设 [假设X]
  2. 调研：用工具（Read/Grep/WebSearch）搜集证据
     ✅ 澄清 → 更新已知信息，识别新涌现的事实性假设加入 QUEUE
     ❌ 无法调研 → 标注为"事实性假设"，加入上报列表（R7）
  3. 退出：QUEUE 为空 → 归零达成
```

**信任 BFS 自然收敛**：不加轮次上限。当无新事实性假设涌现时，QUEUE 自然变空。

---

## R7 规则（无法被调研的事实）

无法被调研的事实属事实性假设，按以下两步处理：

1. research 标注为事实性假设，加入上报列表
2. sense_loop 呈现给 human，由 human 决策（不替 human 判断）

**典型场景**：
- 内部系统黑箱（无文档、无日志访问权限）
- 未来事件（无法预测）
- 他人意图（无法直接观察）
- 历史决策（无记录）

---

## 工具使用

| 工具 | 用途 |
|------|------|
| Read | 读文件、代码、文档 |
| Grep | 在代码/文件中搜索模式 |
| WebSearch | 搜索公开信息 |
| WebFetch | 抓取具体 URL |

---

## 关键原则

- 调查就是解决问题，没有调查就没有发言权
- 不替 human 决策 R7 上报项
- 不替 think 评估价值性假设
- 事实陈述必须带来源
- 简报不含倾向性

---

## 与其他 subagent 的协作

- **think**：think 选出最高风险假设后，若为事实性，research 接手调研
- **sense_loop**：research 输出事实简报，由 sense_loop 呈现 human 决策
- **exporter**：research 不直接交互 exporter，简报存入 briefs/ 供 exporter 读取

---

## 使用模式

```
[初始] 任务派发 → 识别所有事实性假设 → 加入 QUEUE
[LOOP] 出队 → 调研 → 澄清/失败 → 更新 QUEUE
[退出] QUEUE 空 → 输出简报（含 R7 上报项）
```
