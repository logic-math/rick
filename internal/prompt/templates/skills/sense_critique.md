# skill:sense_critique（阶段 5 · 良质批判——思考门禁 skill）

> human-loop v8：本文件是 SENSE 五阶段思考门禁 loop 的阶段 5 skill（main agent 会话内执行）。
> 双重目标：① 启发用户深入思考本阶段内容 ② 验证用户的思考是否足以通过本阶段思考门禁。
> SENSE canon（五步权威文本）：`{{sense_skill_path}}`。

## 本阶段思考目标（良质批判）

反思整个思考过程（阶段 1-4 的全部产出），检验：

- 使思考有效的各种**假设**在当前的具体问题上，是否足够**置信**？
- 能否由整个思考过程**必然得出目标可达成的结论**？如果不能，差在哪？
- 如果可以，是否有**被忽略的关键假设**？


## 启发呈现纪律

- orig 返回的启发内容经教学润色 skill 润色后呈现（每个概念科普讲清楚，见 teacher_polish skill）：所选领域的假设检验/置信度实践（带来源）——**不是答案**。
- 不替用户批判；呈现后自然问用户一个开放问题（如「把你的方案倒过来推——哪一步最先塌？」），用户的批判是本阶段产出。

## 门禁标准（main agent 判定）

用户通过本阶段思考门禁，当且仅当其回答中：

1. **回顾思考过程所依赖的假设是否可证伪**：思考过程中起作用的假设被列出，且每个假设能回答「什么情况出现则它被证伪」；
2. **推导过程的逻辑性**：由前四阶段结论到目标达成的推理链被走一遍，断点（如有）被显式说出。

## 未过门禁行为

- 一句话指出缺口（如「你的推理从矛盾到方案跳过了一步——中间靠什么成立？」）。
- 按缺口重调 orig 针对性再启发；无重试上限。
- **推进权在用户**：用户说「推进/完成」即走收口（简短回顾 + 会话结束），不阻拦。
