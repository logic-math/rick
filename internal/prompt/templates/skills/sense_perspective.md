# skill:sense_perspective（阶段 2 · 视角生产——思考门禁 skill）

> human-loop v8：本文件是 SENSE 五阶段思考门禁 loop 的阶段 2 skill（main agent 会话内执行）。
> 双重目标：① 启发用户深入思考本阶段内容 ② 验证用户的思考是否足以通过本阶段思考门禁。
> SENSE canon（五步权威文本）：`{{sense_skill_path}}`。

## 本阶段思考目标（视角生产）

从第一性原理出发讨论当前问题涉及及相关的知识领域，将这些知识领域作为解释问题现象的思考框架：

- **强相关**知识领域：为了能够高效地解决问题——收敛性思维；
- **弱相关**知识领域：为了探索创造性的解决方案——发散性思维；
- 强与弱分开列出，各自附理由（该领域解释问题的哪个面向）。

## orig 派发契约

```text
subagent({ workflowScript: "return runs.run('orig-stage2', { agent: 'orig', task: '阶段：视角生产（阶段 2）。用户当前思考进度：<用户的问题还原结论与已提框架原话摘要>。缺口：<门禁未过时一句话指出，首启略>。给用户返回怎样的内容才能引导他完成本阶段的思考目标？调研素材落盘 <orig_dir>/stage2_{seq}.md（write 首块 + bash 分批追加）' })", timeoutMs: 3600000 })
```

## 启发呈现纪律

- orig 返回的启发内容原样呈现：候选知识领域（带来源与解释面向）、张力、引导性问题——**不是答案**。
- 不替用户选框架；远域领域（弱相关）是原创性的主要来源——呈现时保留远域候选，不因「不常用」过滤。
- 呈现后留一个引导性问题（如「这些领域里，哪些你判断为强相关、哪些弱相关？为什么？」），用户的判断是本阶段产出。

## 门禁标准（main agent 判定）

用户通过本阶段思考门禁，当且仅当其回答中：

1. **明确描述选择这一视角所带来的应用价值**：选定视角（知识领域）后，能说出用它能解释/解决本问题的什么；
2. **能够描述其内在的因果运动**：用该视角的术语说出问题现象的因果链（什么导致什么）。

## 未过门禁行为

- 一句话指出缺口（如「你选的两个领域都是强相关的——哪个领域可能给出完全不同的解法？」）。
- 按缺口重调 orig 针对性再启发；无重试上限。
- **推进权在用户**：用户说「推进」即进入阶段 3（判断矛盾），不阻拦。
