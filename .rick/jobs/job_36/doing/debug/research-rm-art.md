# research-rm-art 简报（Rick and Morty 原画风调研 → rick web 星空重绘）

阶段：job_36 星空背景重绘 · 主题：R&M 原画风调色板/形态/动态规范 · 调研方式：代码通读 + 4 轮联网交叉验证（无外包叶子）

## 一、调色板

1. **深空背景不是「紫底」，是深蓝近黑**。剧内太空背景为藏青→近黑（可 #0b1226 → #04060c 渐变），紫色只作为星云/星球的点缀出现。来源：剧集截图观察 + 社区风格分析（anifusion.ai/style/rick-and-morty-style；raregallery.art R&M 太空壁纸）。
2. **传送门绿 = 黄相青柠绿（lime），非纯荧光绿**。社区/调色板标注的 portal green 为 `#97CE4C`（tvthemes rickAndMorty 调色板 "Green"，被广泛引用）；剧内实际视觉更亮、带明显黄相，建议区间 `#97ce4c ~ #c7e94e`。当前实现用的 `#39ff88` 偏「纯荧光绿」、缺黄相，是主要偏差。来源：https://emilhvitfeldt.github.io/r-color-palettes/discrete/tvthemes/rickAndMorty/ 、colorswall.com/palette/82394（#1D9612 深绿变体）。
3. **角色代表色**（剧内 + 专门设计站交叉验证）：Rick 发 = 淡蓝/灰蓝 `#9FE6E8`（toon-tone.app）或淡蓝 `#BEE5FD`（tvthemes），白大褂 `#F4F6F9`，内搭青绿 `#01B4C6`；Morty T 恤黄 `#FFF86D`（toon-tone）/ `#FFF874`（tvthemes），头发深棕 `#44281D`，牛仔裤深蓝 `#3A4767`，皮肤 `#F8D3AC`；Summer 粉 `#F675DA` / 红 `#E64358`。
4. **星云/宇宙场景色彩倾向：两类**——「粉紫橙」系与「青绿/钴蓝」系（swirling teal & cobalt nebulae），非单一紫色。来源：artwisher.com R&M cosmic nebula 海报、anifusion 风格页。
5. tvthemes 全套 9 色（社区共识色板）：`#01B4C6` 青 / `#97CE4C` 绿 / `#FFF874` 黄 / `#BEE5FD` 淡蓝 / `#F675DA` 粉 / `#44281D` 深棕 / `#3A4767` 深蓝 / `#F8D3AC` 肤色 / `#E64358` 红。来源同上。

## 二、传送门形态

6. **传送门 = 旋转的绿色漩涡盘面（vortex disc），不是简单圆环/球体**。官方/社区一致描述：多层螺旋臂（galaxy 式正面视角）、流体「果冻（jelly）」质感、不透明、外缘锯齿状能量喷射、中心高亮；枪口喷出时呈绿色液环展开成涡旋。来源：rickandmorty.fandom.com/wiki/Portal_Technology、Portal_Gun；cinecom.net AE 教程（椭圆遮罩 + Twirl 扭曲 + Fractal Noise 模拟涡旋）。
7. **绘图要点**：3-5 条阿基米德螺旋臂自中心向外收拢/展开，颜色从中心亮黄绿→主绿→外缘深绿渐变；外缘加 12-20 个锯齿/能量粒子；中心白色亮点 + 1-2 段弧形高光扫过；整体外圈辉光。漩涡方向剧内不严格统一（社区多画逆时针向心）。

## 三、宇宙飞船形态

8. **飞船 = 银色金属圆盘 + 透明玻璃穹顶驾驶舱 + 灰色内部**，穹顶可拆卸；悬停时底部有光束（剧内多暖黄/白，场景而异）。来源：rickandmorty.fandom.com/wiki/Space_Cruiser、looper.com 道具组访谈。
9. **当前 Saucer.tsx 用紫色碟身 `#5d3fd3` 是明显偏差**——剧内飞船是银灰金属，不是紫色。应改银灰渐变（如 `#c8cdd4 → #8d949e`）+ 淡蓝透明感穹顶 + 底部暖黄光束 + 红/绿/黄三色航灯。
10. **角色极简剪影**：Rick = 白大褂（圆角梯形/矩形）+ 淡蓝蓬发（头顶小云朵状）+ 胡子小凸起；Morty = 黄 T 恤（圆角矩形）+ 深棕短发小簇 + 深蓝裤。注意任务清单中「Morty 黄发」是错的——Morty 是深棕发 + 黄 T 恤。

## 四、星球形态

11. **R&M 行星是扁平 cel-shade 风格**：实心圆 + 单一光源（左上）的明/暗两段硬边界（非复杂多级渐变），少量细节（环形带/云带/陨坑），暗色星球常有大气辉光。来源：剧集截图观察 + anifusion 风格页（flat 2D look、readable exaggeration）。
12. **当前 Planet.tsx 深紫 `#5d3fd3` 5 段渐变是偏差**：剧内行星颜色多样（青/蓝绿/橙/浅紫都有），且明暗分界清晰、色块化。建议改两段式明暗 + 剧内行星常用色（如青 `#3aa6a0` 或浅紫 `#8b6ff0`），细环用暖金 `#e8c96a` 更贴剧内土星式环。

## 五、动态感

13. 传送门：流体涡旋持续旋转，螺旋臂 1-2s/圈（剧内），背景氛围用可放慢到 4-8s/圈 + 中心亮点脉动（~1.2s）；外缘粒子径向微颤。来源：剧集观察（无法精确量化，见 R7）。
14. 飞船：悬停微摆（2-3s 周期 ease-in-out）+ 底部光束脉动 + 航灯错相闪烁（~1.4s）。来源：剧集观察。
15. 星球：背景星球近乎静止或极缓自转（>30s/圈），靠纹理漂移体现。来源：剧集观察。

## R7 上报项

1. 传送门绿的「剧内屏幕确切 HEX」无官方标准：社区 #97CE4C 与剧内更亮荧光感的观感冲突——建议以 #97ce4c 为主、高光层提亮折中。
2. 涡旋旋转方向（顺/逆时针）与圈速无官方数据，仅社区观察。
3. 飞船底部光束颜色随场景变化（暖黄/白/绿皆有），无单一 canon 色。
4. 星球自转速度无官方参考（剧内背景行星基本静止）。
5. 星云配色无官方固定色板，剧集间变化大（粉紫橙 vs 青绿钴蓝两类）。

### 6.2 传送门绘制步骤（canvas 伪代码级）

```
drawPortalVortex(ctx, cx, cy, R, t, alpha):
  # 1) 外辉光：radial(cx,cy, R*0.2 → R*1.5)，rgba(151,206,76, 0.25*alpha) → 0
  # 2) 3-5 条阿基米德螺旋臂（核心视觉，替换现同心椭圆）
  for arm in 0..4:
    θ0 = arm * 2π/5 + t * 0.9            # 整体绕中心旋转（逆时针向心）
    path: for θ = 0 .. 3.2π step 0.1:
      r  = R * 0.1 * (θ / 3.2π) ** 0.85   # 螺旋由内向外展开
      x  = cx + cos(θ0 + θ) * r
      y  = cy + sin(θ0 + θ) * r * 0.9     # y 压扁 0.9 → 椭圆视角
    # stroke 渐变（沿臂）：内 #d4f5a8 → 中 #97ce4c → 外 #4c7a1f
    # lineWidth 内粗外细：R*0.05 → R*0.015；globalAlpha 0.75 → 0.4
  # 3) 外缘锯齿能量：沿 R*0.95 圆周撒 12-20 个粒子（#b8e94e），
  #    大小/相位随机，随 t 旋转 + 径向 ±0.06R 微颤
  # 4) 中心核心：radial 白绿 #f2ffd8 → #d4f5a8 → 透明，半径 R*0.18，
  #    叠加 sin(t*5) 脉动（幅度 ±15%）
  # 5) 高光扫过：1-2 段弧形 stroke #eaffc9（低透明 0.35），沿旋转角度偏移
```

### 6.3 飞船与角色剪影绘制要点

- 碟身：银灰渐变椭圆（#c8cdd4 上 → #8d949e 下），替换现紫色 #5d3fd3；底部加一条暖黄光束（#ffe9a8，alpha 0.15-0.2，随悬停脉动）。
- 穹顶：半透明淡蓝（#aee1f2，alpha 0.55）+ 左上白高光描边（透明玻璃感），替换现 #a6c8dd 实心。
- 航灯：碟沿 5 颗小灯，红 #ff5a5a / 绿 #7eff6a / 黄 #ffd54a 交错，错相闪烁（保持现 SVG animate 结构即可）。
- 舱内剪影（若加）：Rick = 白大褂圆角梯形 + 淡蓝蓬发云朵 + 下巴胡子小凸；Morty = 黄 T 圆角矩形 + 深棕短发小簇 + 深蓝裤，二人并排坐于穹顶内，深色描边（#1a1f2e）。

### 6.4 动画参数

| 元素 | 参数 | 值 |
|---|---|---|
| 传送门螺旋臂旋转 | ω | 0.9 rad/s（约 7s/圈，背景氛围） |
| 中心核心脉动 | 频率 | 1.2s / 周期 |
| 外缘粒子 | 径向微颤 | ±0.06R，周期 0.8-1.6s 随机 |
| 飞船悬停 | bob | 2.2s ease-in-out，±2.5% 位移 |
| 飞船光束 | 脉动 | 1.6s ease-in-out |
| 航灯 | 错相闪烁 | 1.4s 周期，stagger 0.14s |
| 星球自转 | ω | 0.02-0.08 rad/s（30-300s/圈，纹理漂移即可） |
| 星球环倾角 | 固定 | -0.32 rad |
| 帧率 | 上限 | 30fps（现状保留）；reduced-motion 全静态（现状保留） |

- `Portal.tsx`（SVG 小尺寸）：stroke 改 #97ce4c/#6fae2f；可保留同心圆（小尺寸够用）。
- `Saucer.tsx`：碟身改银灰，穹顶改透明蓝，光束改暖黄（现 #39ff88 绿光束改为 #ffe9a8）。
