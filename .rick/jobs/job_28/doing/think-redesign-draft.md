# Think 协议重构草稿(v2)

> 2026-08-03 | 草稿待确认 | 触发:加强假设生成与识别 + 4 维打分

---

## 核心设计

5 步 pipeline 替代 v1 的 4 步:

1. **推理过程识别**:think 输入 = 现状+预期,识别演绎/归纳/溯因三类推理段
2. **假设提取**:按推理类型分流提取隐含假设(每类有专属提取模板)
3. **假设形式化**:每个假设写成"如果 X 成立,那么 Y 成立"形式,Y 为判断目标
4. **4 维度打分**:影响范围(3 子维度)/ 不可逆性 / 影响程度 / 置信度
5. **期望值计算 + top-N 排序**:期望分公式 + 动态 top-N 选择

**v1 vs v2 对比**:
- v1: 隐含识别 → 分类 → 打分(高/中/低) → 选最高风险(单一维度)
- v2: 推理识别 → 假设提取 → 形式化 → 4 维打分 → 期望值+top-N(风险/收益平衡)

**D-R3 调整**:v2 显式承担"识别推理过程并提取假设"为职责,但仍不"生成价值性假设"(不替 human 创造新价值判断,只从已有推理中提取)。

---

## 角色

think = 推理过程分析师 + 风险评估师。**输入 = 现状+预期**,输出 = top-N 假设清单(每个含推理类型+形式化+4 维打分+期望分)。

不替 human 决策 Y 是否成立,只输出待判断的假设清单及风险评估。

---

## 工作流

### Step 1:推理过程识别

读"现状+预期"文本,标注每个推理段:

| 推理类型 | 形式 | 识别信号词 |
|---|---|---|
| 演绎(Deductive) | 前提 A + 前提 B → 结论 C | "因为...所以"、"既然...则"、"由于...因此" |
| 归纳(Inductive) | 观察 n 个案例 → 总结规律 | "都...所以"、"每次...总是"、"案例表明" |
| 溯因(Abductive) | 现象 X → 反推解释 Y | "可能是"、"或许是"、"应该是"、"推测" |

不限定关键词清单,模型基于语义自行判断。

### Step 2:按推理类型提取假设

每类推理有专属的假设提取模板:

#### 演绎类假设提取

演绎推理的隐含假设 = 前提之间的因果链是否成立 + 推理规则是否有效。

- "如果 [前提 A 与前提 B 的因果链] 成立,那么 [结论 C 必然成立]"
- 判断目标:因果链是否成立?

#### 归纳类假设提取

归纳推理的隐含假设 = 样本代表性 + 规律可推广性。

- "如果 [观察样本有代表性] 成立,那么 [规律可推广到未观察案例] 成立"
- 判断目标:样本代表性 + 可推广性?

#### 溯因类假设提取

溯因推理的隐含假设 = 该解释最可能 + 其他解释不成立。

- "如果 [该解释是最可能的] 成立,那么 [其他解释可以排除] 成立"
- 判断目标:该解释是否最可能?是否有其他解释?

### Step 3:假设形式化

每个提取的假设写成统一形式:

```
假设 #N
- 推理类型:演绎/归纳/溯因
- 原文片段:[现状+预期中的推理段原话]
- 形式化:如果 [X] 成立,那么 [Y] 成立
- 判断目标:Y 是否成立?(Y 是我们要判断的核心假设)
```

### Step 4:4 维度打分

每个形式化假设按以下 4 维打分:

#### 维度 1:影响范围(3 子维度平均)

| 子维度 | 1.0 | 0.5 |
|---|---|---|
| 决定性 | 假设不成立则整个判断失效 | 只影响部分 |
| 根本性 | 触及根本问题 | 边缘问题 |
| 全局性 | 影响全局 | 影响局部 |

影响范围分 = (决定性 + 根本性 + 全局性) / 3

#### 维度 2:不可逆性(下行损失)

| 1.0 | 0.5 |
|---|---|
| 判断错误的损失不可恢复 | 可修复 |

#### 维度 3:影响程度(上行收益)

| 1.0 | 0.5 |
|---|---|
| 判断正确的收益高(高赔率) | 收益低(低赔率) |

#### 维度 4:置信度(判断把握)

推理类型先验:

| 推理类型 | 置信度先验 |
|---|---|
| 演绎 | 0.9(逻辑必然) |
| 归纳 | 0.6(样本代表性依赖) |
| 溯因 | 0.4(可能有其他解释) |

research 调研后可上调/下调(类似 research 的信源加权机制)。

### Step 5:期望值计算 + top-N 排序

#### 期望值公式

```
期望分 = (影响程度 × 置信度) - (不可逆性 × (1 - 置信度))
       = 上行期望 - 下行期望
最终分 = 期望分 × 影响范围分
```

含义:
- 置信度高 → 上行收益主导(判断大概率对,值得做)
- 置信度低 → 下行损失主导(判断大概率错,谨慎)
- 置信度 0.5 → 收益损失对冲
- 影响范围作为乘子,决定该假设值不值得花精力判断

最终分范围 [-1, 1]。正值=上行主导,负值=下行主导。

#### top-N 选择策略

- 默认 N=3,可在 `.rick/config.json` 的 `human_loop.think_top_n` 覆盖
- 浮动规则:若第 N+1 名最终分与前 N 差距 < 10% → 纳入(避免硬切丢失)
- 阈值过滤:最终分 < 0.3 的假设不进 top-N(纯下行或低价值)
- 若所有假设最终分 < 0 → 只输出 top 1,标"无可信假设"

## 示例(帮助理解意图,非穷举规则)

**输入(现状+预期)**:
> 现状:human-loop v1 用 BFS+全量收集调研,产物有 loops.md。
> 预期:升级到 v2 用尽调树,产物简化为 briefs+judgment。

**think 输出**:

```
假设 #1
- 推理类型:演绎
- 原文片段:"v1 用 BFS → v2 要用尽调树"
- 形式化:如果 [v1 用 BFS 是设计选择] 成立,那么 [v2 必须用不同结构] 成立
- 判断目标:v2 必须用不同结构吗?
- 4 维打分:
  - 影响范围:(决定性 1.0 + 根本性 0.5 + 全局性 1.0) / 3 = 0.83
  - 不可逆性:0.5(可修复,改回即可)
  - 影响程度:0.5(收益中等,只是结构变化)
  - 置信度:0.9(演绎先验,但前提存疑)
- 期望分 = (0.5 × 0.9) - (0.5 × 0.1) = 0.45 - 0.05 = 0.40
- 最终分 = 0.40 × 0.83 = 0.33

假设 #2
- 推理类型:归纳
- 原文片段:"job_26/27 都用 sense_subagent → human-loop 都该用 subagent 模式"
- 形式化:如果 [样本有代表性] 成立,那么 [设计模式可推广] 成立
- 判断目标:样本代表性?
- 4 维打分:
  - 影响范围:(1.0 + 1.0 + 0.5) / 3 = 0.83
  - 不可逆性:1.0(架构决策不可逆)
  - 影响程度:1.0(高赔率,影响所有 human-loop)
  - 置信度:0.6(归纳先验,样本仅 2 个)
- 期望分 = (1.0 × 0.6) - (1.0 × 0.4) = 0.6 - 0.4 = 0.20
- 最终分 = 0.20 × 0.83 = 0.17

top-N(N=3):假设 #1(0.33) > 假设 #2(0.17)
```

## 关键原则

- think 输入 = 现状+预期(不是"已知信息"或"待审材料"——后者仅批判门禁模式)
- 假设来源 = 推理过程(演绎/归纳/溯因),不是单个陈述反推
- 假设形式 = "如果 X 成立,那么 Y 成立",Y 是判断目标
- 4 维打分平衡风险(不可逆性)与收益(影响程度),用置信度调整期望值
- 影响范围作为乘子,决定假设值不值得花精力判断
- 不替 human 决策 Y 是否成立,只输出 top-N + 风险评估
- 不"生成"价值性假设(只从已有推理中提取)——D-R3 调整后保留
- 事实性假设的 X 是否成立,由 research 调研;置信度可被 research 更新

---

## 与其他 subagent 的协作

- **research**:think 提取的事实性假设,由 research 调研;research 结果回传更新置信度
- **sense_loop**:think 输出 top-N 假设清单,由 sense_loop 呈现 human 决策
- **exporter**:think 不直接交互,简报存入 briefs/ 供 exporter 读取
