# skill:competitor-learning（竞品学习与原创转化）

## 触发场景
当需要系统学习竞品/同类工作（外部论文、内部同型系统、开源项目、设计文档），思考与自身系统的差异，产出**原创性想法**并转化为可落地的改进项时使用。典型信号：「调研一下这篇论文竞品」「看看有什么启发」「对比一下我们的优劣势」「找一个立得住的原创想法」。

## 预期效果
竞品学习不停留在「罗列竞品优点+抄作业清单」（跟随型学习），而是走完「**事实消解 → 差异分析 → 原创表达 → 落地转化**」全链：每条事实有信源等级，每个差异有方向标注（学他/守我/双修），每个原创想法有数学/实证检验，每个改进项有落地路径与验收判据。job_54 实测：三轮竞品学习（InfraRSI/AlphaTune/CompoundingKernel）+ 论文检索 35+ 篇 → 原创「分片流形理论 + adjust 协议 + 三柱数学框架」+ 三份可执行规格。

## 核心内容（四阶段纪律）

### 1. 事实消解（学）——多轮靶向 research，不做一次性泛读

- **多轮递进**（不是一轮全查）：①尽调轮（仓库/论文全貌+机制速查表）→ ②数字轮（论文级定量数据：消融/成本/对比臂数字）→ ③机制深挖轮（按原创方向的卡点定向补查）。job_54 实测：InfraRSI 三轮拆开查（尽调→论文数字→按需深挖）比一轮全查的置信度高且省
- **信源分级强制**：每条事实标 [A]=原文（代码/论文/docstring）/[B]=官方文档/[[C]]=第三方转述（仅线索不作结论）——C 级不采信为结论；**引用竞品数字时区分「论文实测/设计声明/代码 docstring」三级成熟度**（job_54 实测：AlphaTune 是设计文档未实现，把它当实测引用会翻车）
- **Gaps 段强制**：每份简报末尾显式列「查不到什么」——R7 上报不掩盖，后续按需补查
- 落盘：`research-{N}.md`（简报落盘后 read 取回再呈现，回执只是路径）

### 2. 差异分析（比）——三层对比法，必须含反向视角

| 层 | 做什么 | 为什么 |
|---|---|---|
| **骨架层** | 自改进分层同构对照（两者「进化什么」的层结构对齐，每层比护栏） | 只比机制会张冠李戴——同构层之间才能安全移植 |
| **血肉层** | 机制维度逐项对比，每个差异标「我独有/他独有/共有但不同形」 | 机制差异的证据表 |
| **反向层**（**强制，最易缺**） | 「我做得好而竞品做得不好的」坚守清单（附 trade-off 诚实标注） | 没有反向视角=自我贬低式学习——把自家优势当缺点换掉（job_54 实测：QD/四角色/Step7 外层被三竞品反向确认为独有资产） |

- **互证结构**：多竞品×自己教训的交叉表（独立来源共同收敛=最高置信；单源独见=按来源成熟度打折）——job_54 实测：噪声门禁四源互证（GECCO×job_23 课×两竞品×CompoundingKernel）直接定了 P0
- 对未实现系统评「做得不好」要分档：「尚未设计到」≠「设计错了」

### 3. 原创表达（创）——走探索流，不做头脑风暴

- **复用 skill:exploration_stream**（human-loop 的探索流）：SENSE 五步（问题还原→构建视角→洞察矛盾→辩证逆转→良质批判）+ 靶向卡点调研循环（判定阶段→派 research→**费曼张力呈现**→推进判定）
- 本 skill 叠加的竞品语境纪律：
  - **费曼纪律**（呈现侧）：把 human 当领域初学者；新概念 ≤2/块；**每个概念附人话定义，不附定义禁止出现**——job_54 实测：「QD/影子价格/慢流形分支」三次补讲都是因为首次呈现漏定义
  - **不代答纪律**：引导问题只给信息支架（张力的三种标注：证实/证伪/扩展你说的哪句话），原创表述必须是 human 的——**human 原话全程记录 judgment.md**（不转述）——这些原话是论文叙事的第一手素材
  - **架构哲学对齐检查**（关键教训）：调研推荐的机制必须过 human 的架构哲学检查——job_54 实测：parent 推荐「汤普森采样」被 human 正确驳回（数值后验=把语义决策降维到数值空间，与其 LLM-as-Strategy 哲学矛盾；stepping stones 证据证明数值后验会永远错过次优高潜节点）。**先问「这个机制与系统的核心哲学（哪些决策给 LLM/哪些给确定性代码）冲突吗」再推荐**
  - **数学化检验**（理论型想法）：概念定义 → 站在成熟数学视角做定义层映射（**不证新定理**，引用现成定理+可证伪预言承担原创义务）→ 诚实四层标注（数学严格/架构假设/经验假设/纯隐喻）——「贴数学标签无内容」会被审稿打回
- 落盘：`judgment.md`（原话+判定）+ `research_{N}.md`（每轮简报）

### 4. 落地转化（落）——五要素方向清单 → Job 骨架 → 可执行规格

转化链三级（**原创想法的价值由落地深度证明**）：

1. **方向清单**（每条五要素）：证据（附信源）→ 现状差距 → 落地路径（哪个模块/哪一层）→ 预期收益 → 优先级（P0=命中已实证痛点或三源互证）
2. **Job 骨架**：从 P0 方向提炼 2-5 个 job，每个含目标/改动面/验收判据/依赖——**改动面互斥可并行**（job_54 实测：五 Job 按模块边界切分互不冲突）
3. **可执行规格**（关键原创机制额外产出）：协议/信号的规格文档——数学定义、参数表、校准方法、实现接口、验收断言（如 job_54 的 saturation-signal-spec.md 与 adjust-protocol.md：四定义+输入输出 schema+合成序列单测断言）

- **蒸馏收口**：anchors.md（理论名片/协议精要/数学框架/实证义务/文档地图/下次起点）——下次 loop 从这里出发，不重读全程

## 边界（不适用/与其他资产的关系）

- 素材 ≥10 篇的知识库级综述 → 普通批量调研（不走本 skill 的探索流层）
- 一次性 bug 检索（「别人踩过这个坑吗」）→ 直接搜 domain/bugs.md
- 本 skill 是**编排纪律层**：research 派发规范复用 grilling skill；探索流细节复用 exploration_stream；沉淀为仓级知识走 learning loop
