# skill:super-sense（adjust 第二步：定主要矛盾 → 辩证逆转）

> 服务对象：**adjust agent**
> 加载方式：adjust 提示词声明路径 + 触发条件；执行到本步骤时 `read` 本文件
> 方法论 canon：`internal/prompt/templates/skills/sense.md`（SENSE 五步权威文本）——**必须按需 read 该文件**，本文件只规定 super 场景的落地方式，不复制 canon 全文

## 触发场景

`super_experiment_analysis` 完成、区间实验全景摘要已写出后加载。它解决一个问题：

- 「面对这一堆实验结果，**当前的主要矛盾是什么**？往哪个方向突破最值？」

没有明确的矛盾判定就进入 research 或调权 = 盲目探索，必须先用 SENSE 收敛。

## 预期效果

产出一份可执行的「**主要矛盾 → 突破方向**」判定，写进决策记录：

- **主要矛盾**：一句话，满足三个性质——**全局性**（影响多数格而非单格）、**根本性**（不是表象指标，而是机制成因）、**决定性**（解决它多数格同时受益）；附 ≥1 条具体实验证据（iter/seq）
- **突破方向**：1-3 个，每个方向可**直接映射为格动作**（新建格 / 改进格描述 / 调权），并说明「为什么这条路能绕过矛盾」
- **良质批判**：结论的置信度与残余假设（证据不足时显式标 `置信度: 低` 并要求补 research）

## 核心内容

### 五步在 super 场景的映射（canon 见上方路径）

| SENSE 步 | super 落地 |
|---|---|
| ① 事实还原 | 用 `super_experiment_analysis` 的全景 + research 检索到的事实。凡属**价值判断**（如「5% 波动是否可接受」「要不要赌一个新族」）→ 无 human 实时裁决时按**保守默认**处理，并写进决策记录「待人工复核」清单 |
| ② 构建视角 | 以「该域的性能模型」为**强相关**框架（如 matmul：内存带宽/计算强度/cache 层级/BLAS 派发/装配开销），**弱相关**框架用于创造（编译器优化、数值方法、分布式、异构计算） |
| ③ 洞察矛盾 | 从强相关框架解构成因，判定**主要矛盾**（全局/根本/决定）；给 1-3 个候选后**选定一个**并写证据；其余候选记入「备选」 |
| ④ 辩证逆转 | 把矛盾写成一对待转关系：X（阻碍）vs Y（期望）→ 问「当 X 是 Y 的必然前提时，如何让 Y 通过 X 实现？」产出 1-3 个方向。示例：「装配税阻碍 F 序布局收益」→「用 F 序布局让装配天然消失（布局即产物）」 |
| ⑤ 良质批判 | 自检：结论是否必然？隐含假设是否成立？若证据只能支持「猜测」→ 标注置信度并要求补 research（回第 ③ 步） |

### 产出格式（写进决策记录）

```markdown
## 二、主要矛盾（SENSE）
- **主要矛盾**：<一句话>（证据：iter12 seq… / iter14 seq…）
- **排除的候选**：<候选 + 排除理由>
- **辩证逆转**：
  - 阻碍 X = <…>；期望 Y = <…>
  - 方向 1：<如何把 X 变成手段> → 对应格动作：<new_cell / modify_cell / weight>
  - 方向 2：…
- **良质批判**：置信度 <高/中/低>；残余假设：<…>；需补证：<…>
- **待人工复核的价值判断**：<…>
```

### 纪律

- 矛盾判定**必须引用实验证据**（iter/seq 号），不得凭印象（这是决策可解释性的地基）
- **一个矛盾**（不是一堆）：选最主要的一个，其余进「备选」——多矛盾并行会让 builder 的设计方向失焦
- 逆转方向必须**可落地为格动作**；「应该更快」这类不可动作的表述视为无效
- 无 human 在场时不要越权做价值判断：保守默认 + 显式标注，留给人工复核
