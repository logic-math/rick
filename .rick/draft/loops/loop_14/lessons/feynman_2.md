## 最终对错条目（对 teach_1 §6 六条 expectation）

**E1 定义与成因 —— 对（二分挂点修正后收口）**
- 原话（20:36）：「OOD 缩水，就是分布外验证时优化分数缩小的一种现象」「进化算法学习到了选择器的特殊性规律，使得分数极高但效果极差」
- 判定：定义（未见分布上分数缩）+ 成因（过拟合任务特有模式，自有语版＝学习选择器的特殊性规律）均命中 teach_1 §1。挂点修正：复测原话「我说的是候选解」——通用/特殊二分挂在候选解上，非种群（teach_1 §2 第 3 步）。
- 依据：teach_1 §1/§2；research_1 §⑤ RRSI 动机自述「无约束进化在训练任务上大涨、OOD 基准上缩水甚至归零」〔A〕

**E2 形态（涨分真实、非噪声）—— 对（逼问轮一补达）**
- 原话（20:14）：「分数是真的」「传播出去的性能提升在其他场景无用」
- 判定：「分数是真的」＝训练 split 涨分真实可复现（teach_1 §1 表格加粗「不是」）；「在其他场景无用」＝真实但绑定该分布、不迁移——E2 全量命中。反讲缺失，受问后自己补上。

**E3 成因结构 —— 对（复测挂点修正后收口）**
- 原话：「由于选择器无法判断对种群的有害性，这是一种结构性误差，选择器是一种个体择优器无法得到全局择优器的结果，因此有害候选被保留最终导致失败」（20:36）＋「我选择 A，因为选择 A 获得奖励，那么下次还会继续选择 A 的恶性循环」（19:49）
- 判定：「结构性误差」＋「个体择优器无法得到全局择优器」＝「选择压力只来自 verifier 所测的分布、两类改进在选择眼里无差别」的准确自有语转写（teach_1 §6-3）；「选 A 恶性循环」＝逐轮积累放大。「个体择优器 vs 全局择优器」作为准确自有语转写判对。

**E4 与噪声界线 —— 对（逼问轮一收口，课前预判修正）**
- 原话：「他和噪声积累的区别在于，噪声的分数是假的」（20:14）
- 判定：与 teach_1 §3 区分一「噪声 = 分数是假的；OOD 缩水 = 分数是真的、测错了分布」精确对齐。课前（18:06）「学到了噪声规律」误读界线，此问下自纠。
- 依据：teach_1 §3。

**E5 与两失败模式界线 —— 对（反讲时自主推导）**
- 原话：「这里存在另一个被忽视的维度，对于选择器奖励的精英解可能对整个种群是有害的，他可能正确且快」（19:49）
- 判定：正确且快＝两道 gate 全绿仍是坏候选＝teach_1 §3 区分二「正确性 gate 与性能信号双绿灯，仍可能 OOD 缩水」。无提示自主推出。

**E6 防御 —— 边缘（补讲部分收口，差环未答）**
- 原话：「独立的任务集，以及正则化」（19:49）／「第一个问题我回答不了，我对进化-保留拆分没有理解透彻」（20:14）／「loop 可能会保留一个特殊性优化的候选解」（20:23）／「离线 AUC 验证，在线真实流量实验，本质上就是独立验证集这一方法的检查」（20:36）
- 判定：满足「能述其一」底线（独立验证集点名＋结构性映射到自有部署协议）。三处未收口：①「提案器和选择器的因果要被隔离」滑动由 parent 补讲纠正（选择压力必须传导、RRSI 两端加约束非隔离），非自纠；②拆分承重点「保留任务从不参与选择」只在 parent 给线索后方向正确（「可能会保留一个特殊性优化的候选解」），第二层信号污染机制为补讲；③独立验证集教科书形态＝每轮候选的接受门槛，human 形态＝一次性部署验证——差环已指出未答（见下）。

## 最简呈现评价

**OOD 一句话（20:36 原话）**：
「OOD 缩水，就是分布外验证时优化分数缩小的一种现象，由于选择器无法判断对种群的有害性，这是一种结构性误差，选择器是一种个体择优器无法得到全局择优器的结果，因此有害候选被保留最终导致失败，进化算法学习到了选择器的特殊性规律，使得分数极高但效果极差。」
- 命中核心：现象→结构性成因（个体择优器）→失败路径（有害候选被保留）→成因（学到特殊性规律）压进一句话，全程自有语言、无背书痕迹——达到「用最简单话语讲清核心机制」水平。
- 「学习到了选择器的特殊性规律」＝准确自有语转写（判对）且比原表述更具生成性：把过拟合的挂点钉在「选择器所测分布的规律」上。
- 遗漏：E2 的「涨分真实、非噪声」未在句中显式出现（逼问轮一已单独收口，非硬伤；一句话压缩丢掉了形态要素）。句首以「分布外」定义「OOD 缩水」略自指，信息量由成因链承载。

**美团类比（20:36 原话）**：「离线 AUC 验证，在线真实流量实验，本质上就是独立验证集这一方法的检查。」
- 种类上对：把自有协议（第一轮原话「我会在大规模的 auc 上离线验证他的正确性，然后在部署到线上，以实际流量开实验观察全链路耗时的变化」）结构映射到独立验证集——离线 AUC＝loop 所测分布、线上真实流量＝从未参与的独立分布。正合 teach_1 §5「你来推 ②」收编为类比的课程设计。
- 差环（parent 已指出，human 未答）：教科书形态＝接受门槛——独立验证集是 loop **内部**「作为接受与否的最终门槛」（teach_1 §5 防御表原词），逐轮、对每个候选生效；human 形态＝loop 结束后的一次部署验证。loop 场景需要每个候选过独立分布的 gate 才能进种群，事后单查不能阻止任务特有模式的积累。此差环恰是部署经验通向美团 loop verifier 设计的桥（teach_1 §5 末，通第 21 课）——保留为复测项。
- 次级差环（未要求验证）：以线上真实流量当独立分布自带「验证集也会被过拟合」下一层风险与成本不对称——teach_1 §5 点名过，不再计入。

## 原创素材登记（供 originality-sparker 接力）

1. **「个体择优不一定能完全转化为种群择优」**（19:49）——选择压力的种群级视角：选择器逐个优化候选，但积累效应落在种群上；个体最优与种群最优解耦。超出 teach_1 文本。
2. **「对整个种群有害的精英解」**（19:49）——正确且快却对种群有害：害处活在种群层，个体层两道 gate 不可见——E5 第三失败模式的自有延伸，具生成性（可作 verifier 设计判据：需要种群级有害性信号，非个体级指标）。
3. **「进化算法学习到了选择器的特殊性规律」**（20:36）——准确自有语转写且带再框定：过拟合挂点＝「选择器所测分布的规律」，选择器本身是被过拟合的基底。可连 RRSI critic/pruner（筛 benchmark 特有提案）与第 16 课批评层。
4. **「逐步积累这种复杂性会对后续的优化造成干扰浪费上下文」**（20:14）——二阶成本：特殊性优化传播带来复杂性债务、挤占后续搜索的上下文预算。超出 teach_1 文本；可与 RRSI「产出的 harness 比无正则进化省 30% policy token」实测数字（research_1 §⑤〔A〕）连成一条——复杂性债务直觉独立预测了正则化顺带省 token 的原因，是带验证机会的原创点。
