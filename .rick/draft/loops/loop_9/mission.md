# 学习使命 — loop_9 — Mac Studio M5 Max vs M5 Ultra 选型决策

## 为什么学这个（要解决的真正问题）
- 要一个**明确购买建议 + 理由**（决策支持，非深度技术课程）。
- 核心决策：Mac Studio 两款选一 —— M5 Max（64GB / 18+40核 / 512GB，国补后约 ¥25,000）vs M5 Ultra（96GB / 30+64核 / 1TB，国补后约 ¥45,000）。

## 事实前提（human 给出的、不可更改的前提）
1. 当前：只部署 agent + 订阅服务（本地不跑模型）。
2. 未来：考虑部署 agent + 本地大模型。
3. 其他诉求：办公 + 偶尔游戏（已有 Switch，部分游戏玩不了；「Mac 能玩但 Switch 玩不了」是诉求之一）。
4. 对象观点（「Mac 上不跑模型、芯片不用那么好」）**不作为辩论对象**，只作背景；「当前只部署 agent」与「未来可能部署本地大模型」是事实前提。

## 学习目标与考核标准（human 采纳 parent 建议）
学完 = human 能不看资料、用大白话讲清三件事（据此能独立下判断）：
1. 「部署 agent」需要多少内存 / 多大芯片——对象说的「不跑模型就不用好芯片」在什么前提下成立、边界在哪。
2. 什么规模的大模型能在 64GB / 96GB 上跑、跑不动时到底卡在哪（内存？带宽？其他？）。
3. 多花的 ¥20,000 买到的是什么、买不到的是什么——哪些「未来可能用到」、哪些「永远用不到」。

## 起点
- human 自评：概念「清楚了」。
- 教学处理：不追求深度技术课程，只求把建议的理由讲透到能独立下判断。
