## 0｜从你自己的答案接入：两份答案各踩中一半，各缺机制半边

课前的认知强制问了两问：a) 为什么不只用最强的 Pro？b) 只关心速度一个指标，多维分数字典留着有什么用？

**你的 a) 答**：「仅仅是成本的问题，对于大规模的进化搜索而言，token 成本决定了其规模化的上限，只有一定规模的进化才能见到效果，而选择合适智能的模型是节约成本的一大手段。」——后半句「**只有一定规模的进化才能见到效果**」是这句话里最值钱的部分，你说对了规模是效果的前提；但「仅仅是成本」把 Flash 定位成**账单优化器**——按这个框，Flash 的全部价值是省钱，Pro 的角色（以及只丢 Flash 会失去什么）整段缺席。

**你的 b) 答**：「多维指标可以进行有效的目标约束，比如我虽然只关心速度，但我还可以约束其改动量……我们得到一个精英地图，本质上是在回答在不同的维度目标的评价体系下，哪些 code 是最优解法，最终得到的其实是一份完整的优化轨迹。」——「精英地图」「优化轨迹」这两个你自己的词里装着答案的原材料；但「**目标约束**」这个框走偏了：约束是一个**选择端**机制（帮我挑得更好），而论文的论证跑在你第 3 课刚坐实的那条通道上——**回浮**（帮我产得更杂）。这不是约束论证。

两份答案的共同点：方向感都在，机制半边都缺。这节课只做一件事——把两个「不会」焊到机制上，并让你看清它们其实是**同一件事**：

```
吞吐-质量联合（本课主题）
 ├─ 双模型分工 = proposer 端的吞吐×质量（想法的量 × 想法的质）
 └─ 多维分数   = 回浮端的多样×聚焦（什么样的差异值得保留为「高分」）
```

## 1｜双模型：不是成本学，是搜索论——想法吞吐量 × 偶发跃迁

事实层（A：arXiv 2506.13131）：

| 模型 | 角色（论文原文口径） |
|---|---|
| Gemini 2.0 Flash | 低延迟 → 高频候选 → **单位时间想法量大** |
| Gemini 2.0 Pro | 更强 → **偶发高质量建议** → **可能突破性跃迁** |
| 论文观察 | **基座 LLM 越强，AlphaEvolve 越好（model-agnostic）** |

先把你的成本框翻过来。你自己说「只有一定规模的进化才能见到效果」——**规模 = 单位时间产出的想法数**。Flash 不只是在省钱，它在**供给那个规模**：进化搜索消费的是想法量，你第 3 课刚坐实的那台机器——三件套入库、prompt sampler 回浮——吃的是候选流；候选断流，数据库与回浮机制设计得再好也空转。**Flash 的搜索价值 = 让单位时间的想法量大到「进化才见得了效果」的规模**；省钱只是这件事的副产品。这正是整条流水线的自述目标：asyncio 流水线**按吞吐量而非单步速度优化**（A）——双模型是同一个优化目标在 proposer 端的落实。

Pro 半边，注意「**偶发**」写在角色定义里、不是缺陷：搜索大部分时间在既有解周围做小变异（你会的 exploitation 侧），偶发的一次高质量远跳可能直接跨进新的高产区——**跃迁 = exploration 的供给侧**。Pro 不是「更贵的 Flash」，是频谱上另一端的东西。

**消融实证（A，§4）**：两任务（矩阵乘法张量分解、kissing number 下界）× 3 随机种子里，「Small base LLM only」臂——**单一小模型，去掉模型混合的采样多样性**——显著变差。teach_3 埋过伏笔，这臂踩的就是本课双模型。

**你来推 ①（小模型臂悖论）**：按你的成本框推一推——小模型更快更便宜，同样预算下采样量应该**更大**；成本框会预测「小模型臂不亏、甚至赚」。实验结果反着来。**你的成本框缺了哪个变量？**（提示：想法量不是均匀同质的——想想「命中率」，再想想它分布在尾部还是中部。）

两句边界钉死，防止过度叙事（事实/解读分层）：①「model-agnostic」是论文观察（A）——AlphaEvolve 是模型无关骨架，基座升级则 Flash/Pro 两档水位同时上移、loop 收益跟着涨；「这意味着它可以坐吃下一代模型红利」是我的综合解读、非原文。② Flash/Pro 的具体**调用配比、路由规则论文未载**——与岛数、迁移周期同性质：不知道就是不知道，不臆造。

## 2｜多维分数：同分异形——不是约束论证，是回浮论证

事实层（A：2506.13131 原文口径）：**只关心单指标时，多指标共同优化也常改善该目标指标**——不同「好」的定义下拿高分的程序，结构/逻辑相异；相异的高分者回浮进 prompt，可刺激更多样的候选，**提升命中目标指标新颖解的概率**。注意原文说的是「**常**改善」——是概率性收益，不是保证。

先切开你的约束框。你的「改动量 tie-break」（速度相同时优先选改动少的）是真实可用的设计——字典序/平局裁决，作用在**选择端**：多维帮我**挑得更好**。而论文的论证跑在**生成端**：多维帮我**产得更杂**。两框机制位置不同：

```
约束框（你的）：字典多维 → 选择更精细 → 留下的更「对」        ← 选择端
回浮框（论文）：字典多维 → 高分者彼此相异 → 回浮更杂 → 候选更杂 ← 生成端
```

论证链展开（箭头链，A 级事实 + 每步机制位置）：

```
多维「好」的定义
 → 在不同定义下拿高分的程序，结构/逻辑相异（同分异形）
 → 相异的高分者都值得入库、都值得回浮
 → prompt 里的 prior programs 更多样（第 3 课那条采样通道）
 → proposer 视野里的变异素材更宽（你自己的话：避免重复的坑）
 → 命中新颖解的概率↑
 → 你唯一关心的那个目标指标，也常改善
```

这条链的第 2 步有个专门的名字——**同分异形**（我造的压缩词，机制是原文的）：在你唯一关心的指标上**分数完全相同**、但**结构不同**的两个程序。

**内嵌复述点①（挂账，上轮欠的）**：上轮 feynman 你两轮抽象（「更多事实信息」「区分度」）没落地，parent 补讲后无复述——现在补完它，而且你自己已经给了一半例：**速度相同、改动量不同**。落成具体情形：两个候选在你唯一关心的速度维度上分数完全相同——一个重写了内层循环的访存模式，一个换了批处理策略；单维视角下它们**等价**（留一个就够，另一个的信息量是零）；多维视角下它们是**两条不同的路**——字典里其它维度把它们区分开，都算高分，都入库、都回浮 → proposer 的 prompt 里同时躺着两条路的完整代码。只留一条，另一条路的结构信息从此**不会被采样到**。「分数相同、行为不同」的具体情形，就是它。

**内嵌复述点②（挂账，上轮检验 B 的链式观）**：你上轮的闭环最简表达里有半句「评估函数产生执行输出**形成**分数」——把两件入库物链成了一件。边界钉死：**分数 = evaluate 压出来的标量字典**（一件，管排序与回浮资格）；**执行输出 = 程序行为本身的记录，没被压成数**（另一件）。多维论证跑在**分数**这件上——字典的维度决定「什么样的差异被保留为高分」；执行输出进 proposer 走的是**另一条通道**：四类定制里的「渲染的评估结果」（§4）。一句压缩语收口：**分数管排序，输出管提案**——两件物、两条通道，不可再链成一件。

**你来推 ②（砍维思想实验）**：把字典砍成单维（只留速度），回浮进 prompt 的 prior programs 会变成什么样？连你会的两个东西推——No evolution 臂的「变异素材枯竭」、纯利用死胡同。（推到「单维排序下高分者趋同，prompt 里躺着的 prior programs 会……」这一步，就通了。）

**⚠️ 谱系边界（硬纪律）**：你爱用的「**精英地图**」（MAP-Elites 格子直觉）是你自己背景带来的谱系概念——2506.13131 对 MAP-Elites 仅「组合启发」级引用、**未展开内部机制**（C 级回指 [74]，zpd 已记你两次把谱系细节当机制讲）。用它帮理解没问题，但判分时它不是 2506.13131 机制事实；本节论证链（相异→回浮→多样→命中）才是 A 级原文。「优化轨迹」同理——好用，别当论文机制讲。

## 3｜合拢：一个主题，两个器官——吞吐-质量联合

现在把两个概念收拢成一件东西（综合解读，非原文原句——原文分别给事实，合拢是本课的教学生成）：

| | 吞吐侧 | 质量侧 | 张力归属 |
|---|---|---|---|
| 双模型（proposer 端） | Flash：单位时间想法量大 | Pro：偶发高质量跃迁 | 新想法从哪来——量与质 |
| 多维分数（回浮端） | 字典维度多 → 相异者都回浮 | 分数排序 → 聚焦改进最优 | 旧想法里哪种差异值得保留 |

两端各自是第 3 课命名的 exploration/exploitation 张力的一个器官：双模型管**新想法的供给**（量大保底 + 质尾偶发突破），多维分数管**旧想法的回浮选择**（多样差异被保留 + 高分聚焦被优先）。你的基因类比（上轮 feynman 自创、已登记的原创素材）直接可用：Flash ≈ 大量变异，Pro ≈ 偶发有利突变，多维分数 ≈ 保留多种基因型的选择压而非单一适应度。

消融两臂（A，§4）恰好各砍一端：「No evolution」砍回浮端（第 3 课已教）、「Small base LLM only」砍 proposer 端模型混合——**两臂均显著变差**，论文结论原话 "each of the components is responsible for a significant improvement"。两块证据拼起来正是本课主题：搜索的产出 = 想法流 × 回浮机器，量、质、多样，各砍一刀都塌。

**你来推 ③（量能否换质）**：假设预算无限，只用 Flash 但采样量放大 10 倍，能不能等价于加上 Pro？——这是「量能否逼近质尾」的问题，**论文未论证**，留给你的工程直觉。（想想你自己的主场：在线推理里「高频小请求」和「偶发大请求」对系统意味着什么不同？）

## 4｜prompt 四类定制：proposer 输入的可调面

主 prompt 的组成你第 3 课已学（prior programs 带分数+完整代码｜current program｜系统指令）。四类定制是**叠加**在主 prompt 上的可调面（A：2506.13131）：

| 定制 | 内容（A） | 机制位置（自注） |
|---|---|---|
| 显式上下文 | 文献 / 公式 / 代码片段 | 专家知识注入——任务指令「受专家知识启发」的落地 |
| 随机格式模板 | 随机化呈现格式 | **增多样性**——多样性不止在「喂哪些解」，还在「怎么呈现」 |
| 渲染的评估结果 | 评估产出渲染进 prompt | **执行输出类信息进 proposer 的通道**（复述点②的另一半） |
| 元 prompt 进化 | LLM 自拟指令，存**独立数据库**，与解共同进化 | **第二个库**——指令本身也在进化 |

四件里三件踩在本课主题上：随机格式模板是 prompt 端的多样性器官（与多维分数论证同一逻辑：多样的输入 → 多样的候选）；渲染的评估结果是执行输出的回浮通道；元 prompt 进化最重——**论文里有两个库**：第 3 课的解数据库 + 这里的元 prompt 数据库，LLM 自拟指令、**与解共同进化**（「共同进化」是原文口径，A）。用你的基因类比自由延伸：不只基因在进化，「培养指南」也在进化，两个种群互相喂养。边界照例钉死：元 prompt 的具体进化算子、更新频率论文未载，不臆造。

## 5｜课尾费曼检验设计（两项判据检验 + 两个挂账复述点）

**检验一｜双模型两角色（本课判据）**：Flash 与 Pro 各自答什么（Flash：低延迟→高频候选→单位时间想法量大；Pro：更强→偶发高质量建议→可能突破性跃迁）、为什么缺一不可——**必须答出成本框之外的东西**（上轮你的答案整段是成本；这次若还是只有省钱，算不达标），并带上 Small base LLM only 臂作证据。

**检验二｜多维分数论证链（本课判据）**：四步一口气——**相异 → 回浮 → 多样 → 命中概率**——不得复述成「目标约束」（上轮你的答案整段是约束框；这次若复述成「多维帮我挑得更好」，算不达标）。

**挂账点①（同分异形具体情形）**：用你自己的「速度相同、改动量不同」例补完——两个候选、字典里其它维度如何区分它们、为什么两条路都值得回浮。

**挂账点②（两件入库物边界）**：「分数管排序，输出管提案」——各自进 prompt 的通道是什么（分数随解采样；执行输出走「渲染的评估结果」）。

三个留白的自查顺序：①（小模型臂悖论——成本框缺什么变量）→ ②（砍成单维后 prior programs 会怎样）→ ③（量能否换质）。

## 6｜对照钩子与原创视角（埋点不展开，判断权在你）

**对照钩子**：SoL-Pi 的多环境×多数量大规模 rollout（第 17 课）——吞吐轴的另一个样本：它把「量」花在环境×数量上，到时候对照「各系统把预算的量投在哪个部件」；Harness² 的预算扩容（第 14 课）——评估成本的吞吐面（单解约 100 compute-hours 是 AlphaEvolve 口径，你已会）。

**原创视角（两个候选设计面，非结论）**：
1. **美团 agent 档位分工**：快档（flash 级）高频试 serving 配置/kernel 变体，强档（pro 级）处理升级与难题——双模型逻辑的在线推理版。可以与你挂起的 gen env 集成提议（第 2 课原创点）连起来：gen env 若承担判真协议，双档 agent 就是它的候选供给侧。
2. **多指标 verifier 字典**：在线推理天然多维（吞吐/延迟/成本——你的主场）。多维分数论证直接适用：只关心吞吐时，延迟与成本维度照留——同分异形的候选们回浮，生成端更杂。哪些维度入字典、哪些当 gate（正确性）哪些当信号（性能）——你会区的 gate/信号分离直接压上来。

## 7｜本课关键概念清单

（自述检验用，一行一条——它们就是费曼轮的 expectation 清单）

1. 双模型角色：Flash 低延迟→高频候选→单位时间想法量大 × Pro 更强→偶发高质量建议→可能突破性跃迁（A）——搜索价值不止成本；Small base LLM only 消融臂显著变差（A）
2. model-agnostic 观察：基座 LLM 越强 AlphaEvolve 越好（A）——模型无关骨架，两档水位随基座同升
3. 多维分数多样性论证：不同「好」定义下高分程序结构相异 → 回浮刺激多样候选 → 提升命中目标指标新颖解概率（A）——生成端论证，非选择端「目标约束」
4. 同分异形：单指标同分、结构不同的程序，多维字典让它们都值得入库回浮——复述点①「分数相同、行为不同」的载体
5. 两件入库物边界：分数 = 压成的标量字典（管排序）；执行输出 = 未压扁的行为记录（管提案，走「渲染的评估结果」通道）——复述点②
6. prompt 四类定制：显式上下文｜随机格式模板（增多样性）｜渲染的评估结果｜元 prompt 进化（第二个库，与解共同进化，A）；Flash/Pro 配比与元 prompt 进化算子论文未载
