# skill:sense_reconstruct（阶段 1 · 问题还原——思考门禁 skill）

> human-loop v8：本文件是 SENSE 五阶段思考门禁 loop 的阶段 1 skill（main agent 会话内执行）。
> 双重目标：① 启发用户深入思考本阶段内容 ② 验证用户的思考是否足以通过本阶段思考门禁。
> SENSE canon（五步权威文本）：`{{sense_skill_path}}`。

## 本阶段思考目标（问题还原）

还原问题的全部事实信息与价值判断，分清楚期望与现状：

- **期望**：要达成的状态——它属于价值判断，须用户自己确认后才可作为推理前提。
- **现状**：当前实际是什么——事实信息，必须回溯到常识性的置信信息源（来源收敛：一手来源/经典教科书/规范/权威综述；每步能回答「我从哪知道的」）。
- 回溯不到常识层的一律不是事实，标记为价值判断或假设，交还用户判断。
- **期望与现状之间的差距**即问题空间。

## orig 派发契约

派 orig agent 调研启发（基于用户当前思考进度），task 模板：

```text
subagent({ workflowScript: "return runs.run('orig-stage1', { agent: 'orig', task: '阶段：问题还原（阶段 1）。用户当前思考进度：<用户对期望/现状/事实的原话摘要>。缺口：<门禁未过时一句话指出，首启略>。给用户返回怎样的内容才能引导他完成本阶段的思考目标？调研素材落盘 <orig_dir>/stage1_{seq}.md（write 首块 + bash 分批追加）' })", timeoutMs: 3600000 })
```

## 启发呈现纪律

- orig 返回的启发内容经教学润色 skill 润色后呈现（每个概念科普讲清楚，见 teacher_polish skill）——**不是答案**。
- 不替用户还原问题；呈现完概念后按 teacher_polish 的收尾引导，引导用户串联概念、用自己的话表达思想（表达将接受门禁判定），用户的回答是本阶段产出。
- 引入任何领域概念附一句人话定义（权威来源）；不附定义的概念禁止出现。

## 门禁标准（main agent 判定）

用户通过本阶段思考门禁，当且仅当其回答中：

1. **期望、现状、差距三个结构化表述说清楚**：三者分别有明确表述，未混为一谈；
2. **能清晰地明确价值判断和事实判断**：事实表述能回答「从哪知道的」，价值表述被识别为期望/判断而非事实。

## 未过门禁行为

- 一句话指出缺口（如「你的现状描述里有一步是推断——它的来源是什么？」）。
- 按缺口重调 orig（派发契约的 task 中填入缺口）针对性再启发；无重试上限。
- **推进权在用户**：用户说「推进」即进入阶段 2（视角生产），不阻拦。
