# skill:sense_contradiction（阶段 3 · 判断矛盾——思考门禁 skill）

> human-loop v8：本文件是 SENSE 五阶段思考门禁 loop 的阶段 3 skill（main agent 会话内执行）。
> 双重目标：① 启发用户深入思考本阶段内容 ② 验证用户的思考是否足以通过本阶段思考门禁。
> SENSE canon（五步权威文本）：`{{sense_skill_path}}`。

## 本阶段思考目标（判断矛盾）

选择思考框架后，用该知识领域的术语解构问题的成因；结合当前的具体问题，确定造成问题的演化过程中，哪种要素是**全局性、根本性、决定性**的成因——即主要矛盾。

- 可以给出**多个备选**，供用户自己判断选择。
- 不替用户收敛到单一矛盾。

## orig 派发契约

```text
subagent({ workflowScript: "return runs.run('orig-stage3', { agent: 'orig', task: '阶段：判断矛盾（阶段 3）。用户当前思考进度：<用户选定框架与初步矛盾判断原话摘要>。缺口：<门禁未过时一句话指出，首启略>。给用户返回怎样的内容才能引导他完成本阶段的思考目标？调研素材落盘 <orig_dir>/stage3_{seq}.md（write 首块 + bash 分批追加）' })", timeoutMs: 3600000 })
```

## 启发呈现纪律

- orig 返回的启发内容经教学润色 skill 润色后呈现（每个概念科普讲清楚，见 teacher_polish skill）：所选领域中同类矛盾的结构（该领域如何定位主要矛盾，带来源）——**不是答案**。
- 不替用户定位矛盾；呈现完概念后按 teacher_polish 的收尾引导，引导用户串联概念、用自己的话表达思想（表达将接受门禁判定），用户的判断是本阶段产出。

## 门禁标准（main agent 判定）

用户通过本阶段思考门禁，当且仅当其回答中：

1. **基于这一视角对问题进行解释**：用所选视角的术语解释问题现象的成因；
2. **定义决定性/根本性/全局性的矛盾来描述其因果运动**：至少一个主要矛盾被定位，且被放在决定性/根本性/全局性的维度上说明它如何驱动问题的因果链。

## 未过门禁行为

- 一句话指出缺口（如「你定位的是现象不是成因——往上游推一步是什么？」）。
- 按缺口重调 orig 针对性再启发；无重试上限。
- **推进权在用户**：用户说「推进」即进入阶段 4（辩证逆转），不阻拦。
