# 第 5 课｜四路线谱系总图 + 美团落点空白

> 模块 2 第 1 课（综述骨架课）。材料源：R（research_1）「领域谱系」+「Gaps」节。本课只做一件事：把 infra RSI 的领域结构立成一张**可复现的图**，把美团落点在图上标成**空白**。各路线 exemplar 只定位、不下钻——每条路线后面都有整块模块等着。

## 1｜从你的两桶出发——轴对了，桶漏了

你昨天的认知强制答案（16:57）：按「可以进化的对象」分两桶——

- **harness 桶**：推理框架、loop、skill、tools、prompt、plugin、hook 等 agent 扩展组件，「可以实现自进化」
- **model 桶**：模型结构、loss 公式（目标定义）、训练 pipeline、数据生成、训练框架

先给结论：**你的轴就是 R 立谱系用的轴**——按「被进化的对象」分。这个轴耐用，因为对象直接决定 verifier 能不能客观（改外部代码，编译器＋计时器说了算；改 benchmark 分，分数说了算）和 loop 的成本结构（改 harness 几乎零部署成本，改权重＝整套训练 infra）。轴不动、不推翻——只在桶上做手术。但两桶漏了三处，且不是你疏忽，是这套分类法的**结构性盲区**——恰好是本课要立的全部内容：

1. **路线 1 无处安放**：你深学三课的 AlphaEvolve，进化的既不是 agent 自己的 harness、也不是 model——是**外部代码/kernel**。学得最深的 exemplar 恰是漏桶，最锋利的入口。
2. **harness 桶抹平了 target/harness 之别**：「推理框架」在你桶里是 agent 的扩展件；但在路线 3 里，serving 框架是被 LLM agent **优化**的对象（target），agent 自己的 harness（prompt/tools）另算一层。
3. **元层结构性不可见**：批评层和评测基建**不进化任何东西**——它们 judge 进化。按对象分类，没有对象的东西天然看不见。

R 立谱系的原始问题：**「infra 领域里 RSI loop 有几样东西在被进化？各自靠什么判真假？」**——按对象数桶数出四条路线，数不出来的单列元层。你的两桶数出了两条（路线 2、4），漏了 1、抹平了 3、看不见元层。逐个补齐。

## 2｜补桶一：路线 1——你的 exemplar 恰是无处安放的那个

**路线 1｜代码/内核进化搜索**（A）：LLM proposer 改**外部代码**，自动 evaluator 打分（编译/正确性/计时），进化搜索留存。闭环你已会——AlphaEvolve 是全速对照锚，这里只做图上定位，机制不重讲。

定位检验（你来推）：AlphaEvolve 改的那个 kernel，是 agent 的 harness 吗？是 model 吗？——都不是。它是**第三方工件**：改好它，收益落在外部资产上，agent 本体与权重分毫不动。这就是它在你两桶里无处安放的机制原因；也正因为对象在外部，verifier 最干净——编译过没过、数值对不对、跑了多少微秒，**不经过任何 benchmark 分数**。

## 3｜分裂 harness 桶：路线 2 与路线 3——z.ai 的递归拧结

你的 harness 桶装着两类东西，分属两条路线。分裂线一条：**谁改谁**。

### 路线 2｜agent 自己的扩展件（权重冻结）

agent 改**自己的外围件**，权重不动。harness 八件套你已会（探针 2① 机制级）——直引不重讲。代表（A 级，只定位）：**ADAS**（2408.08435，自动设计 agent 系统，开山）→ **Darwin Gödel Machine**（2505.22954，开放式进化自我改写 agent 代码）→ 2026 主战场：**Harness²**（两级递归）／**RRSI**（正则化）／**SoL-Pi**（成本轴）等（全名单见总图）。

**钩子连第 1 课**：RRSI 的存在理由就是你已会的 OOD 缩水——无约束进化训练任务大涨、OOD 基准缩水甚至归零（R §⑤）。为什么偏偏这条路线得病？用你的 E3 自有语：**选择压力只来自 verifier 所测分布**——路线 2 的 verifier 是 benchmark 分，奖励的就是「所测基准特有模式」。第 15 课正面教怎么治。

### 路线 3｜「推理框架」是被优化的对象（target），不是 agent 扩展件

**路线 3｜serving infra 自动优化**（A）：LLM agent 当 infra 工程师，优化**跑模型的系统本身**；verifier＝生产级基准（吞吐/延迟/正确性）。最贴美团在线推理——模块 3 四课全在这，你的主场。代表（各一句话，后四课下钻）：

- **z.ai GLM Infra Agent**（官方博客 2026-09-17）：生产级叙述——"the model optimizes the system; the system runs the model"。**事实层**：3.2× 吞吐；**立场层**：「通往 RSI 早期一步」＋官方自认「非 RSI、人类保留目标/边界/风险裁决」。（立场层注：作者立场，human 已裁决接受为**学习前提**——学习前提 ≠ 美团投入方向。第 7 课正面拆。）
- **FlashInfer-Bench**（MLSys 2026）：kernel 生成→评测→部署三段闭环，生产级基准当 verifier——美团闭环骨架候选（第 8 课）。
- **Helion × CompileIQ**（PyTorch 官方博客 2026-10-19）：「已 autotune 到最优」之下再搜**编译器控制空间**（ptxas/NVCC 内部控件——默认值从未被搜索过）；统计过滤语言第 2 课已解锁（第 9 课）。
- **GEAK e2e_workflow**（2507.23194，AMD 生产级）：端到端优化 vLLM/sglang 吞吐＋进化知识库（第 10 课）。

**拧结点破——你抹平的那个差别就在这句口号里**：被优化的 serving 系统，**正是执行优化的 agent 的宿主**——model（带着自己的 harness）优化 serving 系统，serving 系统跑 model。看似循环，但**不是同层循环**：被优化对象（serving infra）与优化者的 harness（agent 外围件）**分属两层**。你的两桶把「推理框架」塞进 agent 扩展件桶，抹平的正是它。RSI 语言一句话：**路线 3 的 target ≠ 路线 2 的 harness**——路线 2 是 agent 改自己，路线 3 是 agent 改宿主。

> **你来推**：路线 1 和路线 2 都是「LLM 改代码＋评测＋留存」——ADAS/DGM 改 agent 代码，AlphaEvolve 改外部 kernel。同样改代码，R 为什么分两条路线？（提示：**递归性落在哪一侧**——路线 2 改的是 agent 自己依赖的件，路线 1 改的是与 agent 本体无关的第三方工件。想清楚，「自我改进」四个字在两条路线里各落在哪。）

## 4｜补列：元层——按对象分类天然看不见的东西

**为什么看不见**：批评层与评测基建**没有「被进化对象」**——它们的对象是**别的系统的产出与主张**。按对象分桶，没有桶能装「没有对象的东西」。这是轴的结构性盲区——也正是元层**单列**而非当第五条路线的原因：它不是一条路线，是**审四条路线的那层**。两组件（R 元层节，A 级；FlashRSI 例外标注）：

**批评层**（judge「改进是真是假」）：**HUINHB**（2605.30621，EMNLP'26：harness-updating ≠ benefit 解耦，第 16 课）｜**Rethinking Harness Evolution**（2607.12227：单测搜索＋同一公开基准报分，与 test-time scaling 不可比）｜**Where Does Value Live**（2609.02889：收益局部化＋预算切分陷阱）｜**kernel 评测危机三篇**（KernelBench-Verified 2607.16241／Correctness Illusion 2606.20128／Correct but Slow 2607.04454——第 6 课正面教）。

**评测基建**（给「判真假」供基建）：**FlashRSI**（RUC-NLPIR：12 方法 × 30 基准 × 3 harness 统一横评，实验＝方法×harness×benchmark 三元组＋far-OOD 迁移列；**无同行评审论文**，A＝官方文档站＋仓库，第 19 课）｜**σ-Bench RSI 页**｜**MetaRSI/RSI2**（2609.06396：对 RSI 系统本身做 RSI——元层自己变进化对象，递归再拧一层，第 20 课）。

**已会锚全接上（元层是你的主场）**：mission 考核「有效/无效＋为什么」——判这个的工具**全在元层**，你的已会锚逐条对上：判真协议三要素（第 2 课）→ 批评层本质上是把判真协议装到 RSI 评测上；OOD 缩水（第 1 课）→ FlashRSI far-OOD 列、RRSI 正则化、HUINHB 批评共用这块地基；噪声累积→系统性假阳性（会区锚）→ 危机三篇的价值观地基；两失败模式 → fast_p 双端惩罚的设计逻辑；gate/信号分离（探针 2②）→ 危机三篇全部对策的骨架。

> **你来推**：危机三篇的对策——多 shape/对抗输入、源码审计、独立计时、SOL 锚定——**哪些守正确性 gate、哪些守性能信号**？第 6 课开课收这个答案。

## 5｜你的 model 桶：路线 4——桶对得上，机制要补

**路线 4｜RL 自我训练（权重在线更新）**：你的 model 桶与它对得上——模型结构、loss、训练 pipeline、数据生成、训练框架全是它的工作对象（R 路线 4）。桶不漏、不分裂；但两处机制要说透——恰是 R 总判断第 3 句压的两处：

1. **verifier＝环境＋奖励**——不是编译/计时那种客观 gate。后果：奖励稀疏时**信用分配**难（一个 rollout 赢了，是哪一步、哪个 token 挣来的？GRPO→GSPO/CISPO 是部分回答）；环境与奖励本身可被 hack（reward hacking，路线 4 固有难题）。
2. **infra 成本极重**——异步（partial rollout/staleness）、一致性（训推不一致：GSPO 实测每次更新约 10% 激活专家翻转）、长尾（MiMo 实测 25 数据源平均生成 token 差 90×；StepFun 约 5% 样本占约 80% 生成成本）。这些数字**当前只能按 C 级记**：微信①是二手综述，逐条回指 11 家官方报告未完成（R R7）——信源纪律活例。

代表（只定位）：**微信①**（韦子扬《Agentic RL Infra 主流技术路线综述》，C→回指 11 家官方报告）覆盖 11 家：colocated vs disaggregated vs 弹性混合——**美团 LongCat DORA 在列**（你的独有信息优势，第 18 课正面用）。架构选型你是专家，第 18 课不重讲入门，重心就是上面两处。

## 7｜R 谱系总判断——综合判断，取舍权在你

R 在谱系节末的总判断。**先标性质**：A/B **综合判断**——综合自多篇 A 级原文，非任何单篇实测结论；下面是**引用呈现**，不是已裁决事实。四句：

1. **路线 1/3 最稳**：verifier 客观可自动判定（编译、正确性、计时、吞吐）——RSI loop 最稳。
2. **路线 2 有过拟合与评测可信度问题**：verifier 是 benchmark 分——批评层集中于此。
3. **路线 4 用环境＋奖励当 verifier，但 infra 成本（异步/一致性/信用分配）极重。**
4. **美团在线推理 RSI 最相关的参照系＝路线 3＋路线 1 的机制组合。**

用已会锚做机制注脚（把综合判断落在你会的事实上）：

- **第 1 句**＝gate/信号分离**天然成立**：正确性 gate 二值、不可权衡；吞吐/延迟是连续性能信号。且测量**可重复**→第 2 课判真协议全套上得去。两失败模式都有明确暴露面——「稳」稳在 verifier 的物理学。
- **第 2 句**＝第 1 课 OOD 缩水：benchmark 分当唯一选择压力 → 基准特有模式被奖励（RRSI 存在理由）；「可信度问题」＝benchmark 可被 hack（危机三篇）＋路线 2 无 head-to-head。
- **第 3 句**「信用分配」＝reward 侧判真难题：计时直接告诉你快了多少，奖励不告诉你**哪一步**挣来的——判真协议在奖励侧没有直接对应物。
- **第 4 句**：你昨天认知强制**没答**「美团最相关」问——没有 pre-anchor，正好第一次接触就是综合判断原形。R 的理由可机制化读出：路线 3 给**场景与生产级 verifier**（你的主场），路线 1 给**机制**（进化搜索/程序数据库/判真协议——已学四课）。但「最相关」是投入方向判断——values 已裁决 5 条里**没有**它。第 21 课你要交自己的版本。

## 8｜Gaps 空白图＝机会清单

R 尽调完留了空白图。本课的原创视角：**把 Gaps 读成机会清单，不是缺陷清单**——空白显性化，就是 mission「原创性想法」的候选位。三条主空白＋机会形态：

1. **面向在线推理 infra 的 RSI 无直接对标论文**——z.ai 是唯一生产级叙述（且官方自认非 RSI、人类保留裁决），FlashInfer-Bench 提供闭环骨架；美团空白＝机会，也＝无可直接引用的先例。机会形态：**综述的显性空白即贡献点**——你的翻译杠杆现成（在线/离线测量差异、灰度可信度、到达分布）。
2. **评测对策的组合实践空白**——危机三篇对策（源码审计/独立计时/SOL 锚定）× agent 侧防 hacking（RRSI critic）的组合，无公开系统完整示范。机会形态：**美团 verifier 抗 hacking 设计清单**——第 6 课正面教，原创系统设计的承重件。
3. **路线 2 head-to-head 缺失**——FlashRSI 矩阵是唯一统一入口，且逐表核对未完成（R R7）。机会形态：**「无横评」现状的呈现即综述贡献位**。
