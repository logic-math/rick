## ① 发生了什么

- N 阶段已收敛：主要矛盾 = M1+M4 并置；X = 继续基于 pi 开发 + runtime 重评悬置（唯一撤销条件 = Y1 功能阻塞，长期触发 = Y2 层 B 骨架替换）；Y = 双循环五环节操作化定义（human-loop 判断 → plan 细化判断 → doing 执行 → learning 落盘 → dream 统一回收判断轨迹+行为轨迹，持续进化）。[循]judgment.md S 门禁 3/4 轮+N2
- 本阶段提出**逆转命题**：「若 X 必然，则 Y 应当___」。research 的首项事实判定：X 与 Y **直接交集为空**（Y 不要求换 runtime）；5 处阻碍 = 4 处 Y 自身缺失实现（node×2 + edge×2）+ 1 处 X 的间接税（edge rick↔pi）。
- 「悬置期可并行处理 vs 必须解决」的调研答案：**没有一处可以永远绕开**（它们是 Y 的定义性缺失），**也没有一处必须先解除悬置才能动工**——全部可在悬置期并行建设。真问题不是「能不能」，而是「改造量与带宽」。
- think 的组合判断（观点，非事实）：F2+F4+F5 他洽/续洽最好，F1 是悬置期可独立先行的第一块，F3 防御场景仅剩 Y2；但组合的隐含前提 = 三块改造（dream 重写 + plan 判断化 + 每 loop 微 AAR）**总价未计价**——X 只省了 runtime 切换成本，没省 Y 的任何自建成本（H2）。
- 门禁遗留 Q1-Q5 处置位置已定：Q2/Q4 被 F2+F4+④+⑥+⑦ 实质缓解；Q3 事实侧已裁决（plan=规定性）；Q1/Q5 无路径天然解决，收敛进 H1/H2/H3——**最大遗留仍是悬置对象与恢复条件**（H3）。

## ② 这个领域的知识是什么样子

### 2.1 辩证逆转的教学：为什么「若 X 必然则 Y 应当如何」优于「如何消除 X」

**两种问题形式在结构上不同，差异从 X 的身份开始。**「如何消除 X」把 X 当作待清除的障碍——它预设 X 是错误、病灶、终将离去之物。但本 loop 的 X 不属于这一类：**pi 稳定假设是 human 三轮拍板（S 门禁 3/4 轮+N2）选出的前提**，不是待验证假设，更不是闯入的故障。对已选前提发动清除战，实际是在对抗自己的既有决策——心理与组织上都是消耗战，且即便「赢」也只是回到「底座未定」的原点（N1 的八态分析已表明那个原点本身也是矛盾态）。

「若 X 必然，则 Y 应当如何」对应辩证法的标准动作——**转化**：不否认约束、不清除约束，而是**创造条件，使约束从阻碍变成资源**。《矛盾论》所表述的「矛盾双方在一定条件下向相反的方向转化」，其工程翻译是：锁定版本这个「限制」在什么条件下成为「资产」？悬置这个「推迟」在什么条件下成为「窗口」？转换不是修辞安慰：它成立与否可以检验——若找不到任何「只有在 X 之下才成立」的资源，转换就是空话；若找到了，X 的存在本身就变成 Y 的建设条件。

**X 实际提供哪些 Y 用得上的资源**（教师基于 research ①/⑧/⑨ 事实的综合讲解；是否值得使用是判断，见 ③ 追问）：

- **资源一：锁版本 = 冻结的契约面 → 判断细化的可靠输入。** 版本锁死意味着 rick↔pi 交互面在观察期内不变，归因因此变干净：任何可观测变化都来自 rick 自身，而非 pi 的行为漂移。测量学上这叫**控制了混杂变量**——「plan 细化判断」需要的恰恰是这种可靠输入（判断所引用的输入若自身在漂移，判断的可追溯性就失效）。注意这是事实陈述（锁版本确实提供稳定契约面），不是价值判断——M4 的迁移跨度代价照常计价（teach-N2 2.2），两件事同时为真。
- **资源二：悬置 = 无新漂移的窗口 → schema 建设期。** research ⑨-3 确认 plan 消费 judgment 的 schema 不存在，需要新建。schema 设计的敌人是移动靶：若 pi 的 12 钩子/扩展面持续变动，为判断记录设计的结构会反复返工。悬置期内靶子固定——这恰是 schema、契约枚举（F1 的 128 方言点静态扫描）、度量定义（F2/X6）这类「一次性重投入、长期复用」建设最好的窗口。
- **资源三：X 定底座 → Y 的建设全部落在自己控制的领地。** X∩Y=∅（research 事实判定）意味着五处阻碍里四处是 rick 自身代码/仪式的缺失——改造不需要与上游（pi 维护者）谈判，不等任何外部条件。第五处（128 方言间接税）是唯一与 X 相关的，而 F1 对它的处置（枚举+断言）同样不需要上游配合。

**诚实的账（think H2，观点）**：上述资源是「可用的输入」，不是「完工的工作」。X 省掉的只有 runtime 切换成本；Y 的全部自建成本（plan 判断化、dream 重写、耦合回路、仪式建设）一分未付。逆转提供的是**方向**（借力而非对抗），不是免费午餐——把资源用掉仍要花带宽，这正是 H2 要追问的。

**填空命题的合格线**：「若 X 必然，则 Y 应当___」的空格，任何合格填法必须同时满足三条：①不要求 ¬X（不偷偷假设换掉 runtime）；②真能到达 Y（不是安慰性的「也可以过得不错」）；③与 X 的约束相容（不与锁版本/悬置冲突）。research ② 的 F1-F5 是五种不同填法，2.3 逐一讲。

### 2.2 五处阻碍的逐一讲解：它们在系统中的位置与改造性质

先给定位表（research ①，全部可溯源）：

| # | 定位 | 对象 | 现状（事实） | 缺什么 |
|---|---|---|---|---|
| 1 | node | plan | 输入=需求+domain+loops，输出=任务分解（模块化/粒度/可验证/依赖四原则）[码]internal/prompt/templates/plan.md | 无判断结构化输入 |
| 2 | node | dream | 共 91 行：待回收 job 扫描+prompt 生成+agent 写日志 [码]internal/handler/dream.go | 判断回收/度量/巡检三重负载全为规划 |
| 3 | edge | human→dream | M1（终审带宽）+M3（判断以天计）在唯一双轨迹汇聚点叠加 [循]think-gate-N2 Q2 | 汇聚点的通道容量设计 |
| 4 | edge×2 | 判断↔行为 | 两条回路（判断→行为、行为→判断）均无机制 [循]think-gate-N2 Q4 | 耦合机制本体 |
| 5 | edge | rick↔pi | 悬置期 128 处方言继续膨胀（M4/M8）[循]teach-N1 2.1.3 | 方言变化与系统进化的可区分性 |

**node 与 edge 的区分不是术语游戏。** node 的阻碍是「环节内部的变换缺失」——环节存在，但变换不对（plan 会做分解、不会消费判断）；edge 的阻碍是「环节之间根本没有连线」——机制缺失。改造性质因此完全不同：node 改造是既有代码上的**加法**（plan 加判断输入块、dream 加回收逻辑），edge 改造是**从零建线**（两条耦合边）或**重设通道容量**（human→dream）。计价方式随之不同：加法可以估行数/字段数；建线要估协议+参数——⑨-5 的要点即在此：耦合回路的增益/延迟参数**无先例可移植，只能实验标定**。

**阻碍 1：plan 无判断输入——「描述性 vs 规定性」的差距。** 这是门禁 Q3 的裁决结果，这个区分本身值得讲透。「plan=细化判断的过程」有两种读法：**描述性读法**主张「现有 plan 实现已经在细化判断」；**规定性读法**主张「plan 应当细化判断，但现在还没有」。research ⑤ 已做事实裁决：现模板的输入输出中**没有任何判断字段**（无判断 ID、无所虑选项、无预期结果+概率、无回收时点）[码]。描述性读法不成立，这是规定性（目标态）。含义：这不是 bug 修复而是**功能新增**，且其前置（judgment 的 schema）不存在（⑨-3）。research ⑤ 列出四个改造候选：
- **P1 判断引用块**：plan 模板加字段（判断 ID/所虑选项/预期结果+概率/回收时点）——决策日志模式（Mauboussin；Kahneman 倡导）。
- **P2 ADR 块**：context/decision/status/consequences 内嵌 plan（Nygard 2011；MADR 变体）。
- **P3 意图式计划**：plan=意图+约束，执行侧自适应（德军 Auftragstaktik 任务式指挥；美 ADP 6-0）——think 评注「细化判断」语义最接近的形态（观点）。
- **P4 生成器**：judgment.md 条目 → plan 约束/验收标准的自动生成（决策日志驱动开发）。
先例佐证：ADR 已制度化（adr.github.io；Fowler bliki）；决策日志+事后打分用于校准训练有预测锦标赛实践支撑 [文]。

**阻碍 2：dream 现状 91 行、无任何回收度量。** 这是最需要「事实先于想象」的一条：N2 拍板赋予 dream 三重负载（判断回收+行为量化+统一进化引擎），而 [码]dream.go 的全部现实是「扫描待回收 job → 生成 prompt → agent 写日志」，共 91 行——无判断回收代码、无度量代码、无巡检代码。教学上这个数字的意义是**体量校准**：被讨论当作系统拱顶石的「进化引擎」，当前重量是 91 行的日志生成器。这不是批评（规划中负载本来就要新建），而是计价起点：阻碍 2 的改造性质是**从零新建**，不是改造——它与阻碍 1（加法）的工程性质不同，H2 计价时须分开算。

**阻碍 3：human→dream 单点。** 结构原因：dream 是五环节中**唯一同时接收两条轨迹的汇聚点**，而 M1（human 终审带宽有限）与 M3（判断以天计）恰在此叠加——两个最慢的约束压在唯一汇聚点上，这就是「单点瓶颈」的精确含义。注意它是 edge 问题（通道容量），不是 dream 本身的问题（dream 的 91 行不构成瓶颈，瓶颈在进入 dream 的人审通道）。解法因此是通道工程：2.5 的七种汇聚设计模式全部是对这条 edge 的回答。

**阻碍 4：两条耦合边缺失。** 已拍板的三维向量（正确率/赔率/影响）+四指标度量的是**各轨迹自身**；判断如何改变行为、行为如何反馈改变判断框架——两条回路均无机制（[循]gate-Q4）。没有这两条边，「双循环」实际是**两本并行台账**（判断账+行为账），各自可查但不互相作用。理论语法已存在（2.4/⑥：双环学习/级联控制/RLHF 聚合/模板回路/校准环），但任何一条的增益/延迟参数都只能实验标定（⑨-5）——X6 校准实验是第一个实验位。

**阻碍 5：128 方言间接税。** 这是唯一源自 X 的阻碍：悬置期内 rick 对 pi 行为方言的依赖点（128 处）继续膨胀（M4/M8）。真正的危险不是数量而是**不可区分性**：若 Y 的进化以 pi 方言表达（「我们改进了 X 的处理」=改了某处方言依赖），则一次「改进」与一次「漂移」在代码里长得一样——进化声明变得不可检验。这就是阻碍 5 与 2.6 进化/漂移判据耦合的原因，也是 F1（枚举+断言）存在的理由。F1 的前提（128 点静态可枚举）未验证（⑨-6）。

**综合：「悬置期可并行」还是「必须解决」——调研的答案是两者皆是，层次不同。** 五处阻碍作为 Y 的定义性缺失，**没有一处可以永远绕开**（绕开任何一处，Y 就少一环）；但五处也**没有一处与悬置互斥**——不需要解除 X 才能动工，全部可在悬置期并行建设（这正是资源二的窗口含义）。所以真正的问题从「能不能」变成「改造量与带宽」：三块大改造（plan 判断化/dream 重建/耦合回路）+两块中等改造（汇聚通道/方言契约）的总价，能否在悬置期与 pi 迭代并行吸收——这是 think H2 的问题，属判断性，见 ③。

### 2.3 五条逆转路径候选的教学（F1-F5）

每条路径按同一结构讲：**第一性原理**（它把 X 的什么约束转化为 Y 的什么资源）→ **适用/不适用条件**（research 原注）→ **融贯性**（think ② 的自洽/他洽/续洽分析，观点）→ **隐含前提**（think ①，观点）。五条路径回答的是同一个填空，但押注在不同的资源上。

**F1 工程契约路径：「Y 应当把 rick-pi 耦合固化为可执行契约」。**
- 第一性原理：把「隐式依赖」变成「显式资产」。128 处方言依赖现在是隐性知识（散在代码里，无人能完整说出）；F1 用协议清单+消费者驱动契约测试+静态规则（semgrep/eslint 枚举 128 点）把它变成**可机器断言的不变量**，再用 canary 升级跑契约套件。锁版本（X）在这里是前提资源：契约断言的对象是一个**冻结面**，断言才有确定含义。
- 来源：Pact 消费者驱动契约；《Building Evolutionary Architectures》（Ford 等，2017）fitness functions [文]。
- 适用：可枚举、可断言的接口。**不适用：涌现性行为效果**——契约能断言「调用了什么」，不能断言「行为好不好」（涌现效果仍归 human 终审）。
- 融贯性（think，观点）：自洽√；他洽△（与 human 终审拍板是**分工不是替代**，须显式说明）；续洽√（S8 恢复信号依赖它——见 2.7）。
- 隐含前提（think，观点）：128 点静态可枚举（⑨-6 未验证）；断言止于接口层；契约维护成本<悬置收益。

**F2 度量路径：「Y 应当把双轨迹度量做成自动聚合+抽样审计+human 只审摘要」。**
- 第一性原理：把 dream 的审阅负担从「全量 human 注意力」改为「统计过程管理」——机器做聚合（固定窗口控制图），抽样做审计，例外才上报 human。X 在这里的贡献是间接的：pi 面冻结使指标归因干净（资源一），度量定义有稳定靶子（资源二）。
- 来源：审计统计抽样（AICPA）；SPC 例外管理；Google SRE 复盘只追 action item [文]。
- 适用：大批量+指标定义已稳定。**不适用：早期小样本**（research 原注——这条自注正是 H4 的根据）。
- 融贯性（think，观点）：自洽√；他洽△（与 Y4 拍板「周/月环比小样本起步」冲突，需分阶段）；续洽√（M1 的主解）。
- 隐含前提（think，观点）：指标已稳+样本已足；摘要器可信（未经审查的新假设，Goodhart 风险）；抽样误差可容忍。

**F3 协议中立层路径：「Y 的全部功能只依赖 runtime 中立层」。**
- 第一性原理：让 X 的具体选择（pi）退化为可替换的实现细节——seam/端口适配层隔离 pi 方言，Y 建在中立接口上。这是唯一一条「对冲 X」而非「利用 X」的路径：它不为 Y 提供资源，而是为「X 被撤销」提供保险。
- 来源：Cockburn 六边形架构（2005）；rick 已有 Runtime seam（[循]research-N1，这是既有资产）。
- 适用：接口面可抽象。代价：适配层**双写维护**（每次 pi 方言变化，中立层+pi 适配各改一遍）。
- 融贯性（think，观点）：自洽√；他洽×→△——关键事实：dsh 已排除、web ui 走 pi 扩展，F3 防御的切换场景**仅剩 Y2（层 B 自研）**；与 S 阶段「runtime 无关长期期望」一致，但服务对象须澄清，否则是为已排除的未来付保费。
- think 的处置意见（观点，非本简报建议）：F3 降级为 Y2 触发后的选项，现在不投。

**F4 组织分布复盘路径：「回收仪式分布化」。**
- 第一性原理：把回收从「一次大型集中仪式」（dream 全量终审）改为「多次小型分布仪式」（每 loop 微 AAR+定期汇总，dream 只做终审聚合）。它解的是 M3：刻意练习的「即时反馈」条件（见 2.4）要求反馈延迟以分钟计，而集中式终审以天计——分布化把反馈移到产生点。X 的贡献同样是资源一/二：pi 面稳定期间，微 AAR 复盘的对象（自身行为）归因干净。
- 来源：美军 AAR TC 25-20（1993-09-30，TRADOC）；敏捷回顾 [文]。
- 适用：高频低延迟反馈。不适用：需全局统计的判断打分（分布复盘做不了跨 loop 校准——那仍是 dream/聚合的活）。
- 融贯性（think，观点）：自洽√他洽√续洽√——与 X5 拍板兼容：只前移回收，dream 仍聚合，判断归属不变。
- 隐含前提（think，观点）：微 AAR 不被 doing 压力跳过（Toyota Kata 失败模式）；局部复盘可聚合。

**F5 学习系统路径：「判断轨迹=校准训练信号，行为轨迹=经验/技能库，dream=经验汇合点」。**
- 第一性原理：把两条轨迹从「待审记录」升格为「可重放的学习素材」——判断轨迹带预测、事后解析、产出校准曲线（校准训练）；行为轨迹沉淀为可复用技能/经验条目（技能库）；dream 是两者汇合固化的地方。这是与已拍板上下文主义最同构的路径——F5 即「判断作为上下文被记录并复用」这一信仰的实现机制（think 观点：续洽最高）。
- 来源：Reflexion（NeurIPS 2023，arXiv 2303.11366）；Voyager 技能库（arXiv 2305.16291）；ExpeL（AAAI-24，doi 10.1609/aaai.v38i17.29936）[文]。
- 适用：轨迹可结构化重放。**前置最重**：schema 必须先存在（⑨-3：现在不存在）+ 判断样本密度必须够（H1）+ Goodhart 可控。
- 融贯性（think，观点）：自洽√他洽√（上下文主义+三维向量+X6 直接衔接）续洽最高——**但全部押在 H1 前置上**。

**五条路径之间的依赖箭头（事实/分析，选型时必须看见）**：S8 恢复信号依赖 F1 先行落地（契约套件不存在，canary 失败无从谈起）；F5 依赖 schema 先建（H1）；F2 依赖指标稳定+样本量（H4，可分阶段缓解）；F1 依赖 ⑨-6 可枚举性。think 的组合结论（观点）：F2+F4+F5 他洽/续洽最好，F1 是悬置期可独立先行的第一块。组合与否、如何排序，是 ③ 追问 8 的判断题——本简报不替你选。

### 2.4 双循环系统的先例：它们的结构与 rick 五环节的映射

为什么学先例：F1-F5 不是凭空设计，每条背后都有运行多年的同类系统。先例的价值不在「照抄」，而在**看清成功条件与失败模式**——失败模式尤其重要，它们是 F1-F5 隐含前提的经验证据。

**预测锦标赛 / Good Judgment Project（Tetlock；IARPA ACE 2011-15）——与三维向量最近的先例。** [文]
- 结构：预报员对问题给出概率预测 → 定期解析打分（Brier 分=正确性）→ 校准曲线（说的 70% 把握的事是否 70% 发生）→ 更新频率记录；定期打分+反馈闭环驱动改进。
- 映射：human-loop（判断登记=预测注册，带概率与回收时点——恰是 P1 判断引用块的字段）→ dream（解析+打分+校准曲线=已拍板 X6 实验对应物）；三维向量（正确率/赔率/影响）中正确率与赔率可直接借用 Brier/校准的量化语法。
- 成功条件：定期打分+反馈闭环。**失败模式：单判断样本稀疏、指标博弈**——这正是 H1 对 F5 的担忧来源：human 判断以天计（M3），稀疏样本恰是 GJP 已知的坑。

**美军 AAR（After Action Review，TC 25-20，1993）——双轨迹同场复盘的原型。** [文]
- 结构：标准化四问复盘——计划是什么/实际发生什么/为什么有差异/下次怎么改；关键设计是**计划 vs 实际（行为轨迹）与指挥员决策（判断轨迹）在同一张桌上复盘**，且教训要**改条令**（不是记完就完，要改下一轮的制度）。
- 映射：doing→learning 的微 AAR（F4 的仪式本体）；「教训改条令」映射到 rick = dream 复盘结论改写下轮 plan 模板/检查单——这正是缺失的「判断→行为」耦合边的制度化形态（research ⑥ 模板回路）。
- 成功条件：标准化问题+心理安全+教训有人认领。失败模式：沦为打卡仪式、教训无人认领。

**刻意练习（Ericsson 等，1993）——「持续进化」的心理学判据来源。** [文]
- 结构：进步只在三个条件同时满足时发生——**任务明确+即时反馈+难度适配的重复**。缺任一条即「天真练习」：有活动量、无进步（平台期）。
- 映射：五环节=重复的结构（每 loop 一轮）；微 AAR=即时反馈条件（F4）；三维向量+预注册预测=任务明确化；难度适配=loop 难度的选择。**「进化 vs 漂移」判据的原始直觉即来自此**：Y 若只有仪式没有三条件，就会退化为准时打卡的天真练习。
- 成功条件=三条件齐备本身；失败模式=天真练习平台期——这是 Y 最隐蔽的失败形态（一切照常运转、什么都没进化）。

**RLHF（Christiano 2017；Ouyang 等 2022）——判断→行为耦合边的先例与警告。** [文]
- 结构：human 判断（偏好排序）→ 聚合器（奖励模型）→ 驱动行为（策略优化）。这是「判断轨迹系统性改变行为轨迹」最著名的工程实现——正是 rick 缺失的第一条边。
- 映射：判断（human-loop）→ 聚合（dream 度量/摘要）→ 行为（plan 模板/检查单更新）。
- **失败模式：reward hacking / Goodhart——代理指标变成目标后，系统优化指标而非意图**。对 rick 的直接警告：F2 的「自动摘要器」和 F5 的「校准信号」都是聚合器，都携带 Goodhart 风险（H4 的「摘要器可信是未经审查的新假设」即指此）。

**其余四例（简讲）** [文]：Toyota Kata（Rother 2010）=每日改善循环+教练环，行为-元认知双环制度化，失败=产线压力下教练环被跳过（F4 的风险原型）；SRE 无责复盘（Google SRE Book 2016）=行为轨迹→系统变更，失败=action item 无主而复发；Quantified Self（2007 起）=自我量化，**失败=只采不用的数据坟场**，成功=每个指标绑定一个具体消费决策（对 dream 度量设计的直接教训）；PKM（Zettelkasten+Anki 间隔重复）=知识轨迹定期回收，dream 的形态近亲，失败=收藏癖无输出。

**共性归纳（research ③）**：成功系均有三件套——**固定回收仪式+结构化记录+反馈到下一轮的显式通道**；失败集中于三种——**仪式空转、反馈不闭环、指标被博弈**。这张清单可直接当 Y 的验收清单用：任何 F 组合最终都要长出这三件套，否则落入三种失败之一。

**五环节 × 先例映射总表**：

| rick 环节 | 最近先例 | 借来的结构 | 对应失败模式 |
|---|---|---|---|
| human-loop（判断） | GJP 预测注册 | 带概率+回收时点的登记 | 样本稀疏 |
| plan（细化判断） | 任务式指挥/决策日志 | 意图+约束+预期结果 | 计划与判断脱节 |
| doing（执行） | 刻意练习 | 难度适配的重复 | 天真练习 |
| learning（落盘） | SRE 复盘/AAR | 结构化记录+认领 | action item 无主 |
| dream（汇聚） | AAR 改条令+GJP 打分+QS | 聚合+校准+教训改模板 | 数据坟场/Goodhart |
| （缺失边：判断→行为） | RLHF/模板回路 | 聚合器+模板更新 | reward hacking |
| （缺失边：行为→判断） | 双环学习 Argyris 1978 | 规范本身被审视 | 只单环纠偏 |

### 2.5 dream 汇聚的七种设计模式——单点风险的工程解法

阻碍 3（human→dream 单点）之所以不是死局，因为这个形状的问题在软件工程史上有整套解法。七种模式（research ④），每种讲原理+代价：

1. **事件溯源+CQRS**（Fowler 2005/Young 2010）：轨迹 append-only 作为唯一事实，读模型/投影**异步**构建——dream 不必同步等 human，只维护投影。适用：轨迹不可变可重放；代价：投影滞后（看到的是稍旧的聚合）。
2. **日志中心化**（Kreps《The Log》2013）：生产与消费解耦，消费方自定步调——human 终审被移出在线路径（不阻塞任何环节）。
3. **数据湖/lakehouse**（Inmon；Armbrust CIDR 2021）：原始数据先落盘，schema-on-read，聚合延后——适用于**度量定义未稳期**（正是当前：X6 未跑、指标在变），避免为还不稳定的定义提前固化管道。
4. **审计抽样+重要性阈值**（AICPA）：全量→抽样，超阈值才上报 human——适用于 human 时间稀缺；前提：抽样误差可容忍（F2 同款前提）。
5. **自动聚合+例外上报仪表盘**（平衡计分卡 Kaplan&Norton 1992；数据可观测性告警）：human 只看摘要+异常——F2 的机制本体。
6. **数据 mesh**（Dehghani 2019）：聚合权下放各域，消中心瓶颈——适用于域自治成熟后（对 rick=各 loop/环节自聚合，dream 只收域摘要）。
7. **仪式化时间盒**：固定 cadence+模板限带宽——与已拍板 5-job 窗口直接兼容（这是唯一一种不需要写代码的模式，纯组织设计）。

**单点问题的组合解（教学综合）**：这七种不是互斥选项，而是可叠加的层——例如「append-only 轨迹（1）+异步投影（1/2）+例外才上报（4/5）+固定 cadence（7）」叠加后，dream 从「human 必须逐条过的关口」变成「维护投影的聚合服务」，human 从吞吐瓶颈变成**例外处理器+终审者**——带宽需求从 O(轨迹量) 降为 O(异常量+摘要量)。这正是 gate-Q2 所要求的「dream 量化被设计为异步/抽样/自动聚合的机制草图」的完整形态。

**但要注意 H4 的边界（think，观点）**：模式 4/5 的前提（指标稳+样本足+摘要器可信）在早期不成立——Y4 拍板的是小样本周/月环比，X6 未跑。故若走此路，现实形态是**分阶段**：早期全量+human 体感（已拍板保留），度量定义与样本量成熟后再切抽样+例外。分不分阶段、阈值在哪，是判断（H4）。

### 2.6 进化 vs 漂移：六种判据——「持续进化」的操作化

Y 的定义词「持续进化」若不配判据，就是不可证伪的口号：任何变化都能被追认为「进化」。六种判据（research ⑦），各给不同的操作把手：

1. **SPC 控制图**（Shewhart 1931；Nelson 规则 1984；CUSUM Page 1954/EWMA Roberts 1959）：统计上区分**共因变异**（系统常态噪声）与**特因变异**（真变化）；CUSUM 对小漂移敏感。适用：窗口化指标——Y4 拍板的周/月环比**直接可用**；前提：样本量足够（又见 H4）。
2. **预注册预测**：每次变更登记预期效果+方向；事后对照——**进化=预测实现，漂移=未预期变更**（Toyota Kata 目标条件模式）。这条最便宜（只是纪律，不是基础设施），且与 P1 判断引用块的「预期结果+概率」字段天然同一——登记判断的同时就完成了预注册。
3. **回归基准重放**：固定任务套件定期重跑，比较表现——直接复用已拍板的「测评基线降级为环境监测项（选 B）」，零新增决策。
4. **Goodhart/Campbell 定律**（Campbell 1979/Goodhart 1975）：纯指标进步声明须配定性复核——已拍板保留的 human 体感在此获得结构性角色（不是怀旧，是判据 4 本身）。指标与体感互补，不是冗余。
5. **CMMI 阶梯**：过程定义→度量→优化作为进化阶段判据——可用于判断 rick 当前在哪一级（有过程定义、度量刚起步）。
6. **Ashby 必备多样性**（1956）：**进化=可应对的扰动类别实际增加，而非活动量增加**——最锋利的一条：跑了一百个 loop 是活动量；能应对的扰动种类没变就是没进化。

**教学要点**：六条互补而非竞争——2/3 是事前判据（预测+基准），1/4 是事中/事后统计判据，5 是阶段定位，6 是最终语义。判据 2 与 P1 判断引用块的字段同一，是「一处建设、两处受益」的具体位置（schema 设计时值得看见）。同时判据 4 提醒：判据本身也是指标，也要防博弈。

### 2.7 Y1 恢复信号 S1-S8：悬置的恢复条件候选

**先看一个刺眼的事实（research ⑧）**：悬置是已拍板的控制手段，但 X 的撤销条件（Y1）与协议清单**均未写入 domain**——[码].rick/domain/pi-runtime.md 无任何触发条款，恢复条件现仅存 human 记忆。后果：若 human 不在场/遗忘，悬置没有制度化的解除机制；且 think H3 指出清单方向已是**第三次表态变化**——无条件延迟在实践上等于推翻。

八个候选信号（操作定义，供勾选；来源 research ⑧，先例：Renovate/Dependabot 锁文件+定距升级、Node LTS 生命周期表、Pact 契约门禁 [文]）：

### ③ 启发式追问

**先如实呈上本阶段未消解项（R7×6，均标注「未消解」）**：⑨-1 判断回收的 ground-truth 归属（谁/何时判定判断「正确」，五环节无归属，判断性，必须 human 拍板）；⑨-2 赔率共识基线数据源（Y5 方向已定，subagent 搜网络观点的执行规格未定）；⑨-3 plan 消费 judgment 的 schema 不存在（P1-P4 均需新设计+X6）；⑨-4 dream 带宽无实测（5-job 窗口需 human 实际分钟数未知，单点结论无法定量）；⑨-5 耦合回路增益/延迟参数无先例可移植，只能实验标定；⑨-6 128 方言点静态可枚举性未验证（F1 的前提）。其中 ⑨-3/⑨-5/⑨-6 是事实性可核验项，⑨-1 是纯判断项。

以下追问建立在 ② 已讲清的知识之上：

**追问 1（协议一问·意外路径）**：F1-F5 五条路径分别把 X 转化为工程资源、统计资源、抽象资源、组织资源、学习资源——这五种转化全部来自既有先例的谱系。若 X 不可避免，实现 Y **最意想不到的路径**是什么——有没有第六种转化，不在任何先例谱系里，但满足 2.1 的三条合格线（不要求 ¬X/真能到达 Y/与 X 相容）？
改变判断的证据：一条不依赖 F1-F5 任何先例、但可写出机制草图的填空出现。

**追问 2（协议二问·阻力变推力）**：② 2.1 给出了两个可转化约束的例子（锁版本→稳定契约面→可靠判断输入；悬置→无新漂移→schema 窗口）。反向问：X 的哪个约束是**不可转化的真税**——任何路径都绕不开、只能被计价？（候选：M4 的迁移跨度随锁龄单调上升，teach-N2 2.2——它转化为资源了吗，还是只能进 H2 的总价账本？）
改变判断的证据：为某个「真税」找到被先例消解的同构案例；或确认其无转化路径、只能计价入 H2。

**追问 3（协议三问·逆向工程）**：从 Y 的终点倒推五环节接口——dream 统一量化**需要什么输入**→learning 因此**要落盘什么**→doing 因此**要产生什么信号**→plan 因此**要消费什么判断格式**→human-loop 因此**要什么记录结构**？这条倒推链与 H1（schema 前置）在哪里相遇：倒推出的第一张 schema 草图，字段是否就是 P1 的四字段（判断 ID/选项/预期+概率/回收时点），还是暴露出 P1 覆盖不到的字段？
改变判断的证据：倒推出的接口清单与某个现存机制（ADR 模板/决策日志/GJP 登记表）字段级重合——则 schema 可借用而非全新设计。

**追问 4（H1·schema 前置最重）**：若坚持 F5（判断轨迹=校准训练信号），那么也假设了「judgment 可结构化重放的 schema 已存在或可先行建成，且 human 判断样本密度足以支撑校准」——这真的正确吗？事实侧：schema 不存在（⑨-3）、human 判断以天计（M3）、GJP 的已知失败恰是单判断样本稀疏（② 2.4）。样本密度这个前提，在你对自己的判断频率的体感里，离 GJP 的坑有多远？
改变判断的证据：schema 草图出现+X6 校准实验产出首个校准曲线并声明可接受样本量。

**追问 5（H2·组合总价）**：若以 F2+F4+F5 组合（或任何组合）填空，那么也假设了「dream 重写+plan 判断化+每 loop 微 AAR 的总改造量，可在悬置期与 pi 迭代并行吸收」——这真的正确吗？两块改造量均未计价（阻碍 1/2）；X 只省了 runtime 切换成本（think 观点）。分期路线（先 plan schema→后 dream 度量→后耦合回路）的首期工作量，是否 ≤ 你当前迭代的余量？
改变判断的证据：分期路线图+首期工作量计价，且首期 ≤ 当前迭代余量。

**追问 6（H3·最大遗留：悬置对象与恢复信号）**：若坚持 X 并采 F1/⑧，那么也假设了「悬置对象三选一（①巡检整体不落地/②终审暂免/③完备降级）已隐式选定，且恢复信号清单已写入 domain」——这真的正确吗？事实：N2 拍板原话未含对象与恢复条件；pi-runtime.md 无触发条款；清单方向已是第三次表态变化，无条件延迟=实践上推翻。三个对象的账本完全不同（①M4 计价/②风险黑洞前置/③默示层失守，teach-N2 2.3）——你实际站在哪个对象上？
改变判断的证据：一句话钉死对象+从 S1-S8 勾选信号并令其写入 domain；或显式宣布清单作废（承认推翻）。

**追问 7（H4·自动聚合的前提时点）**：若以 F2 解 dream 单点，那么也假设了「三维向量等指标定义已稳定、样本量已足够、摘要器可信」——这真的正确吗？事实：Y4 拍板=周/月环比小样本起步；X6 未跑；research 自注 F2 不适用早期小样本；摘要器可信是未经审查的新假设（Goodhart）。分阶段（早期全量+体感，后期抽样+例外）是把前提推迟到成立时点的设计——你接受把 F2 拆成两期吗？
改变判断的证据：X6 产出首批统计值且窗口内样本≥阈值；或接受 F2 分阶段的拍板。

**追问 8（路径选择框架，不替你选）**：F1-F5 单选、组合、还是排序？决策时至少要看见三组事实：①依赖箭头（2.3 末）：S8←F1、F5←schema（H1）、F2←指标稳（H4）、F1←⑨-6 可枚举性——选任何组合即隐含接受了它所依赖的前提；②think 的融贯性分析（观点）：F2+F4+F5 他洽/续洽最好、F1 可独立先行、F3 仅剩 Y2 场景；③H2 的总价约束：组合越大，悬置期吸收压力越大。把这三组事实放在一起：你的第一块砖是哪条路径，为什么它而不是别的？
改变判断的证据：给出带依赖箭头标注+首期计价的组合路线图（哪怕只有第一块）。

### ④ 延伸学习指导

本阶段决策（路径选择+悬置对象钉死+H1-H4）涉及三个知识域，各荐材料（只说为什么读，不说你应选什么）：

**辩证法（逆转操作的语法）**
- 《矛盾论》（毛泽东，1937）「主要的矛盾和主要的矛盾方面」+矛盾转化各节——本 loop 全程使用的主要矛盾/转化/主次分析的原文出处；读完你能判断：一个「逆转」是真转化（找到了 X 之下的资源）还是改名（只是换了个说法接受约束）。
- Stanford Encyclopedia of Philosophy，"Hegel's Dialectics" 条目——把「否定之否定/扬弃」放回哲学谱系；读完你能识别工程语境里辩证词汇的误用（例如把「拖着不办」称作「悬置的辩证法」）。

**学习系统（Y 的实现手册）**
- Tetlock & Gardner《Superforecasting》（2015）——GJP 的可操作细节（概率登记/Brier/校准/团队修正）；读完你能判断：rick 的判断样本密度离校准训练的最低要求有多远（H1 的阈值直觉）。
- Ericsson & Pool《Peak》（2016）——刻意练习三条件与天真练习案例的展开；读完你能判断：五环节缺哪个条件、「持续进化」在什么条件下退化为打卡。
- Reflexion（arXiv 2303.11366）与 Voyager（arXiv 2305.16291）论文——F5 的两个源头实验，各约 10-20 页；读完你能判断：语言反馈自改进/技能库增长在 rick 的体量与任务分布上是否成立，还是只在特定 benchmark 上成立。
- Argyris & Schön《Organizational Learning II》（1978）第 2-3 章——单环/双环学习理论原文，两条耦合边的语法；读完你能判断：P1-P4 各属单环还是双环，哪条改造真正触及判断框架本身。

**控制论与度量（耦合回路与判据的数学）**
- Ashby《An Introduction to Cybernetics》（1956，有免费电子版）requisite variety 各章——进化=多样性增加的操作化；读完你能判断：一条「我们在进化」的声明是扰动覆盖的增加，还是活动量的增加（判据 6）。
- Åström & Murray《Feedback Systems》（2008，Princeton，免费 PDF）级联控制/增益与延迟各章——为什么 human 天级延迟的耦合环必须低增益+采样保持（防振荡）；读完你能判断：⑨-5「参数只能实验标定」的必然性，以及 X6 应测什么。
- Deming《Out of the Crisis》（1986）控制图与共因/特因各章——SPC 例外管理的源头；读完你能判断：Y4 小样本窗口使用控制图的边界，以及 H4 分阶段的合理切换点。
- Google SRE Book（2016，O'Reilly 免费在线）postmortem 文化一章——无责复盘+action item 认领的工程制度；读完你能判断：F4 微 AAR 需要哪些制度前提才能不重演 Toyota Kata 式空转。
