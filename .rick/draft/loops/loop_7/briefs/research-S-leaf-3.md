# pi vs dsh：AI agent harness runtime 职责事实对照（仅事实）

pi 源=本地 `…/pi-coding-agent/docs/`（下称 docs/）；dsh 源=deepseek-harness.github.io reference（下称 D=…/en/reference/）与 GitHub deepseek-ai/deepseek-harness。

| 维度 | pi | dsh |
|---|---|---|
| 会话/进程管理 | SessionManager 树形 JSONL（~/.pi/agent/sessions/，entry 以 id/parentId 成树）；/new /resume /fork /clone；SDK AgentSessionRuntime 负责会话替换（newSession/switchSession/fork/importFromJsonl），另有 inMemory 模式。[docs/sessions.md; docs/sdk.md] | Session=append-only SessionEvent 事件日志，唯一事实源，LLM 历史由日志派生；SessionPersistence seam（ctx.sessionPersistence）定义后端契约，含 JSONL 后端、flush checkpoint、崩溃恢复。[D subsystems/session; D subsystems/persistence; D config-catalog] |
| 上下文管理 | 内建 compaction：阈值自动（reserveTokens 默认 16384、keepRecentTokens 20k）+ /compact；/tree 分支摘要；扩展可经 session_before_compact 给自定义摘要或取消。[docs/compaction.md; docs/extensions.md] | compaction 为可选 capability seam（ctx.compaction）；basic 后端 BasicCompactionEngine：ctx.tokenMeter 压力、token 预算保留、一次性 llm.stream 摘要并重放前缀以复用 KV cache；/compact 为 human consumer。[D subsystems/compaction; packages/compaction/compaction-basic] |
| 工具执行/自定义工具 | 内建 read/bash/edit/write(+grep/find/ls)；SDK defineTool 与扩展 pi.registerTool 注册自定义工具；tool_call 钩子可 block/改参，tool_result 可改结果；并行工具执行。[docs/sdk.md; docs/extensions.md] | 工具 registry 本身是插件，工具注册进 ctx.tools；bash 执行为独立 seam，多执行器（bash-local/bash-sandbox/terminal-bash）。[D reference/; D capability-seams] |
| Subagent/扇出 | 无内建 subagent；SDK 用例明确"custom tools that spawn sub-agents"，即由调用方建子 AgentSession；另有 fork/clone+sendUserMessage 会话交接模式。[docs/sdk.md; docs/extensions.md] | ctx.subagents 按名注册多后端：subagent-inprocess、subagent-acp、subagent-codex、subagent-claude-code；subagent 是可选能力，不在 agent-loop 脊柱内；examples/headless-agent 含 subagent delegation+workflows 组合。[D subsystems/subagent; D capability-seams] |
| 扩展/插件 | TypeScript 扩展（jiti 免编译），自动发现 ~/.pi/agent/extensions 与 .pi/extensions；registerTool/Command/Shortcut/Flag/Provider；覆盖 session/agent/tool/model/provider 全周期事件钩子；appendEntry 存跨重启状态。[docs/extensions.md] | Cordis 框架：一切皆插件（模型适配器、工具 registry、session log、agent loop 均可由配置替换），无特权核心；注册是可逆 effect，插件卸载即回滚。[D reference/] |
| 无头集成 | 三通道：pi --mode json（stdout 单向 JSONL 事件流，JsonAgentSessionEvent）；pi --mode rpc（stdin/stdout JSONL 双向命令+事件，含 extension UI 请求/应答子协议）；SDK createAgentSession 同进程嵌入。[docs/json.md; docs/rpc.md; docs/sdk.md] | npx @deepseek-ai/dsh web（Web UI，127.0.0.1:3080）；dsh --profile headless "task" 一次性运行（headless-runner 插件，不挂 Host/HTTP/浏览器）；dsh --profile 组合 bundle patch 层。[GitHub README; apps/cli/README.md; packages/bundle/headless] |
| MCP | 所读 6 份官方文档均未提及 MCP。[docs/extensions.md 等] | @deepseek-ai/dsh-mcp-client：连外部 MCP server，把其工具注册进 ctx.tools，命名 mcp__<server>__<tool>，支持 stdio 与 Streamable HTTP(SSE)。[deepseekdocs.com/en/docs/features/mcp; D config-catalog] |
| 沙箱与审批 | 无内建审批/沙箱；官方模式=扩展做 permission gate（tool_call block + ctx.ui.confirm）；另有 project_trust 项目信任流程（trust.json）。[docs/extensions.md] | 审批 seam ctx.approval：ask/never 每会话策略、ACP 自动化桥给机器决策、消费方 fail-closed；沙箱 seam dsh-sandbox-local：Linux bwrap/Landlock、macOS Seatbelt、Windows ACL 受限令牌，SandboxMode 只管文件系统效应。[D subsystems/approval; D subsystems/sandbox] |
| Planning | 无内建规划工具；todo 列表属扩展示例（stateful tools 用例）。[docs/extensions.md] | 三层：ctx.goals（跨轮目标）、ctx.jobs（后台任务）、todo_write 工具（每次全量替换列表，todo/write 事件入 session log，重放取最新）。[deepseekdocs.com/en/docs/features/goals-tasks; packages/todo/tool-todo] |
