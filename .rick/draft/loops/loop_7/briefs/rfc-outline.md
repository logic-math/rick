## 第一章 结论区——三个核心判断（终态）

定位：RFC 的裁决输出。逐条锚定 EC 原话「我已经下了结论，runtime 的技术路线，rick 的产品价值，以及双循环的度量体系」；其余章节均为本章的证据与展开。

- 1.1 判断一·runtime 技术路线：基于 pi 继续演进；dsh 直接排除（「牺牲隔离性的自改进是不可取的」）；长期期权=fork pi 或完全自研（自研论证：社区组件复用假设可能不成立+按需生成扩展）；runtime 重评悬置+「pi 足够未来 3 年迭代预期」假设。
- 1.2 判断二·rick 产品价值：human-ai 双循环进化五环节操作化定义（human-loop=下判断／plan=细化判断／dream=回收判断并量化／plan→doing→learning=行为轨迹落盘／dream=统一双轨迹持续进化）+ S-R 逆转=学习系统（ai 辅助 human 学习→加速判断→解除带宽瓶颈）。
- 1.3 判断三·双循环度量体系：三维向量（正确性＞赔率＞影响力，附子判断等价论证）以统计值（中位数/max/均值）分列独立优化；赔率=共识概率倒数；P1 四字段；dream 5-job 窗口回收；X6 实验前置；反共识=human 自评（短期）+Y5 网络共识信号并行、冲突上报 human。
- 材料来源：judgment.md（S 门禁 r2/r3、N2、S-R、EC 节）；teach-EC ①节演进链末态。

## 第二章 事实基础区——判断所依据的事实资产（20 项）

定位：loop_7 全部事实沉淀的分域归档，每项带原始来源与信源等级，供 domain 与后续工程直接引用；事实与判断严格分离。

- 2.1 pi/dsh 对比事实资产：pi loop 源码考古（L1 552 行双层 while+12 钩子封闭清单+handler 级隔离；loop 可替换与故障隔离为正交维度）+模板耦合面量化（128 方言/19/30 文件/compaction 0 处）+bus factor 与生态；dsh 故障实测下限 ≥35 条（boot 全树事务/级联卸载/组合盲区 PoC 未合入上游）+独有能力三层清单（3 结构性/7 生态位/4 程度/1 无差异，rick 8 定制点对 loop 替换零命中）+developer preview churn 现状。
- 2.2 判断力度量方法学：proper scoring rules（Brier/对数分严格 proper）+Murphy 三项分解；N=1 纵向工具箱（Beta-Binomial 收缩/SPRT/SCD ABAB/IRT 难度归一）；三项连乘的数学问题（偏离 proper 范式/EV 加性/激励虚报影响力）与「分数+影响力」分列共识；小样本统计量性质（mean 崩溃点 0/median 近无信息/max=尾部信号/三维独立优化为待检验假设）。
- 2.3 双循环先例与判据：八类先例（GJP/AAR/刻意练习/RLHF/Toyota Kata/SRE/Quantified Self/PKM）成败条件+成功三件套（固定回收仪式+结构化记录+显式反馈通道）；进化 vs 漂移判据六种（SPC/预注册/基准重放/Goodhart/CMMI/Ashby）；benchmark 生态（harness 方差≥模型方差多源量化/SWE-bench Verified 退役/TB2.1 冲突未归因）；语义巡检自动化无工业先例。
- 2.4 系统结构事实：M1-M8 八矛盾态与三维打分；五处阻碍定位；F1-F5 与依赖箭头；X∩Y=∅（双循环目标不要求换 runtime）；dream 汇聚七设计模式；judgment 消费 schema 不存在。
- 材料来源：teach-EC ②节 20 项资产总账（逐项回链 research-S/extra 系列、think 系列、teach-gate 系列）。
