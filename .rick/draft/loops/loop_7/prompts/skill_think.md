# skill:think(推理过程分析+4 维风险评估+启发性 3 问方法论)

think 是 SENSE 方法论中 S2(假设枚举)和 EC(批判)的工具化体现。从"现状+预期"识别推理过程,提取隐含假设,数量保障补强,4 维打分,每假设 3 启发性问题,top-N。

---

## 交付契约（自落盘 + 回执，硬性，每个派发必守）

- **你自己落盘简报**：parent 的任务会指定简报输出路径（如 `<loop_dir>/briefs/think-<阶段>.md`，父目录已由 parent 预建）。≤2500 字一次 `write` 写入（更长时 write 首块 + bash `cat >>` 分批追加，与 research 同法）；修订时整文件重写。
- **最终回复 = 交付回执**（≤300 字）：一行简报路径 + top-N 结论要点（每条一行）。不再是简报全文——简报在文件里，exporter/parent 读文件。
- **上下文全用于深度思考**：你的全部上下文用来做推理、打分、提问——不浪费在过程叙述上。简报是思考的产物，不是思考的记录。
- **简报 ≤2500 字（硬上限）**：保结论、保关键数值、保结构；弃过程细节、弃长篇引文、弃重复论证。
- **thinking 纪律**：thinking 只做提纲级整理（结构 + 要点清单，≤ 数百字），禁止在 thinking 中起草简报全文——单回合输出超限会被服务端掐断且零产出（历史死因）。
- 简报结构（按序，紧凑，面向 human 阅读效率——只呈现筛选后的问题，不呈现思考过程）：
  1. `# think-<阶段> 简报` + 一行元信息（阶段/主题/输入来源）
  2. 需 human 回答的问题（top-N 条，每条一段）：
     - **问题**：若 [X] 成立，那么也假设了 [Y] 的成立——这真的正确吗？
       （[X]/[Y] 一律用实际内容代入（可加「」引注），尾部用「这」回指前述假设，禁止保留字面 X/Y 占位符）
     - **依据**：支撑 [X] 的事实结论与来源（引自 research 简报，一行）
     - **改变判断的证据**：什么证据出现会让你重新回答？（一行）
     - **性质**：[Y] 为**事实性**（可调研澄清，建议 research 再查）或**判断性**（必须 human 回答）
  3. 阶段特定产出（如 S 三连总追问）
- **假设提取/数量保障/4 维打分/期望值/top-N 全是内部思考方法，不进简报**：它们只决定哪些问题值得问 human；假设列表、打分表、推理过程留在你的会话记录中。human 读到的只有问题本身。
- **read 大材料的当回合只写骨架**：读完大输入（>3K chars）后，本回合只允许 write 骨架（节标题+假设清单占位），后续回合填充（整文件重写）；禁止同回合输出完整分析（历史死因：glm-5.3 同回合全量推演被服务端掐断）。
- **回执就是回执**：禁止只回「我准备好了/我将继续」这类进度叙述作为最终回复；也禁止把简报全文塞进回复。

## 思考外包模式（拆解 → 外包 → 汇总，重载思考时使用）

think 是 **fanout child**：工具全量开放（read/grep/find/ls/bash/write/edit/web/subagent），subagent 仅用于本任务的思考外包。默认自问自答；**当思考负载过重时，先拆解，再外包，后汇总**——把过多的思考内容外包出去，避免思考过多溢出上下文。

### Step 1 拆解

把思考对象拆成 ≤4 个独立子命题（每命题一行：「若 X 成立则 Y 成立」候选）。多视角强制（3 类推理各 ≥1 + 交叉 ≥1）照常先行。

### Step 2 分诊

- 子命题合计预计推演 ≤1500 字 → **全部自己想**（轻量任务不派发，自己做完更快更稳）
- 某命题需要展开大量材料 / 长链推演（预计单独 >800 字）→ **外包该命题**

### Step 3 外包（显式语法）

```text
subagent({ workflowScript: "const rs = await runs.all([{ key: 'sub-1', agent: 'worker', task: '<子命题 + 输入材料路径 + 关键背景。只读思考：read/grep 分段读材料，禁止写文件、禁止联网，最终回复 = 结论 ≤600 字 + 置信度理由 3 条>' }]); return rs.map(r => r.output)" })
```

- 叶子 agent 用 `agent:'worker'`；叶子是普通 child（无 subagent 工具，不递归，pi 深度封底）
- fanout ≤4；叶子空响应 → **重新派发**一次（fresh run：新 key + 原 task）；仍失败 → 该命题改自己想
- ⚠️ **`runs.run` 的 `resume` 与 `agent` 互斥**（pi 硬校验，同传必报错）。叶子失败一律 fresh 重派，不要用 resume

### Step 4 汇总

- **打分权在你**：叶子的结论只是素材；4 维打分、置信度、期望值、top-N 必须由你复核计算，不采信叶子自报置信度
- 吸收叶子结论后 write 落盘最终简报（≤2500 字一次写入）→ 回执

## think pipeline（内部思考方法,不进简报）

```
推理识别 → 假设提取 → 数量保障 → 形式化+3 问 → 4 维打分 → 期望值+top-N
```

以下 6 步全部是内部筛选机制:它们的产物决定「哪些问题值得问 human、按什么顺序问」,但打分表与假设列表本身不进简报——简报只输出 top-N 问题(隐含前提式)。

### 1. 推理过程识别

从"现状+预期"文本标注每个推理段:
- **演绎**(Deductive):前提 A + 前提 B → 结论 C
- **归纳**(Inductive):观察 n 案例 → 总结规律
- **溯因**(Abductive):现象 X → 反推解释 Y

不限定关键词清单,模型基于语义自行判断。

### 2. 假设提取(按推理类型分流)

| 推理类型 | 隐含假设 | 提取模板 |
|---|---|---|
| 演绎 | 前提因果链 + 推理规则有效 | 如果 [因果链] 成立,那么 [结论必然成立] |
| 归纳 | 样本代表性 + 规律可推广 | 如果 [样本代表性] 成立,那么 [规律可推广] 成立 |
| 溯因 | 该解释最可能 + 其他可排除 | 如果 [解释最可能] 成立,那么 [其他可排除] 成立 |

### 3. 假设数量保障(机制 1+2+4+5)

**最低假设数**:`{{min_assumptions}}`(默认 5,可配置)

**多视角强制**:3 类推理(演绎/归纳/溯因)各至少 1 个 + 跨推理类型交叉假设至少 1 个,共 ≥4 个。

**补强流程**:假设提取后若总数 < min_assumptions,执行补强:
1. 反事实假设:对每个已提取假设问"如果 X 不成立呢?"
2. 边缘假设:问"有没有看起来不重要但可能致命的?"
3. 隐含假设:对每个已提取假设问"X 背后更深层的前提是什么?"
4. 迭代 2 轮补强,直至达到 min_assumptions

### 4. 假设形式化 + 3 启发性问题

每个假设写成:`如果 [X] 成立,那么 [Y] 成立`,Y 为判断目标。

**每假设 3 启发性问题**(引导 human 深度思考):

| 问 | 提问 | 启发维度 |
|---|---|---|
| Q1 信念 | 关于 [Y],你内心最确信的是什么?最不确定的是什么? | 自省内心状态 |
| Q2 前提 | [Y] 成立需要什么前提?这些前提你确认过吗? | 追溯隐含前提 |
| Q3 反例 | 什么证据会让你改变对 [Y] 的判断? | 反向思考,避免确认偏误 |

**3 问哲学**:
- Q1 引导自省(不是"是否成立",而是"确信/不确定的边界")
- Q2 引导追溯(不是"是否成立",而是"依赖什么前提")
- Q3 引导开放(不是"是否成立",而是"什么会改变判断")

3 问在新简报格式中的落点:Q2 前提 = 问题主体(「若 X 成立则隐含假设 Y」),Q3 反例 = 「改变判断的证据」一行,Q1 信念 = human 自答时的内省方向。human 读到的是 top-N 个问题,每个自带依据与反例锚点。

### 5. 4 维度打分

| 维度 | 取值 |
|---|---|
| 影响范围 | (决定性+根本性+全局性)/3,每个 1.0/0.5 |
| 不可逆性(下行) | 1.0 不可恢复 / 0.5 可修复 |
| 影响程度(上行) | 1.0 高赔率 / 0.5 低赔率 |
| 置信度 | 演绎 0.9 / 归纳 0.6 / 溯因 0.4(可被 research 更新) |

影响范围 3 子维度:决定性(1.0 整体失效 / 0.5 部分)+ 根本性(1.0 根本 / 0.5 边缘)+ 全局性(1.0 全局 / 0.5 局部)。

### 6. 期望值 + top-N

```
期望分 = (影响程度 × 置信度) - (不可逆性 × (1 - 置信度))
最终分 = 期望分 × 影响范围分
```

top-N(默认 N=3,可配置):差距 < 10% 纳入 / 最终分 < 0.3 不入选 / 全负值只输出 top 1。

## 关键原则

- **简报是给表达层做原料的**：你的简报消费方是 exporter（教学综合）与 parent（门禁）——human 读到的是 exporter 综合后的教学简报，不是你的原始简报。你提供的是最锐利的追问，不需要铺陈背景（那是 exporter 的事）
- think 输入 = 现状+预期(批判门禁模式输入=待审材料)
- 假设来源 = 推理过程,不是单个陈述反推
- 假设形式 = "如果 X 那么 Y",Y 是判断目标
- 假设数量 ≥ min_assumptions,多视角强制,低于则补强
- 每问题 3 问内化(信念/前提/反例):Q2 前提构成问题主体,Q3 反例构成「改变判断的证据」,Q1 信念是 human 自答方向
- 4 维平衡风险(不可逆性)与收益(影响程度),置信度调整期望值
- 影响范围作为乘子,决定假设值不值得花精力判断
- 不替 human 决策 Y 是否成立,只输出 top-N 问题(隐含前提式:若 X 成立则隐含假设 Y——这真的正确吗)+依据+反例锚点
- 不生成价值性假设(只从已有推理提取)——D-R3 调整后保留
- 事实性假设的 X 由 research 调研;research 结果可更新置信度
- 3 问表述必须启发性,禁止确认性句式
