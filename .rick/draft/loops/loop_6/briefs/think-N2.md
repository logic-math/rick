## 打分依据（只陈述理由，不替 human 选择主要矛盾）

### 根本性（触及根本问题 vs 边缘问题）

- **K1（1.0）**：零 pi 触发语法（N3.1）是触发概率低的**直接根因**——main agent 收到的触发指令（i1）与 subagent 工具协议（i2）在语法层不对齐。
- **K2（1.0）**：零内置 agent 名（N3.2）是触发失败的第二直接根因——即使有语法，自造名 think/research/exporter 也无法解析（"Unknown agent"，BP-2）。
- **K3（1.0）**：触及 rick 作为「引导程序 / sense 方法论自成体系」的**身份定位**是否保留。
- **K4（1.0）**：触及 rick 与 pi 的**长期关系**（深度耦合跟随 vs 保持独立可迁移），是"改造到多深"的根本取舍。
- **K5（0.5）**：属"对齐之后"的残余问题（模型能力上限），边缘于"触发概率低"的直接根因（协议不对齐）。
- **K6（0.5）**：属"如何覆盖各命令"的执行策略，非根本。
- **K7（0.5）**：属协议对齐中"谁触发"的澄清（BP-8），偏执行细节（且 pi 已隐含：普通子 agent 不持 subagent 工具）。

### 全局性（影响全局 vs 局部）

- **K1/K2（1.0）**：243 处自然语言触发词 + 全部自造名，覆盖 human-loop/plan/dream/doing/easy/learning 全部含 subagent 命令（F1 触发分布）。
- **K3/K4（1.0）**：rick 整体方法层与框架定位，影响全部命令与长期演化。
- **K5（1.0）**：模型能力上限约束所有命令的"上限内最高"目标。
- **K6（1.0）**：涉及全部命令的改造覆盖面（ctrl 无 subagent 要求是特例，仍需纳入统一框架判断）。
- **K7（1.0）**：触发权归属是跨命令的通用约束（BP-8/D6）。

### 决定性（系统从 A→B 必经 vs 仅影响部分）

- **K1（1.0）**：不改触发语法，E2/E3 边的协议不对齐无法消除，A→B 必经（控制手段①）。
- **K2（1.0）**：不注册/映射真实 agent 名，即使有语法也会 "Unknown agent"，A→B 必经（控制手段②）。
- **K4（1.0）**：human 的 B = 「高度定制化改造 + 触发确定性上限内最高 + 长期跟随 pi」。在 pi 长期发展既定前提下，「改造深度 vs 保持独立」的取舍是 A→B 的必经战略决策——不取舍（=维持现状 A）或选择浅度适配（无法达上限内最高、无法长期跟随）均不能到 B。
- **K3（0.5）**：「方法层身份是否保留」在技术上可延后——可通过适配层在保留 sense 方法论的同时对齐触发协议，故仅影响改造彻底程度与长期先进性，非最小必经。
- **K5（0.5）**：是否达"上限内最高"依赖模型能力，但对齐本身不依赖先验证能力上限（human 已承接"改正后实测"）。
- **K6（0.5）**："统一 vs 特殊"是覆盖粒度取舍，A→B 必经的是"覆盖各命令"，而非"统一 or 特殊"的特定答案。
- **K7（0.5）**：parent 触发权在 pi 机制中已隐含（子 agent 不持 subagent 工具），提示词显式化是加固而非最小必经。

### K4 是否即 top-1 的评估（不替 human 决定，只摆事实）

- K4 与 K1/K2 在三维打分上并列满分（3.0），但**层次不同**：
  - K1/K2 是「协议不对齐」的**直接技术表现**（零语法 + 零 agent 名），是 A→B 的最小必经技术步骤。
  - K4 是「改造深度 vs 独立性」的**战略伞型矛盾**：其解法（深度改造）**包含** K1（改语法）+ K2（注册名）+ K7（触发权归属）+ 部分 K6（统一改造）——即 human 选择的 K4 方向，在解决自身时**同时决定了 K1/K2/K6/K7 的解法**。
- 因此：若以「最小必经技术步骤」衡量，K1/K2 是 top；若以「一个矛盾解决后带动其余」的辩证标准衡量，K4 是主要矛盾——这与 human 的指向一致。**最终由 human 在 N2 选定**。

## 「看似次要实则根本」审查

1. **K5（确定性 vs 能力上限，总分 2.0）——潜在"看似次要实则根本"**：
   human 在 S 阶段明示「模型能力差异没有排除，有可能是这个原因」。若实测发现模型 tool-calling 上限是约束"上限内最高"的主导因素，K5 会从"边缘"升为"根本"——即协议对齐（K1/K2/K4）只决定触发概率的"下限提升"，而 K5 决定"上限"。当前因无 benchmark 信源（R7），保留为待实测项，暂不升为 top。
2. **K3（框架独立性，总分 2.5）——与 K4 高度重叠**：
   K3（身份：sense 方法论自成体系是否保留）与 K4（程度：改造到多深）是同一矛盾的两个切面。human 的 N1 回答 #2「3 年后失去先进性」与 #3「rick 是核心节点」均指向"长期先进性取决于 rick 方法层，而非仅跟随 pi"——这构成 K3/K4 之外的一个更根本的张力：**先进性来源 = 深度对齐 pi（K4 解法）还是 rick 方法层自身（K3 保留）**。该张力未被 K1/K2 覆盖，值得 human 在选定主要矛盾时顺带明确。
3. 其余（K6/K7）评分 2.0，均属执行层面，未发现"被低估的根本矛盾"。
