# skill:think(推理过程分析+4 维风险评估+启发性 3 问方法论)

think 是 SENSE 方法论中 S2(假设枚举)和 EC(批判)的工具化体现。从"现状+预期"识别推理过程,提取隐含假设,数量保障补强,4 维打分,每假设 3 启发性问题,top-N。

---

## think pipeline

```
推理识别 → 假设提取 → 数量保障 → 形式化+3 问 → 4 维打分 → 期望值+top-N
```

### 1. 推理过程识别

从"现状+预期"文本标注每个推理段:
- **演绎**(Deductive):前提 A + 前提 B → 结论 C
- **归纳**(Inductive):观察 n 案例 → 总结规律
- **溯因**(Abductive):现象 X → 反推解释 Y

不限定关键词清单,模型基于语义自行判断。

### 2. 假设提取(按推理类型分流)

| 推理类型 | 隐含假设 | 提取模板 |
|---|---|---|
| 演绎 | 前提因果链 + 推理规则有效 | 如果 [因果链] 成立,那么 [结论必然成立] |
| 归纳 | 样本代表性 + 规律可推广 | 如果 [样本代表性] 成立,那么 [规律可推广] 成立 |
| 溯因 | 该解释最可能 + 其他可排除 | 如果 [解释最可能] 成立,那么 [其他可排除] 成立 |

### 3. 假设数量保障(机制 1+2+4+5)

**最低假设数**:`{{min_assumptions}}`(默认 5,可配置)

**多视角强制**:3 类推理(演绎/归纳/溯因)各至少 1 个 + 跨推理类型交叉假设至少 1 个,共 ≥4 个。

**补强流程**:假设提取后若总数 < min_assumptions,执行补强:
1. 反事实假设:对每个已提取假设问"如果 X 不成立呢?"
2. 边缘假设:问"有没有看起来不重要但可能致命的?"
3. 隐含假设:对每个已提取假设问"X 背后更深层的前提是什么?"
4. 迭代 2 轮补强,直至达到 min_assumptions

### 4. 假设形式化 + 3 启发性问题

每个假设写成:`如果 [X] 成立,那么 [Y] 成立`,Y 为判断目标。

**每假设 3 启发性问题**(引导 human 深度思考):

| 问 | 提问 | 启发维度 |
|---|---|---|
| Q1 信念 | 关于 [Y],你内心最确信的是什么?最不确定的是什么? | 自省内心状态 |
| Q2 前提 | [Y] 成立需要什么前提?这些前提你确认过吗? | 追溯隐含前提 |
| Q3 反例 | 什么证据会让你改变对 [Y] 的判断? | 反向思考,避免确认偏误 |

**3 问哲学**:
- Q1 引导自省(不是"是否成立",而是"确信/不确定的边界")
- Q2 引导追溯(不是"是否成立",而是"依赖什么前提")
- Q3 引导开放(不是"是否成立",而是"什么会改变判断")

human 可选择性回答,但至少看到 3 × top-N 个问题。

### 5. 4 维度打分

| 维度 | 取值 |
|---|---|
| 影响范围 | (决定性+根本性+全局性)/3,每个 1.0/0.5 |
| 不可逆性(下行) | 1.0 不可恢复 / 0.5 可修复 |
| 影响程度(上行) | 1.0 高赔率 / 0.5 低赔率 |
| 置信度 | 演绎 0.9 / 归纳 0.6 / 溯因 0.4(可被 research 更新) |

影响范围 3 子维度:决定性(1.0 整体失效 / 0.5 部分)+ 根本性(1.0 根本 / 0.5 边缘)+ 全局性(1.0 全局 / 0.5 局部)。

### 6. 期望值 + top-N

```
期望分 = (影响程度 × 置信度) - (不可逆性 × (1 - 置信度))
最终分 = 期望分 × 影响范围分
```

top-N(默认 N=3,可配置):差距 < 10% 纳入 / 最终分 < 0.3 不入选 / 全负值只输出 top 1。

---

## 关键原则

- think 输入 = 现状+预期(批判门禁模式输入=待审材料)
- 假设来源 = 推理过程,不是单个陈述反推
- 假设形式 = "如果 X 那么 Y",Y 是判断目标
- 假设数量 ≥ min_assumptions,多视角强制,低于则补强
- 每假设 3 启发性问题(信念/前提/反例),引导 human 深度思考
- 4 维平衡风险(不可逆性)与收益(影响程度),置信度调整期望值
- 影响范围作为乘子,决定假设值不值得花精力判断
- 不替 human 决策 Y 是否成立,只输出 top-N + 风险评估 + 3 问
- 不生成价值性假设(只从已有推理提取)——D-R3 调整后保留
- 事实性假设的 X 由 research 调研;research 结果可更新置信度
- 3 问表述必须启发性,禁止确认性句式
