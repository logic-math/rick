## 2｜叙述的骨架：系统是什么（事实层给满，未载即 Gaps）

先还原博客自己的叙事弧：未具名国产加速器上 GLM-5.3-Flash 首次跑通（W8A8）→ 13 天到 3.22×——「迁移窗口」是全部机制的原始问题；结果之后跟着边界声明（§5）。

### 2.1｜一支 agent、一面反馈墙、一座骨架库

**单 agent 形态（A）**：博客原话 "an Infra Agent powered by GLM-5.3"——通篇单数，无多 agent／编排器／搜索算法字样。循环就一拍：

```
agent 提假设 → 改代码 → 跑实验 → 反馈（保留 / 修改 / 否决）→ 下一轮
```

纪律：这是**外部循环形态**——agent 内部结构（工具接口／上下文管理／单次实验成本）全未载（Gaps），只教外壳、不臆造内部。

**工具面＝工程师预建的 dense feedback 环境（A）**：正确性测试／运行时日志／执行 trace／运行时事件／microbenchmark／端到端指标，被组织成**可重复、agent 可直接调用**的验证工作流；外加「并行策略 → kernel 实现」映射，把系统级配置拆成可逐个验证的 kernel 级任务。dense ≠ 多喂日志——三性质：**局部**（改哪测哪）／**廉价及时**／**客观可验**（数字不过叙事）。墙是谁搭的？工程师——§5 第三职责伏笔。

**知识留存件＝优化骨架库（A）**：从 SGLang／FLA／DeepGEMM 既有手写 kernel 提取优化技术＋适用条件（applicability conditions／转换方法／资源约束／验证证据），经增量＋消融实验蒸馏成**骨架**；新 kernel 从骨架出发，验证过的变更回写库。检索／组织／淘汰机制——未载（Gaps）；§6 部件对照的关键缺口就是它。

### 2.2｜优化对象与栈生态（三案例一句话定位）

**对象清单（A）**：kernel（数值＋性能）｜Python-C++ 边界并发（GIL）｜并行策略（Context Parallel／Layer Split）｜量化（W8A8、混合精度 cache）｜调度｜EPD 分离架构。未提编译器 flag 与路由层——第 9 课恰有人在搜那个空间。

**栈生态（A＋B）**：SGLang＋FLA 的 KDA kernel＋DeepEP＋Mooncake KV Transfer＋未具名国产加速器 >10 万卡——**跨公司开源组合**。被服务模型 GLM-5.3-Flash：320B 总参／18B 激活、45 层＝34 KDA＋11 sparse-MLA（3:1）、1M 上下文多模态（320B/18B/1M 多源印证；架构比例 B 级二手）。

三案例各一句定位（GIL 详拆见 §4）：

- **① KDA kernel CP 路径数值 bug**：分片／非分片执行路径数值对比暴露差异 → 定位 state merge 精度 → input_precision="tf32x3" 修复，合入 FLA 上游——实核 PR #1180 真实存在、逐条吻合（**A 双源**）；但 PR 由人提交、维护者重做，**agent 贡献在公开工件中不可分离**。
- **② GIL 持锁阻塞 KV Transfer**：§4 详——判真反差样本。
- **③ KDA Decode kernel 三段演化**：v0→v1 以算力换显存（变慢）；v1→v2 除法优化 −9.6%；v2→v3 合并 V 维 tiling 消除 4 次重复归一化＝**1.71×（kernel 级，A）**——以降并行度消除冗余计算。

### 2.3｜「the model optimizes the system; the system runs the model」——族级自指

第 5 课你已定位过这句口号的拧结（路线 3 的 target ≠ 路线 2 的 harness）。现在拆到机制级：

```
优化者：GLM-5.3（agent 的动力模型）
    ↓ 优化
serving 栈（kernel／并发／并行／量化／调度／EPD）
    ↓ 承载全部生产推理
被服务者：GLM-5.3-Flash（"All production inference for GLM-5.3-Flash runs on this system"）
```

优化者与被服务者**同家族、不同变体**——博客原句 "The model thus participated in optimizing its own inference system"：这是**族级自指（family-level），不是实例级**。两条精确性纪律：

1. 博客**未称** agent 自身的推理跑在被优化栈上——agent 宿主问题未载（Gaps）。「模型优化跑自己的系统」在已知事实里只到家族这一层。
2. 跨部署留存有原句（A）大意：每次部署积累的经验降低了下一轮优化的工程量——但**第二轮**（系统优化自己刚改过的部分）未发表。

> **你来推（留白②）**：族级自指 → 实例级自指，缺的是什么？提示：实例级＝「被优化系统运行优化者自己」——检查箭头链上哪一环在已知事实里是断的，数出两环（一环在 Gaps 清单上，一环在「未发表」清单上）。想清楚，你就能精确说出「通往 RSI 早期一步」（立场层，待裁决 4，你已裁决接受为学习前提）在事实层还差几步。

## 8｜关键概念清单＋费曼检验

**关键概念（自述检验——一行一条）**：

1. Infra Agent 三件套：单 agent（提假设→改代码→跑实验→保留/修改/否决）＋dense feedback 工具面（局部／廉价及时／客观可验，工程师预建）＋优化骨架库（技术＋适用条件→蒸馏→回写）；内部结构未载
