### R2 — 期望线索最小化形态（Q17）
- 架构设计全部剥离到独立架构 RFC
- 简报内仅保留一句话指针陈述存在，不展开分工/交互/优先级

### R3 — 阶段门禁与结束条件（C1 + F1）
- 阶段门禁推进条件：该阶段所有假设被澄清
- 整体 sense 结束条件：良质跃迁 + 所有价值性假设已显式澄清 → 调用 exporter agent 产出 RFC

### R4 — 分层归属（Q2 + Q6）
- research agent：事实性假设澄清（三层判断）
- main agent（sense agent）：通用假设澄清确认（复核）
- human：最终确认

### R5 — 简报格式（Q7）
- 简报末尾以提问结尾，引导 human 做出判断
- 提问前需陈列足够事实信息帮助 human 理解正在发生的事

### R6 — research agent 工作 loop（G1-G4）
- 理解需求 → 产生调研树（事实模糊点）→ 广度遍历树进行事实模糊性澄清 → 结合调研内容扩展调研树 → 往复循环 → 直到事实模糊性为 0
- 假设以问题的形式表达
- exporter agent 独立
- 假设澄清由 main agent 执行
