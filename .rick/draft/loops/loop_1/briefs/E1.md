### 节点说明

**核心节点（协议层）**
- **sense agent（main agent）**：流程推进与验收者，非执行者；负责三层复核第二层（main 复核）
- **research agent**：事实性假设澄清，三层复核第一层；执行 research 工作 loop 直到事实模糊性归零
- **think agent**：基于调研事实与 human 需求生成价值性假设；目标：暴露致使目标最终失败的最大风险项
- **exporter agent**：将整个会话思考过程表达为 RFC（独立架构 RFC，draft/rfc/ 路径）
- **三层复核机制**：research（事实层）→ main（通用假设确认）→ human（最终确认）
- **阶段门禁**：同层所有假设（事实性 + 价值性）被澄清才可推进
- **整体结束**：良质跃迁 + 所有价值性假设显式澄清 → 调用 exporter agent
- **research 工作 loop**：理解需求 → 产生调研树（事实模糊点）→ 广度遍历树进行事实模糊性澄清 → 结合调研内容扩展调研树 → 循环直到事实模糊性=0
- **skill_sense 五阶段**：S1（现状/期望/差距）→ S2（Subject 假设枚举）→ ... → SN + EC（外部理论候选）

**核心节点（价值判定层）**
- **启发性**：替换原"价值性假设"措辞；标准 = 致使目标最终失败
- **判断重要性标准**：失败概率（模型主观评估）
- **悬置项规则 R1**：AI 草案仅列客观矛盾点，不带推理、不带建议方向；human 基于矛盾点原创问题描述；问题描述也需 human 确认
- **简报格式 R5**：事实陈列在前 + 提问结尾，引导 human 做出判断

**核心节点（产物层）**
- **架构 RFC 剥离**：draft/rfc/ 独立路径，与 loops/judgment 分离
- **简报格式**：所有阶段产物统一为简报 + 提问结尾

**外部理论候选（E2 视角选择依据）**
- **双环学习（Argyris）**：单环学习修正行动，双环学习质疑行动背后的假设本身 → 对应 think agent 的价值性假设暴露
- **库恩范式转换**：常规科学 vs 范式危机 vs 革命科学 → 对应"良质跃迁"的整体结束条件
- **Wittgenstein 枢轴概念**：语言游戏的枢轴转动，确定性基于未言明的枢轴 → 对应"模糊性归零"的 research loop
- **HRO 失败假设**：对失败的预期 vs 实际失败 → 对应"致使目标最终失败"的启发性标准

### 建议深挖节点

- **X1**：双环学习与 think agent 价值性假设的映射准确性 — 双环学习质疑的是"行动背后的假设"，think agent 暴露的是"致使目标最终失败的最大风险项"，二者是否等价？
- **X2**：库恩范式转换与"良质跃迁"的映射准确性 — 范式危机是否等价于良质跃迁？革命科学是否等价于整体结束？
- **X3**：Wittgenstein 枢轴概念与"事实模糊性归零"的映射准确性 — 枢轴是否等价于事实性假设？枢轴转动是否等价于事实澄清？
- **X4**：HRO 失败假设与"致使目标最终失败"的映射准确性 — HRO 是组织层面对失败的预期，think agent 是个体层面价值性假设，二者层级是否兼容？
- **X5**：sense agent（main）与 think agent 的边界 — main 是流程推进与验收者，think 是价值性假设生成者；当 main 复核价值性假设时，是否越界进入 think 的职责？
- **X6**：架构 RFC 接口边界 — exporter agent 产出 RFC，但架构 RFC 在 draft/rfc/ 独立路径；RFC 内容范围、与 loops/judgment 的引用关系需澄清
- **X7**：skill_sense 五阶段与 E2/N 阶段的对应关系 — S1-SN 是否一一对应 sense_subagent.md 的 E1-EN？EC（外部理论候选）与 E2 视角选择的关系？
