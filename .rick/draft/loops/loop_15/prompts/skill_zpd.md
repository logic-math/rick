# skill:zpd（ZPD 档案——parent 会话内联执行的档案方法论）

> 本文件是 parent 的内联方法论（非 agent）：ZPD 档案（`zpd.md`，parent 独写）是 lesson-writer 详略取舍与教学节奏推进的唯一事实来源——会什么/不会什么/边缘区，随 loop 展开逐次完善。

## 档案格式（`zpd.md`）

```
# ZPD 档案 — <主题>
## 概念掌握表
| 概念 | 状态（会/边缘/不会） | 证据（模糊点与对错摘要） | 时间 |
|---|---|---|---|
## 当前结论
- 已掌握（可加速）：…
- 边缘区（重点教）：…
- 缺失（需补基础）：…
## 薄弱点（= 薄弱知识领域标记）
- <概念>：<模糊点原话摘要>（讲得出结论、讲不出机制的领域）
## 详略建议（给 lesson-writer）
…
```

## 状态判定（从费曼演绎的模糊点与对错推导）

- **会**：无错误断言，关键概念及其关系能自述完整（讲得出「X 为什么影响 Y」）
- **边缘**：讲得出结论但讲不出机制/边界（事实模糊点所在——**往往 = 薄弱知识领域**）
- **不会**：存在错误断言，或两轮追问仍答不上（费曼步③触发补讲处）

## 更新时机与写者

- **费曼演绎步③之后**：每轮费曼暴露的模糊点即时更新对应概念的行（状态可随新证据升/降档）
- **② ZPD 生成 d 步建档**：首轮建档（parent 首块 write 创建）
- **parent 独写**：zpd.md 只由 parent 写入（费曼演绎/建档/更新均在会话内执行时顺手完成）
- 写入方式：首块 `write`（≤60 行）；更新 = read 当前档案 → 修改受影响行/节；追加用 `bash: cat >>` 分批

## 使用

- **给 lesson-writer**：派发 task 附 `zpd.md` 路径（详略依据：会可加速/边缘重点教/不会补基础+薄弱点清单）
- **给自己（节奏）**：推进与否最终问 human，但档案是调整详略与复测选择的依据
- 跨 loop：下个会话的 ② ZPD 生成 b 步读本档案 + anchors.md 选回忆点
