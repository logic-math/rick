## 1. 背景与问题

### 1.1 触发问题（human 原话）

> 我觉得 human-loop的输出，太啰嗦，效率比较低；并且业界目前的工作也比较多，可以学习改进。

配套约束与起点（human 原话）：

> 说清楚为什么，有改进计划
> 天天用我很熟，这些领域基本的概念我是理解的。
> 这些升级方案（历史 RFC）在我看来，不够有原创性。

### 1.2 v6 的结构性事实（research_1 Q1，等级 A＝协议原文直读）

| 症状 | 结构性来源 |
|---|---|
| 输出长 | teach 正文必须全文返回 + parent 逐字呈现（「不改写、不摘要」）；lesson 三硬要求（引注／2–4 追问／荐 primary source）；loop_11 实测 ≈160KB/会话，单课 15–20KB |
| 慢／贵 | 每次派发 fresh 上下文并重读约 6 份 canon/材料；research→teach 强制串行；每回合固定四段（认知强制→派发→呈现→记 judgment）；协议自记单轮 TTFB 可达 8 分钟 |
| 原创不足 | 五环节中「原创性启发」无直接实证支撑；loop 内无差异源注入机制、无效果判据、无淘汰规则 |

### 1.3 关键事实边界（决定本 ADR 的置信度）

- 「复习机制 → 原创产出」**无直接 RCT**（research_2 #11，A 级缺位判定）
- 「仅指错 vs 指错+给更优替代」**无直接对照实验**（research_4 Gaps）
- 「LLM 每轮字数 → 学习结果」**无 RCT**（research_4 #27）——human 抱怨的正是证据最薄的那件事
- 「按掌握度选任务」的独立增益为 null（ALEKS 阈值 RCT，N=806,279，保持率差 ≈0.02；research_4 #24，A/C）
- 「口头回忆式测评」作为测量工具的效标效度无系统证据（research_3 Q1②，B）
- 本工作区无 token/延迟日志，成本类结论只能是结构性估计，不能报数（research_1/3 Gaps）

## 3. 决策明细

### D1 教学＝ZPD 内的认知负荷管理（V1）

> 本质上教学就是管理学生的认知负荷，就是 ZPD 最近发展区原理，测试学生已经掌握的知识，探测学生可能掌握的知识，这个差距就是最近发展区。 也就是认知负荷管理的范围。 这就是教学法，通过这种方法，来管理多轮对话的节奏即可。

**含义**：教学的目标函数不是「交付完整内容」，而是「把每一轮的认知负荷压在 ZPD 内，并据此决定下一轮」。ZPD 由此有两个用途，且都必须存在：① 决定讲多深（负荷边界）；② 决定推进/倒退（节奏开关）。

**依据**：认知负荷理论 + 专长反转（Kalyuga 2003，A；Sweller & Cooper 1985，A）——对熟手做完整讲解会失效甚至负效；V1 把这一条从「知识」提升为「教学定义」。

**后果**：协议的验收契约必须从「内容完整性」改成「节奏正确性」。v6 的 lesson 三硬要求与「正文全文呈现」在这条决策下失去正当性（它们优化的是交付完整度）。

### D2 原创的定义与优化范围（V2 / V3）

> 我认为只有是启发有差异性想法的都可以算
> 暂不考虑外部，只考虑各人收益

**含义**：不取 Boden 的「变革型创造」定义（改概念空间规则，极罕见且无可靠触发方法），而取「相对 human 已有空间产生差异」为判据；不把「不加剧集体同质化」纳入目标（Doshi & Hauser 2024 的个体↑/集体多样性↓ 取舍中，只取个体侧）。

**后果**：原创性可被操作化为「差异源注入 + 想法差异性」，无需等待变革型创造的触发条件；同时也放弃了集体外部性这一约束——若未来用于多人或公开产出，此项需重新裁决。

### D3 保留防卸载护栏（V4）

> 可以维护，这个确实需要一些手段

**含义**：接受「引导自答」相对「直接给答案」更慢、更啰嗦的代价，用以换取不损害无辅助表现。依据：Bastani et al. 2024（PNAS，A·已复验）——无护栏 GPT 辅导提升练习成绩（+127%/+48%）但损害无辅助考试（−17%），加「不给答案」护栏后损害消失。

**与 mission 的张力**：human 同时抱怨「啰嗦低效」。本条与 mission 的第一句抱怨构成直接张力，取舍为「保留护栏，但用 D8/D9 的手段把成本压下来」。这一张力**未被消解，只被排序**。

### D4 记忆复习机制（V5 / V6 / V7 / V9）

> 应加入记忆复习的机制，因为我认为复习才是产生新想法的关键。 在多次跨时间思考同一问题时更容易切换视角关联其他知识，产生原创性。
> 复习 我认为,可以搜索之前的 loop 内容，给于几个复习关键词，让 human 回忆之前的知识，允许遗忘，只是在回忆的过程中进行知识的再创造；
> 将复习机制这种允许遗忘的回忆，作为一种对被教育者实际能力的测评即可。 选择回忆的内容可以根据 历史 loop 的信息进行启发即可，没有的话则可以根据领域相关性进行启发。 允许用户一点也想不起来，作为无能力的标记即可

**机制形态（已定）**：循环开始时，从历史 loop 抽取关键词 → human 回忆并写出 → 与事实比对 → 产出「强/中/弱」与「无能力标记」→ 作为 ZPD 初始化输入。允许遗忘；回忆过程本身即再创造；不做保持式 SRS。

**证据**：
- 支持面：跨时间重访加权 d=0.29（117 研究，仅对先前深度接触过的旧问题有效，酝酿时长本身无预测力，research_2 #1，A）；记忆可用性为组合创造必要条件（Boden 2004 原文，A）；遗忘具去固着功能（RIF 高者定势 2% vs 低者 21%；Smith & Blankenship 1991，A）
- 反面边界：机械集中重复致固着（Luchins 1942，81% vs 0%）；单纯重复练习不提升发散思维（Brucks & Huang 2020，N=830，A）
- 缺位：本机制到原创产出的直接因果链无 RCT

**由此产生的设计空白（未决，见 §7）**：D8 废弃白板后，「跨 loop 可重访的锚」没有承载物。候选：历史 lesson 的卡点条目 / judgment 原话 / research 缺口清单——各有代价，human 未裁决。

### D5 节奏（V8）

> 我还是期望一个会话讲透哈，会话重访是为了跨领域进行想法的启发。

**含义**：单会话内仍追求讲透（不采用「多会话间隔铺垫」的节奏）；跨会话重访的用途被限定为**跨领域启发**，不是复习巩固。

**与 D4 的关系**：D4 的复习探针发生在 loop 之间（跨会话），但它的用途是测评 + 跨域启发，不是补齐未讲透的内容。两条决策因此可以并存——前提是每个会话结束前留下可被下次重访的锚（当前缺失）。

### D6 掌握度判定（V10 / V11）

> 通过搜索 loop 历史和对需求的理解，引导用户阐述某些概念，根据用户阐述概念与事实符合程度来判断，用户对所学领域的掌握程度。 分为 强 中 弱即可。
> 是的，讲出来就可以作为达标判断，但要看讲的内容是否符合事实

**含义**：判据＝「阐述 × 事实符合程度」→ 三档（强/中/弱）。不使用百分比阈值（70/80/90% 属约定，无实证推导；70/80/90 三组对照期末成绩无差异，research_3 Q1⑤，A/B）。

**已知误差结构（M3 已解构，未裁决解法）**：三类失效——① 复述原句（假阳性，不违反信度）② 说错但结论对（终点可达、路径不存在）③ 说不出来但其实会（系统性假阴性）。V9「想不起来＝无能力」在跨 loop 探针上代价低，但若原样搬到「驱动推进/倒退的即时判决」的位置，会把「一时提取失败」误判为「不会」，进而倒退到已会的课——这是 mission 抱怨的新增来源。

**未决**：误差吸收手段（先讲 vs 先给答案 / 单探针 vs 三探针交叉 / 多轮取样 / V18 三次规则）未选定；且「三次什么」（三次同类＝信度检验，三次异类＝效度检验）未定。

### D7 架构形态与依赖策略（V12 / V14）

> 按 rick 的 loop+skill 格式进行内化
> 自研组件

**含义**：不采用业界 SKILL.md 生态的直接移植；按 rick 的 `.rick/loops/*.md`（frontmatter name/trigger + 目标/上下文管理/工具/验证）与 `.rick/skills/<name>_skill/skill.md`（触发场景/预期效果/核心内容）格式内化。组件自研：不引 pyBKT / FSRS / GenMentor / sparkling 等第三方依赖（sparkling 另为 AGPL-3.0，许可传染性也被此决策一并排除）。

**后果**：知识追踪、排程、图解渲染等环节全部自研或降级；省掉许可与适配成本，代价是失去已验证实现（ALEKS 级 KST、FSRS-7 级调度）。

### D8 原创性启发的形态（V13 / V15 / V16 / V17 / V19）

> 我认为可以作为一个 skill 进行引用进行测试，如果没效果可以删除掉。 其实本质上，这个对抗式认知摩擦，本质上就是 保留关键对话记录，然后对用户的回答进行符合事实的差异化回答，不是完全反驳，而是引入某个新概念后的差异化反驳，不是不对，而是更好。
> 真实异质性 是我选择的
> 给更优替代
> 不要这个白板功能了 没用
> 图文生成这些就不做了，画图可以改成基本的文本绘图。鼓励进行文本绘图就行了

**四项子决策**：
1. **真实异质性**（而非魔鬼代言人角色扮演）：依据 Nemeth 2001（A）——真实异议方案数 2.76 vs DA 1.86 / 无异议 1.84，合成 z=0.92 vs −0.32/−0.22；DA 会增加「加固原立场」（B）；质量收益只在合作语境（+17%，竞争 −23%，Curhan 2021，A）
2. **给更优替代**（而非只指错）：依据「指错」类反馈均效 d=.41–.48 但 17%–>1/3 为负（Kluger & DeNisi 1996；Wisniewski 2020，A）；与质量正相关的是「修正」而非「识别」（Gibson & Mumford，B）；**直接对照缺位**
3. **废弃白板**：理由 human 判「没用」；技术后果是外部记忆载体消失，「已证伪假设清单」失去存放处（该清单的干预效果本身也无研究，research_4 #12 标注 C）
4. **不做图文生成，改基本文本绘图并鼓励使用**：依据概念图 g=.604（自建 .819 / 阅读现成 .373 / 超链接图不显著，Nesbit & Adesope 2006，A）；TikZ 最好模型成功率仅 73.9%、LLM 直出 SVG 语义 .80，失败模式＝丢失教学意图（A）

### D9 效果判据（V18）

> 目前主动判断吧，看人的判断。  连续三次不行我觉得就是不行了

**含义**：不建量化 eval；判据＝human 主动判断；淘汰线＝连续三次不行即删。

**已知风险**（M3/M8 已指出）：人的主动判断天然偏向「读着顺」，而 desirable difficulties 说明短期流畅感与长期习得可反向（Bjork 1994，A）——该规则可能系统性保留「舒服但无用」的方案。且「三次什么」未定义。

### D10 五步 loop 与 skill/agent 划分（judgment 原话）

> 1. 学习目标对齐 2. 最近发展区初始化 3. 构建教学大纲 4. 推进教学任务(调研->生成教学内容(图解+文字)->让学生讲出来->判断学生掌握程度->原创性启发->推进或倒退到上一课) 5.总结与复习，引导学生基于学习到的知识达成学习目标
> 最近发展区 应该是一个 skill；调研是一个 agent；教学大纲生成是一个 skill；教学内容生成 应该也是一个 skill；让学生讲出来这个不需要，只需要理解即可；判断学生掌握程度 可以是最近发展区的 skill；基于最近发展区来判断是否推进到下一课内容上。

**注**：第 4 步原话含「图解+文字」，已被 D8（V19）推翻为「基本文本绘图」；「让学生讲出来」在 skill 划分里被判「不需要（只需理解）」，但与 D6（V11：讲出来作为达标判断）并列时存在解释空间——见 §7 未决项。

## 4. 目标架构（按 rick 格式内化）

### 4.1 Loop：`.rick/loops/human-learning-loop.md`

```text
name: human-learning-loop
trigger: 当 human 要求学习某领域知识、需要在会话内完成「目标对齐→ZPD 初始化→大纲→逐课推进→收口复习」时触发
```

| 步 | 目标 | 承载 | 判据（无判据＝开环点） |
|---|---|---|---|
| ① 学习目标对齐 | 产出 mission（为什么学 / 考核标准 / 起点） | skill：mission-builder | human 确认 mission 落盘 |
| ② ZPD 初始化 | 跨 loop 关键词唤起 → human 回忆写出 → 强/中/弱 + 无能力标记 | skill：zpd-assessor = 复习探针 + 掌握度判定（合一） | 阐述与事实符合程度（三档） |
| ③ 构建教学大纲 | 事实 + 已裁决价值 → 模块序 + 每块判据 | skill：syllabus-builder | human 确认大纲 |
| ④ 推进教学任务 | 子循环：调研(agent) → 内容生成(图解+文字→文本绘图) → 讲出来 → 判掌握 → 原创性启发 → 推进/倒退 | agent：research；skill：lesson-writer / originality-sparker | 掌握度三档 + 原创启发效果判断 |
| ⑤ 总结与复习 | 抽关键词、留可重访锚、收口到学习目标 | skill：recall-review | human 判断「三次不行即删」 |

### 4.2 Skill 清单（自研，rick 格式）

| skill | 输入 | 输出 | 自研要点（无现成同构实现） |
|---|---|---|---|
| `zpd_assessor_skill` | 历史 loop 关键词 / human 回忆原话 / 本模块目标 | 强·中·弱、无能力标记、推进或倒退、下一轮回忆引导关键词 | 自然语言回忆 → 结构化能力判定；误差吸收规则（待定） |
| `syllabus_builder_skill` | research 事实 + 已裁决 values + mission | 模块序 + 每块判据 + 位置理由 | 现有 LLM 课纲生成无学习增益 RCT，且 SENSE 留痕形态无现成实现 |
| `lesson_writer_skill` | 模块 + 当回合事实 | lesson 正文（事实层给满 / 推导层留白 / 装饰层删净 / 基本文本绘图） | 图文配比与教学意图约束；文本绘图替代图解生成 |
| `originality_sparker_skill` | human 的旧判断 + 异领域事实 + 真实分歧来源 | 「更优替代」候选 + 差异维度说明 | 真实异质性来源工程；无白板；无直接实证支撑 |
| `recall_review_skill` | 历史 loop 文件 | 复习关键词 + 再创造任务 | 跨 loop 关键词抽取（从卡点条目抽，而非结论） |
| （agent）`research` | 派发任务 + 材料路径 | research_N.md + values 待裁决条目 | 复用 v6 已有实现 |

### 4.3 「啰嗦/低效」三条来源在新架构中的处置

| 来源（v6 明文） | v7 处置 |
|---|---|
| teach 正文全文返回 + parent 逐字呈现 | D1（节奏而非交付）→ 改成「事实层给满 / 推导层留白」，由 human 生成补齐 |

## 5. 被否决 / 推迟的备选

| 备选 | 结论 | 理由 |
|---|---|---|
| 变革型创造作为目标定义 | 否决 | 极罕见、无可靠触发方法（Boden，A；V2 裁决） |
| 把「不加剧集体同质化」纳入目标 | 否决（本阶段） | V3：只考虑个人收益 |
| 保持式 SRS 复习（FSRS/SM-2 式） | 否决 | 机械集中重复致固着（Luchins 81% vs 0%）；V6 裁决为「回忆中再创造」 |
| 白板（外部记忆 / 已证伪清单） | 否决 | V17：没用；且笔记收益来自「生成+复看」而非存储介质（Bohay 2011，A） |
| 魔鬼代言人角色扮演 | 否决 | 真实异议显著优于 DA，DA ≈ 无异议且增加「加固原立场」（Nemeth 2001，A） |
| 只指错式批评 | 否决 | 反馈 17%–>1/3 为负；修正而非识别与质量相关（A/B） |
| 图文生成（Mermaid/TikZ/SVG 自动生成） | 否决 | V19；TikZ 成功率 73.9%、失败模式＝丢失教学意图（A） |
| 第三方组件（pyBKT/FSRS/GenMentor/sparkling） | 否决 | V14 自研；sparkling 为 AGPL-3.0 |
| 每轮字数 KPI | 否决 | 「LLM 每轮字数→学习结果」无 RCT（research_4 #27）；用字数当判据等于把「长=好」写回判据 |
| 量化 eval（语义距离/AUT/微调判分） | 推迟 | V18：先用人的主动判断；自动指标 r=.35–.49，成本与效度都不划算 |

## 6. 后果

### 正向
- 目标函数从「交付完整」改为「节奏正确」，与 mission 的第一句抱怨直接对齐
- 五步 loop 每一步都有明确承载物与判据入口，开环点被显式标出（此前全部隐藏在临场语感里）
- 复习与测评合一（D4），一次交互同时完成能力探测与去固着
- 原创性启发有了具体形态（真实异质性 + 更优替代 + 文本绘图），不再只是「加点 prompt」

### 负向 / 代价
- 传感器的效度无证据（B 级缺位），而它驱动推进/倒退这个开关
- 「三次不行即删」可能系统性保留「读着顺」的方案（desirable difficulties 方向相反）
- 自研路线失去已验证实现（KST/FSRS 级组件），工程量与不确定性上升
- 废弃白板后，跨 loop 重访的锚没有载体——D4 与 D5 的并存缺少物理条件
- 「讲出来」与「只需理解」两种表述并存，sub-loop 的验收点仍需澄清

### 本 ADR 自身的证据局限
- 「复习→原创产出」与「篇幅→学习结果」两条承重假设都只有间接链
- 成本类结论（token/延迟）无实测日志支撑，只有结构性推理

## 7. 未决问题（需要 human 裁决或后续实现回答）

1. **可重访锚**：D8 废白板后，跨 loop 重访靠什么存续？候选：lesson 的卡点条目 / judgment 原话 / research 缺口清单。这决定 D4 与 D5 能否同时成立。
2. **「三次什么」**：三次同类（信度检验）还是三次异类（效度检验）？这决定 D9 压的是噪声还是构念污染。
3. **误差吸收规则**：先讲 vs 先给答案；单探针 vs 三探针交叉；多轮取样；以哪个为主、冲突如何裁决。
4. **V9 搬家边界**：「想不起来＝无能力」只用于跨 loop 探针，还是也用于即时达标判决？后者会把提取失败误判为不会。
5. **「讲出来」的验收位置**：D10 的 skill 划分说「不需要（只需理解）」，D6（V11）说「讲出来可作达标判据」——是「讲出来不作为独立 skill、但作为验收动作」，还是「只判理解、不要求产出」？
6. **掌握度阈值的替代**：强/中/弱的边界（关键概念覆盖率？错误断言数？）未定义三档之间的操作边界。
7. **首次 ZPD 初始化的冷启动**：无历史 loop 时，按 V9 的「领域相关性启发」具体怎么问。

## 附：本会话的一条元证据
