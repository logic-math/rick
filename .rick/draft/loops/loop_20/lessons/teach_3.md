## 0｜从你自己的答案接入：方向已踩中，缺的是机制三答

课前的认知强制问的是：**AlphaEvolve 每一代产生大量带分数的候选，除了当前最优，那些没被选上的历史解为什么还留着？代价是存储和 prompt 空间，收益是什么？**

你的回答原话：「进化轨迹本身是有价值的，它包含丰富的反馈信号。被证伪或者有效果的实验本质上都是有效实验，只要实验是有效的，那么就在降低不确定性，就是在逼近最终答案。负反馈信号也是有价值的，只要信号是有效的。所以进化轨迹本质上就是在提供这种信息，他提供完备的历史经验，提供 proposer 避免重复的坑反复实验，帮助 proposer 提议的更好。」

三个判断你全踩中了：**轨迹 = 记忆**；**记忆的服务对象 = proposer**（你原话里自己点名了它）；**负反馈也是有效信号**——被证伪的实验同样在降低不确定性。方向全对，而且与论文的目标句同构：程序数据库的**首要目标 =「optimally resurface（最优回浮）已探索想法到后续世代」**（A：arXiv 2506.13131）。你的答案回答了「为什么留着」，这门课补的是探针三轮未现的三个「怎么」：

1. **存什么**——一个解入库，库里躺着哪几件东西？
2. **怎么回浮**——「记忆」通过什么物理通道进 proposer 的输入？
3. **张力叫什么、怎么被机制回答**——数据库要同时「持续改进最优」和「别把多样性丢光」，这对矛盾的名字与拆解机制。

先定位数据库在闭环里的位置（箭头链，A：2506.13131）：

```
用户任务规范（初始程序 + evaluate 函数）
  → prompt sampler（从程序数据库采样、构造 prompt）
  → LLM proposer（产 SEARCH/REPLACE diff）
  → evaluator（执行 evaluate 函数打分）
  → 回注程序数据库（代码 + 分数 + 执行输出）
  ↺ asyncio 异步流水线（controller / LLM samplers / evaluation nodes），
    按吞吐量而非单步速度优化
```

环上已会的部件直引不重讲：**评估端**（级联+LLM 反馈补分，你会）、**proposer IO**（采样历史解→SEARCH/REPLACE diff，方向级会）、**多样性设计**（岛模型防局部最优、退化=纯利用死胡同，会——§3 直接拿它用）。环上你从未讲过的部件只有一个：**程序数据库**。与第 2 课刚收口的判真环对照一句就够：判真管「分数可不可信」，数据库管「可信之后记什么、怎么被搜索消费」——**数据库是搜索环的记忆**。

这节课只做一件事：把你的「轨迹 = 记忆」焊到机制上。

## 1｜存什么：三件套——代码 + 多维分数 + 执行输出

2506.13131 对「一个解入库」的定义就一句话：**每个解 = 代码 + 多维分数 + 程序执行输出，一并入库**（A）。三件各自的机制位置：

| 件 | 事实定义（A） | 机制位置 |
|---|---|---|
| 代码 | 整代码文件（可达数百行、任意语言）；EVOLVE-BLOCK-START/END 注释标注待进化块 | diff 定点替换的锚 |
| 多维分数 | evaluate 返回标量字典（约定最大化） | 决定回浮谁；淘汰发生在入库步 |
| 执行输出 | 程序执行行为的记录 | ？——你来推（见本节末） |

**代码是整文件，不是片段**。进化对象是整代码文件——可达数百行、任意语言——而不是 FunSearch 的单函数 10–20 行；用户用 EVOLVE-BLOCK 注释圈出待进化块，块外代码原样带在库里（A）。推导（自推导，非原文）：proposer 产出的是**定点替换**的 SEARCH/REPLACE diff（代码很短或宜整体重写时可配置为直接输出整块代码）——diff 要「定点」，就得有完整文件作坐标，所以入库件必须是整文件而非进化块本身。

**多维分数是数据库的排序键**。分数和执行输出附着于解入库，**决定哪些想法被回浮到后续世代**（论文原话："promising solutions are registered back into the program database"）；级联早期失败即剪枝、LLM 反馈不达标即淘汰（A）——注意淘汰逻辑长在入库这一步，不是「先全存、回头再挑」。「为什么是多维、不是单维」的多样性论证是第 4 课对象，这里只需要事实：evaluate 返回的是标量**字典**、约定最大化，字典随解入库。

**执行输出是独立于分数的第三件**。分数是 evaluate 压出来的标量字典；执行输出是程序行为本身的记录——它没被压成数。

**你来推 ①**：你的课前原话说「负反馈信号也是有价值的」。分数已经把好坏压成数了，为什么还要把执行输出单独存一份？**它能给、而分数给不了的是什么？**（提示在 §2 的「四类定制」里——先往下读，读到了回来填这个空。）

## 2｜怎么回浮：prompt sampler 采样通道

「回浮」不是抽象概念，它有物理通道——**prompt**。数据库与 proposer 之间的桥只有一个：prompt sampler 从程序数据库采样、构造 prompt（A）。主 prompt 的组成（论文图 3(b)，A）：

```
主 prompt
 ├─ 多个历史解（prior programs）——各带分数 + 完整代码
 ├─ 待改进的 current program——带分数 + 完整代码
 └─ 系统指令——SEARCH/REPLACE 规则 + 任务指令（「提出受专家知识启发的新改进想法」）
 可叠加四类定制（A，第 4 课展开）：显式上下文（文献/公式/代码片段）
   ｜随机格式模板（增多样性）｜渲染的评估结果｜元 prompt 进化
```

把你课前的答案焊上来：你说轨迹「提供完备的历史经验，提供 proposer 避免重复的坑反复实验」——**机制上就是这个采样通道**。prior programs 带着分数和完整代码躺在 prompt 里，proposer 看到的不只是「当前最优长什么样」，还有「走过的路里哪些值分、哪些不值分」。「resurface（回浮）」这个词的字面就是它的机制：想法沉在数据库里，采样把它重新浮上水面——浮进 prompt。数据库不是被动仓库，是**主动供给引擎**；「optimally resurface」里的 optimally，落在「回浮谁、回浮几个」的取舍上（自推导：prompt 空间有限，这正是你课前答案里认过的代价半边）。

**你来推 ②**：回浮进 prompt 的 prior programs **必须带分数**——为什么？只给代码不给分数，proposer 少了什么？（你课前原话里装着答案的一半：负反馈也有价值——分数标注的正是「这条路走过、值不值再走」。）

**留白 ① 提示兑现**：四类定制里的「**渲染的评估结果**」——评估端产出的信息可以被渲染进 prompt，是执行输出类信息进入 proposer 视野的通道之一。现在回 §1 末尾的空：分数压不掉的行为细节，为什么值得为它占库容——你能说出至少一种「分数相同、行为不同」的情形吗？（不必标准答案，推到哪算哪。）

元 prompt 进化顺带一提（事实，不展开）：论文里其实有**两个库**——解的数据库 + 元 prompt 数据库（LLM 自拟指令、与解共同进化）。第 4 课讲 prompt 四类定制时会再见到它。

## 3｜张力命名与机制回答：exploration/exploitation——MAP-Elites + 岛模型组合启发

数据库的核心设计张力，论文给它起了名字：**exploration/exploitation——「持续改进最优程序 vs 维持多样性以探索整个搜索空间」**（A）。这是探针三轮里你没命名的那个东西：你已经会的「岛模型防收敛进单一局部最优」，就是这张力的 exploitation 极被推到底之后的死法。

```
exploitation：持续改进最优程序（分数驱动——高分解优先回浮）
     ↕  同一个数据库同时干两件互相拉扯的事
exploration：维持多样性以探索整个搜索空间（防收敛进单一局部最优）
```

算法自述的机制回答（A）：**MAP-Elites [74] + 岛模型种群 [97, 83] 的组合启发**。拆开看：

- **岛模型**——你已经会的那半：种群分岛隔离，防整体收敛进单一局部最优；迁移/重播种对应「防种群收敛进单一局部最优」（A：正文问题陈述）。
- **MAP-Elites**——组合启发的另一半：2506.13131 引用为灵感来源、**未展开其内部机制**（下钻需补调研，此处不臆造）。

**⚠️ 谱系边界（本课硬纪律）**：岛数、迁移周期、重播种阈值这类参数级规则，以及「周期性把跨岛最优交 LLM 杂交后回注」「停滞岛保留最优、其余重播种」这类具体操作——源出被引 **FunSearch（Romera-Paredes et al., Nature 2023）岛模型谱系**，2506.13131 仅引用、未展开（R1 标注：A = 正文问题陈述；C = 谱系细节回指 [83]）。**论文正文未载岛内按分淘汰/清底的具体规则。**你在别处读到「AlphaEvolve 岛内每 N 代清底」一类的说法，信源等级是 C 不是 A——本课把这些当谱系背景讲，不当 2506.13131 原文事实教；它们也是判分反锚点（不得据此判你会/不会）。

## 4｜消融实证：「No evolution」两任务 × 3 种子

你的课前直觉（轨迹在降低不确定性）在 §4 消融里拿到了实证托底。设计（A）：**两任务（矩阵乘法张量分解、kissing number 下界）× 3 随机种子**，两个消融臂：

| 消融臂 | 移除的是什么 | 结果 |
|---|---|---|
| No evolution | 不用进化数据库、**反复喂同一初始程序**——回浮/多样性机制整体移除 | 显著变差（A） |
| Small base LLM only | 单一小模型——去掉模型混合的采样多样性（这臂踩的是双模型，第 4 课展开） | 显著变差（A） |

论文结论原话："**each of the components is responsible for a significant improvement**"（A）——每个部件都各自扛着一块显著收益，数据库是其中被单独验证的一块。

**你来推 ③**：No evolution 臂里，LLM 被调用的次数没少、生成的候选量没少、评估也照跑——**少的是什么？为什么采样量不变、结果显著变差？**把你课前原话反过来用：你说「有效实验在降低不确定性」——这一臂里，每次采样还在降低不确定性吗？

（以下为 R1 的解读、非 2506.13131 原文，标注为解读）去掉进化/多样性后，搜索退化为**围绕单一初始程序的重复采样**，失去跨解回浮与变异来源。这正是你已会的「纯利用死胡同」的实证形态：prompt 里永远只有同一个程序，proposer 的变异素材枯竭——多样性死亡不是「搜索变慢」，是**新颖解来源死亡**。同样口径补一句你课前问题的代价半边：存储和 prompt 空间的代价是真的，消融证明的是收益侧——收益 = 跨解回浮 + 变异来源，恰恰是「No evolution」被拿走的那两样。

## 6｜对照钩子与原创视角：跨轮知识留存家族 + 美团知识库该存什么

**家族图谱（第 10/11 课钩子，埋点不展开）**：程序数据库不是 AlphaEvolve 独有的器官，它是「跨轮知识留存」家族的第一个成员——同族问题是同一个：**改进如何跨轮留存、且不退化**。

```
跨轮知识留存家族
 ├─ AlphaEvolve 程序数据库（本课）：三件套入库 + prompt 采样回浮
 ├─ GEAK 进化知识库（第 10 课）：「越用越聪明」
 └─ ForgeKernel 自晋升参照链（第 11 课）：通过验证 → 晋级参照
```

**美团原创视角（判断权在你，本课只摆选项不替你选）**：AlphaEvolve 存三件套，是因为它的 proposer 吃 prompt——**库存什么，由「消费者每一步能看到什么」倒推**。美团 RSI 的知识库就是同一道倒推题：你的 proposer（改 kernel / serving 配置 / 编排的 agent）每步看到什么？候选并列：

- **代码**（kernel 实现、serving 配置文件）
- **配置**（并行度、调度策略、批处理参数）
- **profile 证据**（NCU 指标、SOL 上界、瓶颈定位）
- **执行输出**（真实或回放流量下的延迟分布、吞吐曲线）

哪些进库、哪些带分数、哪些渲染进 prompt——这是第 21 课蓝图的一块，现在只需要带着一个问题回去：**在你的在线推理场景里，「执行输出」对应什么？分数由谁压出来？**（提示：第 2 课的判真协议就是分数生产端的候选答案。）

## 7｜本课关键概念清单

（自述检验用，一行一条——它们就是费曼轮的 expectation 清单）

1. 程序数据库三件套：代码 + 多维分数 + 执行输出，一并入库；淘汰长在入库步（级联早期失败剪枝、LLM 反馈不达标淘汰）
2. optimally resurface（最优回浮）：数据库首要目标；物理通道 = prompt sampler 采样 prior programs（带分数 + 完整代码）进 prompt
3. exploration/exploitation 张力：持续改进最优 vs 维持多样性——机制回答 = MAP-Elites + 岛模型组合启发（岛数/迁移周期/重播种阈值等参数级细节属 FunSearch 谱系，非 2506.13131 原文）
4. 「No evolution」消融：回浮/多样性整体移除 → 两任务 × 3 种子均显著变差——纯利用死胡同的实证形态
5. 进化对象 = 整代码文件（可达数百行、任意语言）+ EVOLVE-BLOCK 标注；evaluate 返回标量字典（约定最大化）
6. 闭环最简表达（收口边缘项）：数据库采样 → LLM proposer 产 diff → 评估 → 回注——proposer 是最简层，不可隐身
