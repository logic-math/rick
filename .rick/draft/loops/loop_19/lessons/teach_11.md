## 0｜从你的两答切入：留存家族分成了两个亚族

**a 的裁决位**（旧 kernel 经验怎么被新任务复用）。你的原话——「总结成知识，按操作手册总结成 md，供 AI 阅读」。这是**知识蒸馏框架**：经验 → 文本 → 读进 prompt。它不是错的——它正是留存家族的一个亚族：**知识文档**，GEAK perf_knowledge 静态参考库（第 10 课：只 seed 不裁决、自认「may be stale…not decisions」）就是它的工程形态。ForgeKernel 复用的是**另一个亚族：参照工件**——复用的不是「关于 kernel 的文字」，是**验证过的工件本身**（密封二进制，直接当下一轮的起点和基准）。你的答案恰好落在亚族一上，本课补亚族二；对照表＝§3。

**b 的裁决位**（从已验证专家 kernel 出发，差别是什么）。你的原话——「参照带来复用提高效率，但坏处在于依赖了一个并非最优的前提」。**两刀全中**：加速刀（复用提效）＋先验束缚刀（依赖非最优前提）。这两刀就是本课结构——§1 讲链怎么吃到加速、怎么把你的第二刀从「风险」变成「发动机」。

## 1｜自晋升参照链：机制（一课一事的主件）

链图（R §⑧ 机制段，A repo 自述）：

```
任务 N
  参照 kernel（密封二进制、已验证——链顶端）
    → 架构探测：跑 / 计时 / profile（不看源码，§2）
    → 生成「架构优先」的 milestone 课程（进化路线，§2 末）
    → coding agent 逐里程碑实现
    → 验证：不过 → 丢弃（参照不动，链不长）
    → 验证：通过 → 晋级为新参照（链顶端前移）
  任务 N+1 从新顶端出发 → ……（链无限延伸）
```

机制一句（费曼件①的靶子）：**新任务从已验证的链顶端出发；进化结果通过验证后自身晋升为新参照——参照不是给定的，是链自己挣来的。** ForgeKernel 的自我定位：不是「生成一个 kernel」（一次性交付，任务结束系统归零），而是「无限进化链」。用你第 3 课的原创类比：链是「数据库＝可遗传层」的另一种物理形态——可遗传的不是历史解集合，是**顶端工件本身**。

参照的两面＝你 b 答的两刀，逐刀落机制：

- **加速刀**：链的起点就是专家级实现（§4 战绩：被追平/超过的 18/22 个专家库 kernel——链的起点正是这些被超越的专家）。新任务不从空白探索，从已知最优出发——参照的复利面。
- **束缚刀的机制回答（两层）**：① **验证是参照的资格线**——晋升的唯一通道是通过验证；赢不过验证的候选连参照位都摸不到，所以「依赖的前提」至少是验证过的前提，不是噪声前提（连第 2 课判真：噪声候选连入场券都没有）。② **「非最优」在链里不是静态风险，是被持续挑战的动态状态**——链的每一代必须**赢过**参照才上位；参照若真非最优，链的结构保证它被下一代顶掉（这正是链的存在目的：「持续超越已知最优实现」）。你担心的「依赖非最优前提」在静态复用（拿参照当真理抄）里是锁死；在链结构里，参照只是**卫冕者**，不是真理。

留白一（你来推）：链的验证如果只能判「比参照快」，而参照本身过拟合了某个 shape 集——链会放大这个错误，还是纠正它？提示：第 1 课 OOD 缩水（选择压力只来自 verifier 所测分布）＋第 6 课幻象（验证分布⊂使用分布）。你来推：**链式留存对「验证面宽度」的依赖，比种群式留存（多岛多解分散下注）更高还是更低？**（repo 未覆盖——论文全文未获取，只能推不能引。）

## 2｜密封二进制探测：能力面而非源码面（与第 6 课源码审计的对照位）

参照物是密封二进制——专家库 kernel（cuDNN 等）本来就是闭源/不可读形态。ForgeKernel 的读法：**跑、计时、profile，不看源码**（R §⑧ A）。与第 6 课对照（同一张「看什么」的两面）：

| 维度 | 第 6 课·源码审计（对策位） | 本课·密封探测（机制位） |
|---|---|---|
| 看什么 | 候选的**源码**（语义层） | 参照的**能力**（行为层） |
| 源码在不在手 | 候选是自己产的，源码在手 | 参照是密封的，源码本来就没有 |
| 手段 | 读代码抓调框架算子/缓存输出 | 跑 / 计时 / NCU profile |
| 服务于 | 抓 reward hacking（快但错） | 学参照的能力结构 |

为什么参照**可以**密封（探测面足够）：kernel 的 verifier 本来就是行为面的——第 5 课路线 1 verifier＝编译/正确性/计时，客观可自动判定；要学的不是「源码怎么写」，是**它在硬件上展现的能力结构**（哪些 shape 快、occupancy/SOL 到哪、瓶颈在哪）——这恰好全是跑/计时/profile 可测的。第 9 课 CompileIQ 的 NCU 指标目标（occupancy、L1TEX）同族：profile 本来就是机器可读的能力语言。**「架构优先」的 milestone 课程**＝探测的产出物：把「超越参照」拆成按能力结构组织的有序里程碑（阶梯），coding agent 逐级实现——课程学习在进化系统里的迁移（弱相关接口，一句带过）。

代价（源码层知识丢失——两亚族互补的根源）：能力面看不到**实现路径**——这个 tiling/流水线结构**为什么**能达到这个能力，设计知识被密封吃掉。链只能「追平能力」，不能「继承设计」。这正是 §3 知识库存在的原因：**密封工件给能力参照，知识库补源码层知识**——两亚族不是二选一，是互补双通道。

## 3｜跨算子共享知识库：留存家族第五次登场＋两亚族对照表

机制一句：**硬件探针认证的结论沉淀进跨算子共享知识库**（R §⑧ A repo 自述）——A 算子的链上认证过的硬件结论，B 算子的链直接可用（「越用越聪明」，R 概念清单同词条）。

留存家族五次登场谱（一句话各，直引不铺垫）：① AlphaEvolve 程序数据库（第 3 课）——种群本身，分数驱动回浮｜② z.ai 骨架库（第 7 课）——蒸馏件｜③ CompileIQ Booster Pack（第 9 课）——预调工件目录注入起点｜④ GEAK KB 三物件（第 10 课）——搜索旁 advisory，add-only｜⑤ ForgeKernel（本课）——**参照工件＋知识文档双通道**。

本课在家族内引入的分裂——**两个亚族**（你 a 答的正是亚族一）：

| 维度 | 亚族一·知识文档 | 亚族二·参照工件 |
|---|---|---|
| 留存物 | 文本/结构化知识（你的「操作手册 md」／GEAK 蒸馏卡） | 验证过的工件本身（密封二进制顶端） |
| 复用通道 | 读进 prompt（第 5 课「专家知识上下文」那条） | 当进化起点＋验证基准 |
| 保真度 | 蒸馏有损——知识可能 stale（GEAK 自认「may be stale…not decisions」） | 工件无损——二进制跑起来就是它自己 |
| 失效形态 | 过时／以偏概全／笼死搜索（GEAK add-only 铁律防的就是这个） | 参照非最优／验证面窄（留白一） |

原创点连接（#14，判断权在你）：容器的选择不止种群/知识库二选一，是**种群＋知识库＋参照链三种容器的组合问题**——ForgeKernel＝「链（工件通道）＋库（文本通道）」，GEAK v4＝「控制面＋advisory 库」，AlphaEvolve＝「种群即库」；三者无 head-to-head（链与库的分工比例 repo 未给数据——如实打折）。

## 5｜与 Kernel Forge 辨析：一字之差，两个系统（引用纪律件）

- **Kernel Forge**＝arXiv 2607.24762，Clover Group，**MCTS 搜索树**（50 轮迭代真实模型上 1.52-2.83×，R §⑨ 已核 id）——第 13 课搜索策略动物园的主件
- **ForgeKernel**＝OpenBMB／ModelBest 智能演化实验室，**自晋升参照链**（本课），ICLR'27 在审
- 微信文章②同时覆盖两者（R §⑨）——二手综述是碰撞高发区。引用纪律：**核 arXiv id／组织名，不认词序**（与第 10 课 GEAK v1/v4 两代混标同族引用事故）。

机制层真差异（不止是名字）：MCTS 是**搜索策略**（单任务内，树怎么分配探索-利用）；自晋升链是**资产结构**（跨任务，搜到的东西怎么留下来当起点）。一个回答「怎么搜」，一个回答「留什么」。第 13 课把 Kernel Forge 拉回搜索轴正面讲；本课的链留在留存轴。

## 7｜关键概念清单（你当老师前的自检表）

1. 自晋升链一句：新任务从已验证链顶端出发→进化→通过验证→自身晋升新参照→链无限延伸（参照是挣来的，不是给定的）
2. 「通过验证才晋升」＝对「非最优前提」风险的机制回答：验证是资格线＋每代必须赢过参照才上位（非最优＝被持续挑战的动态状态，参照是卫冕者不是真理）
3. 密封二进制探测：跑/计时/profile 读能力面、不看源码（verifier 本来就是行为面，故可密封）；代价＝源码层设计知识丢失→知识库亚族补位；milestone 课程＝「架构优先」的能力阶梯
4. 两亚族：知识文档（蒸馏有损、stale 风险）vs 参照工件（无损、非最优/验证面窄风险）——互补双通道
5. Kernel Forge（MCTS，2607.24762，Clover）≠ ForgeKernel（自晋升链，OpenBMB）——一字之差两个系统，核 id 不认词序
6. 信源折价三层：repo 自述 A／论文在审未公开／直播数字 B；判真档位「过程透明、协议未见」
