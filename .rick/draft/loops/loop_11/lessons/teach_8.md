# 第八课 · 推动同事 + 原创点从哪找

## 承上：第七课算出「幅度只能自己量」，这一课问「量出来的东西凭什么让别人跟你一起做」

前七课把论文讲完了，也把你在美团的站位摆出来了：级联要留、只改实现（第一课）；谁共享谁隔离（第二课）；一致性来自联合训练与模型内蒸馏、设计是容量的函数（第三课）；召回并进同一个模型、目标从外部路由变成决策前缀加在线偏移（第四课）；靠 MoE/μP/SNT 三引擎继续长（第五课）；一张「美团现状 vs OneTrans 全级联统一」的差距表（第六课）；收益口径的纪律——外部数给方向、给不了幅度（第七课）。

你在 judgment 里把最后一道门槛说得很直白：「我们其实已经基本做了相似的事……但想在美团拿到资源，不仅要认可这个论文，还要提出一些差异化的点，做出这件事后还要能发论文，因此需要有一定的原创性。关键就在于想出这个原创点。」（judgment 直觉 3）

这一课只讲这一件：原创点从哪找，以及为什么「原创点」本身就是推动同事的那根杠杆。（前七课的追问你都跳过、直接推进了；这一课的追问不挂在论文上——挂在你的场景上。）

## 先看一个已经找到缝隙的人是怎么找的

论文没写动机，所以下面凡是我重构的都标「重构」；事实部分逐条引注。

他面对的位置已经挤满了人。2026 年生成式推荐这条线上能站的位置大致两个（下面两条是他取舍空间的摆法，属**重构**）：**端到端生成**——一个模型直接从上下文生成最终结果、级联本身被删掉，更激进、更容易被写成「新范式」；**全级联统一**——级联结构原封不动，把三段 task 塞进一个 backbone，听起来只是「工程合并」，不新。

他手里有一条硬事实把取舍钉死了：**移除候选特征会显著降低推荐质量**（论文 §1/Fig.1，A；V1 你已裁决接受）。这条事实意味着：端到端那条路上「候选特征不再逐阶段进模型」是它的设计前提，而这个前提在他的生产环境里不成立。

于是他做的动作不是「挑一条更原创的路」，而是**换一个找缝隙的方向**：别人问「哪个机制还没人做过」，他问「哪条路别人走不了、而我能走」。答案是「保留级联的全级联统一」——它听起来不新，恰恰因为它是被约束筛剩下来的那一格、是端到端路线主动放弃的那一格。

## 他这一格的「新」不在「统一」，在统一之后别人没做的三件事

「统一」本身不构成原创：MTGR 已在单阶段排序上统一过（research_1 · B，#12，HSTU、CIKM 2025、2025-04 全量），前作 OneTrans 已在粗精这一段统一过（arXiv:2510.26104，WWW 2026，research_1 · A，#3）。他的新意落在三件「保留级联才需要、也才有意义」的事上：

1. **把「隔离」从模型间降级到模型内，同时保留候选特征**——共享的是每请求只编码一次的 shared user context，隔离的是 stage token + visibility mask，候选特征靠混合参数化（承 OneTrans）继续逐阶段进模型（research_1 · A，#5，§4.1）。这一步是「保留级联」逼出来的：允许删级联，就不需要 mask。
2. **跨阶段一致性靠模型内蒸馏对齐，不是复用算力自动得到**——精排当 teacher、粗排在同 backbone 里当 student，mean-centering + τ=0.5，同一份计算图、同一次反向传播（research_1 · A，#6，§4.2.2）。
3. **统一之后还能继续长**——SNT 按用户窗口分组曝光，序列每窗口只编码一次、各曝光以因果视图复用（请求相对 RoPE 时间编码），训练 4.4×、序列特征存储 −95%（research_1 · A，#9，§4.4/§7.9）。入口不是改架构，是改训练数据的组织方式。

三条都是**论文已做**，不是缝隙。它们给你一个校准点：**「在一格里做出新意」不是发明新名词，是在别人放弃的那格里把别人没做全的事做全。**

## 第一条可抽出的原则：原创点不在「别人没想到的机制」里，在「别人必须放弃的约束」里

（这条是我从他这个案例里抽的读法，不是论文的话。）

机制类原创点需要「没人想到」，而方向上参与者越多，没人想到的机制越少——2016 年可以是 Wide&Deep，2026 年很难再有一个「谁都没试过的结构」。约束类原创点需要的是「别人做不了」，而约束是**你的**生产事实给的，别人复制不了你的约束。**别人做不了的位置不靠抢，靠位置本身。**

前提先说破：**约束必须是真的、且别人认得出、认了会点头。** V1 那条之所以能当缝隙地基，因为它是可测量的生产事实、不是口味；如果约束只是一句「我们系统比较特殊」，那不是缝隙，是自我设限。分辨很朴素：**这条约束能不能被一个线上实验证伪？**

## 你手里的缝隙土壤：research 的缺口清单，先按来源分四类

第六课差距表的 ❓ 格与 research_1 的 Gaps/R7 就是土壤。但土壤不等于种子——按**缺口来源**分类，四类性质完全不同：

| 缺口（引注） | 来源 | 性质 |
|---|---|---|
| item-side classifier-free guidance（权重 w）论文明示**未部署**、留待未来工作（research_1 · R7） | 论文自己留的 | 作者认为有价值、当前不必要 |
| SNT 按天切窗口与美团数据/评估口径的兼容性未明（research_1 · R7） | 论文做了、你的场景未验 | 迁移问题 |
| 字节 vs 美团的召回通道数量/粗排特征集/业务目标组合差异，论文未覆盖（research_1 · Gaps） | 论文做了、你的场景未验 | 迁移问题（差异大到机制要重定义，则升级为原创） |
| §7.1 联合训练隔离被第三方（Pith）C 级质疑（research_1 · R7） | 论文做了、可信度未定 | 验证问题 |
| 无代码/权重/数据；无确切参数量/专家数/层数/序列长度（research_1 · R7/Gaps） | 论文做了、你复现不了 | 复现问题（不发论文，只发工单） |

第一用法是**排雷**：最后一行最诱人（「我可以自己搭一遍」），但产出的是工程能力不是论文——补上它，你得到的是别人也能得到的东西。第四行（§7.1）反过来可能出论文，但地基是 C 级线索，你得先把它升到 A/B 级才敢站上去。

第二用法才是找种子：真正能长成原创点的是**第二、三行那种「论文做了，但做它的前提跟你不一样」的格**——机制已存在（不用从零发明），前提不同（别人复制不了你的位置）。

## 一个先说破的陷阱：「论文没做」不等于「值得做」

（本课要你判的第一件事，我不替你判。）同一张清单上，「论文没做」有两种原因：**不值得做**（作者试过/判过，收益不抵代价，所以没写进主线）与**没法做**（缺口的解决依赖作者手里没有的东西，比如你的场景）。清单本身分辨不了这两者。两条判据并列，用哪条是你的判断：

- **判据甲 · 是否连着一条你的生产硬事实**：能写成「在我这里，不满足 X 就会掉 Y，Y 可测」的，是约束类缝隙；连不上，可能只是你没做到位。
- **判据乙 · 补上它是否需要新开一套系统**：能落进同一个 backbone/同一套训练组织的，是「格子」；要求另起数据管线或另一个模型族的，代价与推动难度跳一档（第六课甲/乙/丙/丁的差别正在这里）。

## 四个候选，并列摆着（不替你收敛）

四个都从 research 的事实出发，各标**论文已做 / 论文没做**、可能成缝的原因与代价。四个不互斥，分别落在第六课四条路线（甲全级联、乙一致性、丙调控、丁架构族）的延长线上。

### 方向一 · 架构族：在 HSTU 骨架上做，还是往因果 Transformer + SNT 走

**已做**：一个因果 Transformer 承载三段 task（research_1 · A，#5）；SNT 用「请求相对 RoPE 时间编码」把同一窗口的多次曝光复用成因果视图（A，#9）。
**没做**：论文没回答「复用收益里多少是架构族给的、多少是数据处理给的」——它的 backbone 只有一族。
**你的起点**：MTGR 用 HSTU 且已全量（B，#12）。

可站的一格：SNT 的核心动作（按窗口分组、序列每窗口只编码一次）看起来更像**训练数据的组织方式**，「请求相对 RoPE 时间编码」才是注意力层的耦合点——那么可问：**把这套窗口复用搬到 HSTU 骨架上，收益还在吗？**（这个拆法是我的推断，论文未做该解耦实验——所以它同时是缝隙与风险：你可能花力气证明「不在了」。）按 V3（设计是容量的函数，你已接受；见第三课、research_2 · #12/#13），这不是「谁更先进」的通用比较，是「在你的容量点上谁更合适」。代价：换族等于动 MTGR 底座，推动阻力最大。

### 方向二 · 召回统一：把决策前缀 + 生成式召回搬进美团的多路召回

**已做**：DCGR 先预测 4 维决策前缀（z_oc 购买 / z_aov 消费 / z_disc 新颖 / z_ad 供给，构成见 research_2 · #1），再自回归生成 3 层 SID（RQ-KMeans，每层码本 8192）（research_1 · A，#7）；召回多目标被从多个外部通道内化成模型内部的决策分布（V6，你已接受）。
**没做**：论文没告诉你它的召回**起点**是几个通道——字节侧召回通道数量/各通道目标/特征集，材料未覆盖（Gaps）。
**你的起点**：MTGR 统一的是排序这一段（B，#12）；你们融合的是粗排与精排（judgment 直觉 3）；召回是否仍多通道、多少个——第六课那格仍是 ❓，只有你能填。

缝隙在「**从多通道起点做统一**」这个论文没做过的动作上（不是「用生成式召回」——DCGR 已把机制做完）：论文起点是同一套级联，你的起点是一组各有专精的通道。把「各通道的专精」折叠进「一个模型内的决策空间区域」（V6）而不掉专精，论文没回答；成不成立，取决于你那些通道的目标组合能否被一组决策维度重构。**若你的目标组合（大纲模块八列的 GMV/供给/履约这类维度——仍属待你确认的美团侧事实，第六课「目标组合」那格是 ❓）与字节的购买/消费/新颖/供给不同构，那决策前缀的维度定义本身就要重设计**——这是机制级而非迁移级的改动。代价：同时动召回结构（SID 检索索引）、训练组织、调控链路，且要先补第六课表里最多格。

### 方向三 · β·φ(z) 的美团多目标化：从一根旋钮到几根旋钮

**已做**：打分 = log P(z|H) + β·φ(z) + Σ log P(SID_ℓ|…)，偏移**只加在决策前缀分数上、不动物品项**；φ(z)=Σ_j φ_j(z_j) 跨维度求和；β 是**单一标量**，在线可调、β=0 一键恢复模型自身排序、无需重训（research_2 · A，#5–#8）。它的数学身份是 KL 正则 improvement step：q(z) ∝ P(z|H)·e^{βφ(z)}，φ 扮演业务价值/优势函数、β 是逆温度（research_2 · A，#7）。
**没做**：论文只用**一个** β，没有按维度的版本，也没给弱/中/强 β 的具体取值（research_2 · R7）。

缝隙候选：**多目标可能需要多根旋钮。** 单标量 β 把 φ 的所有维度一起推动（φ 的跨维度求和定方向、β 只定强度），于是「先推供给、GMV 不动」这类要求没有旋钮可拧。把 β 扩成 β_j（q(z) ∝ P(z|H)·e^{Σ_j β_j φ_j(z_j)}）形式上很靠近原式，但论文没做。取舍：正向看几乎免费（φ 本就按维度求和，research_2 · #6），代价低、偏工程；反向看，「几乎免费」也正是风险——**改动越小，越难说它够原创**。它够不够撑一篇论文，取决于你把它当「一个可调项」还是「一套多目标治理机制」（后者要回答：β_j 互相拉扯时怎么定标、谁定 β_j 的相对大小——V6 那个「决策空间区域」在治理层的延伸，论文没碰）。

### 方向四 · 容量切换点：多模态 embedding 直喂，还是先过 SimTier

**已做**：§7.8 给了一条原则——多模态 embedding 直接喂进模型「**仅在容量充足时**」有利（相对 SimTier 直方图这类压缩表示）；「容量」指模型容量（参数量/表示能力），不是 GFLOPs、不是序列长度（research_2 · A，#12）。V3 你已接受（「符合具体问题具体分析的哲学观」），机制见第三课与 research_2 · #13。
**没做**：论文把「设计是容量的函数」讲成原则，但没给切换点任何数值——§7.8 未给参数量/层数/专家数/宽度因子（research_2 · R7）。

缝隙候选：**原则与操作点之间那段是空的。**「容量充足」在论文里是定性判据；在你这里可做成可测判据——什么容量/什么表示维度/什么模态组合下，直喂开始赢过压缩表示。论文不做这一步，因为它不需要（它是做设计的人，不是那个要判断「我的规模该用哪套」的人）。**V3 的原创缝隙正好在这里**：把 V3 这条规范性结论变成切换点，是把一个判断经验变成一份可复用的测量。取舍：产出偏「实证报告/测量方法论」，分量取决于能否做成**可被别的规模复用的判据**（切换点随容量变化的曲线，而非一个孤立阈值）；只给阈值，容易被读成「一次调参记录」。代价低（不动在线链路），推动阻力也小，甚至可作主线并行的小课题。

## 推动叙事：你已有的实践是筹码，不是障碍

（回答 judgment 直觉 3 的前半句。下面几种叙事并列，用哪种、混用还是都不用，是你的判断。）

先落到硬事实：**MTGR 已在美团全量、用 HSTU（research_1 · B，#12，CIKM 2025 + 官方博客，2025-04 全量）；你们已把粗排和精排融合、精排复用一部分粗排算力（judgment 直觉 3）；而且——是论文在 §2.1 里引 MTGR，不是 MTGR 引这篇论文（B，#12）。** 三条合起来是一个位置：**你们站在这条路线的上游，不是在下游追。**

在这个位置上，同事的阻力往往不是「不认同」，而是三句具体的话：**「这事 MTGR 已经做过了」「又要学一套新东西」「做出来能拿到什么」。** 对应几种叙事：

- **甲 · 补台阶（对「已经做过」）**：MTGR 统一的是**一段**（排序），OneTrans 统一的是**全程**（召回+粗排+精排），你们融合的是**算力**、论文对齐的是**分数**（第六课差距表的「统一范围」「共享粒度」「跨阶段一致性」三行）。落点不是「从零学一个架构」，是「在已融合的粗精上补一个台阶」。第六课那张表就是这个叙事最好的道具——同事能自己核，不用你先说服。
- **乙 · 上游位置（对「怕落后」）**：论文引我们（§2.1，B），方向是我们先走的；把已有的往前推一格，比换一套新范式更省、也更像我们的东西。
- **丙 · 原创点当资源钩子（对「能拿到什么」）**：你 judgment 那句话本身就是闭环——**认论文 + 差异化点 + 能发论文 = 资源**。抓手不是「这篇论文很好，一起做吧」，而是「我们有别人没有的缝隙（方向一到四里的某几格），做出来就是一篇别人发不了的论文」。**别人发不了不是因为聪明，是因为那个缝隙在你手里（美团的召回通道/目标组合/SNT 口径，research_1 · Gaps/R7）。** 这把「推动」从说服变成交换：同事出的力，换一篇他署名、外部做不出来的工作。
- **丁 · 先量后动（对「不确定性」）**：先不承诺架构改动，只承诺「把差距表那几个 ❓ 量出来」——量出来的数本身就是可汇报的产出（第七课纪律：幅度只能自己量）。用它换时间与人力，再决定动不动主线。

有形收益收口：**四个并列差异化候选**（架构族 / 召回统一 / β 多目标化 / 容量切换点）+ **一个推动叙事**（已有实践是筹码，抓手是「我们的缝隙 = 别人发不了的论文」）。两样都在上面——选哪个、按什么顺序，是你的判断。

## 追问（把你的判断逼出来，不是考你）

（前七课的追问你都跳过；这四个不挂在论文上——挂在你的系统、你的人力、你的同事身上。）

1. 四个候选里若这一轮只能先动一个，你会拿哪个判据排序——「机制已存在的比例」（越快出结果）、「改动的系统面积」（越省推动成本）、「能不能独立成一篇文章」、「是不是主线的必经一格」？你会排出怎样一条顺序？什么会让你改变判断——比如方向三在自己流量上实测下来、按维度 β_j 与单 β 的在线差异落在噪声里，你是把它降为「顺带做的事」，还是认为它恰好证明了「多目标在这里不是主要张力」、从而改推方向二？
