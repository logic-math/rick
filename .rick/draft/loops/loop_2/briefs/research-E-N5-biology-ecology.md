# N5 生物学/生态学视角 — rick 迁移到 pi agent

## 视角名:内共生 + 生态位 + 中枢外周神经分工

## 来源理论(任务派发指定 + 公认知识)

### T1:共生理论(Symbiosis — de Bary / Margulis)
- **共生**(symbiosis):不同生物长期共同生活。包括互利共生(mutualism)、偏利共生(commensalism)、寄生(parasitism)。
- **内共生(endosymbiosis — Lynn Margulis)**:一种生物**进入**另一种生物体内,成为其细胞器。例如线粒体起源于被真核细胞吞噬的细菌,后成为永久细胞器。
- **关键洞察**:重大进化常通过"内共生"而非"渐进突变"实现。一个生物成为另一个的"器官",边界从"两个个体"变为"一个整体"。
- **内共生 vs 外共生**:内共生 = 共生体进入宿主**体内**(物理嵌入);外共生 = 共生体在宿主**体表**(物理分离)。

### T2:生态系统理论(Ecosystem Ecology)
- **生态位**(niche):物种在生态系统中的"职位"(资源 + 关系)。Hutchinson 的 n 维超体积模型。
- **资源竞争**(resource competition):物种间争夺有限资源。竞争排斥原理(competitive exclusion,Gause):完全同生态位的两个物种不能长期共存。
- **生态演替**(succession):生态系统随时间从简单到复杂的演化过程。先锋物种 → 顶极群落。
- **关键洞察**:物种的"价值"取决于其在生态位中的不可替代性。

### T3:神经科学(Neuroscience — 中枢 vs 外周)
- **中枢神经系统**(CNS:脑 + 脊髓):决策、整合、记忆。
- **外周神经系统**(PNS):感觉神经(传入)、运动神经(传出)、自主神经(交感/副交感)。
- **反射弧**(reflex arc):感受器 → 传入神经 → 中枢 → 传出神经 → 效应器。短反射不经过脑(脊髓反射),长反射经过脑。
- **关键洞察**:分工 = 中枢负责"高层决策",外周负责"快速反应"。中枢不直接控制每个肌肉,而是设定目标,外周自主执行。

## 事实支撑(引用 R1-R8)

### 内共生映射(T1)
- **外共生(现状)**:rick 和 claude code 是两个独立进程,通过 NDJSON stream 通信。rick 在 claude code "体外"。共生的边界 = 进程边界 + 协议边界。
- **内共生(迁移后)**:rick 的逻辑通过 pi extension **进入** pi 进程内部(Node.js require 同进程,R8-N3)。rick 的 doing_check / easy_check / TDD 门禁成为 pi agent loop 的"细胞器"。
- **human Y8 确认**:"内嵌是内嵌到 agent loop 内部,是 pi 的扩展内部"——这是内共生的精确定义:rick 进入 pi 体内。
- **human Y11 确认**:"所有反馈性的,检查性的门禁都做成扩展内嵌到 pi 中"——门禁从"外部检查"(外共生)升级为"内部细胞器"(内共生)。
- **R8-N3 事实**:pi extension 是同进程(Node.js require),而非 VSCode 式 extension host 进程隔离——这是物理嵌入,不是协议通信。内共生的物理基础成立。
- **R4-N3 事实**:pi 5 类 compaction 自定义扩展点(session_before_compact / session_compact / ctx.compact / before_agent_start / transformContext)——这些是 pi 暴露的"细胞器插槽",rick 注入逻辑成为细胞器。

### 生态系统映射(T2)
- **生态位**:rick 当前生态位 = "AI Coding Framework"(plan/doing/learning 三阶段 + skill/loop/domain 知识体系)。claude code 生态位 = "通用 coding agent"。两者生态位**部分重叠**但 rick 有独特维度(三阶段工作流 + domain 知识)。
- **竞争排斥**:如果 pi 自己发展出 "plan/doing/learning" 等价能力,rick 的生态位会被挤压。但 human 决策 "后续不再支持其他 agent" + "rick 深入 agent 内部" = rick 选择**与 pi 共生**而非与 pi 竞争。
- **生态演替**:rick 的 v2.9.0 架构迁移(删除 wiki/tools/SPEC.md,重构为 loops/skills/domain)= 一次生态演替(先锋物种 → 顶极群落的简化)。迁移到 pi 是又一次演替——rick 从"独立框架"演替为"pi 的共生体"。
- **R7-N4 事实**:pi 25 项功能映射——rick 现有功能在 pi 生态位中找到对应位置(8 完全等价 + 5 部分等价 + 9 需适配 + 1 需新建 + 5 pi 增强)。这是生态位重叠的量化。
- **V3 skill allowlist 注册** = rick 控制 pi 的 skill 生态位(哪些 skill 可"定居")。

### 中枢外周神经映射(T3)
- **中枢 = rick**:plan(决策)/ dream(整合记忆)/ learning(学习)——这是 CNS 的功能。
- **外周 = pi**:agent loop 执行 LLM 调用 + tool 执行 = 反射弧的"效应器"。tool_call 事件 = 传入神经(感知),tool_result 注入修正 = 传出神经(反应)。
- **反射弧**:LLM 决定调用 tool(刺激) → tool_call 事件(传入) → rick extension 检查(中枢处理,可选) → tool 执行(效应器) → tool_result 事件(反馈)。短反射 = rick 不注入 extension(pi 自动执行);长反射 = rick 注入 TDD 门禁(经过中枢)。
- **R7-N5 事实**:V1 TDD 门禁 = 长反射弧(经过 rick 中枢检查);现状 claude code = 短反射(无中枢介入,直接执行)。
- **V5 subagent 递归** = 神经系统的层级结构(脊髓 → 脑干 → 大脑皮层的层级反射)。

## 独特偏见

1. **偏见:生物决定论**。内共生是**亿万年演化**的结果,rick-pi 是**人为设计**的系统。把内共生套用到工程,可能忽视"设计意图"与"自然选择"的本质差异——内共生是**无目的**的,迁移是**有目的**的。
2. **偏见:忽视权力不对等**。共生理论假设共生体是"平等"的(或至少是自然关系),但 rick-pi 关系是权力不对等的——pi 定义 extension 契约,rick 只能遵守。这是"宿主霸权"。
3. **偏见:忽视死亡**。生物共生体可能"死亡"(线粒体功能障碍 = 细胞死亡),但软件系统的"死亡"是不同的(可回滚/可重启)。把生物隐喻套用软件,可能夸大"系统崩溃"的不可逆性。
4. **偏见:和谐主义**。共生理论倾向强调"互利",但实际共生关系中常有**冲突**(共生体可能转为寄生)。rick 注入 extension 是否可能"寄生" pi(消耗资源而不贡献)?这个风险被和谐主义掩盖。

## 3 启发性问题

### Q1(信念追问)
**这个视角的核心信念是"内共生 = 共生体进入宿主体内"。但内共生在生物学中是**宿主吞噬**共生体(宿主主动),还是**共生体入侵**宿主(共生体主动)?rick 迁移到 pi,是 pi "吞噬" rick( pi 提供 extension 插槽,rick 被动填入),还是 rick "入侵" pi(rick 主动把逻辑注入 pi loop)?这个主动权归属,是否影响迁移后 rick 与 pi 的权力关系?**

### Q2(前提追问)
**这个视角的前提是"内共生是稳定状态"。但内共生在生物学中经历**亿万年**才稳定(线粒体整合耗时 20 亿年)。rick-pi 的内共生( extension 内嵌)是否真的能快速稳定?pi 20 天 9 版本的快速演化(R8-N4),是否意味着"宿主"在快速变化,共生体(rick extension)难以稳定适应?内共生是否需要**宿主先稳定**?**

### Q3(反例追问)
**反例:生态系统的"竞争排斥原理"说"完全同生态位的两个物种不能长期共存"。迁移后,rick 和 pi 都做"agent 执行"——rick 的 doing 阶段启动 pi,但 rick 自己也有 doing_check / easy_check 等"agent 类功能"。rick 和 pi 是否在"agent 执行"生态位上**部分重叠**?如果 pi 未来发展出等价的 check 能力,rick 是否会被**竞争排斥**(被 pi 吸收或淘汰)?这个视角下,rick 如何保持生态位的**不可替代性**?**
