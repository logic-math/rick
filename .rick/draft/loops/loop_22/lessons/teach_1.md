## 0｜从你自己的话接入

你在探针作答里说过一句话（judgment.md，2026-11-02）：

> 「如果在线请求和离线测试请求到达时间的分布不遵循相同的分布，那么测试的差异会比较大。」

这句话就是今天这个概念的前半段。你已经机制级地知道：**测量环境的分布 ≠ 真实环境的分布时，测出来的结论不可迁移**。压测流量到达是泊松、线上高峰是突发长尾——你在离线 benchmark 上调到最优的 serving 策略，到线上就不是那回事。这个「分布不一致」就是 OOD（out-of-distribution，分布外）的内核。

你缺的是后半段：**当一个进化式改进 loop 的选择压力，长期只站在分布的一侧，这个错位会被放大成什么**。单次测量遇到分布错位，结论作废重测就行；进化 loop 遇到分布错位，会把错位本身变成被选择、被传播、被逐轮积累的「改进」。这就是 OOD 缩水——你在探针 2 里明言不理解、且整题缺失的那个概念，恰好是 10 份新材料里三处反复踩的公共承重语言（RRSI 的存在理由、FlashRSI 的 far-OOD 迁移列、批评层的过拟合指控）。

## 1｜一句话定义（事实层）

**OOD 缩水**：进化式改进 loop 在它训练/进化所用的任务上分数持续上涨，在未见的（OOD）基准上分数缩水、极端情况下归零。成因：被进化保留下来的提案**过拟合了任务的特有模式**——改进本身是真实的，但绑定在那个特定分布上，不迁移。〔R 概念清单「有效性/可信度」簇；R §⑤〕

先看它发生在 loop 的哪个位置：

```
提案（对 harness / 代码的编辑）
  → 在训练任务上评估（verifier 打分）
  → 按分数选择、保留、传播
  → 下一代提案在「已被选择塑造」的基础上继续
  → ……轮次往复

关键：选择压力只来自训练任务——未见基准不在环内。
```

再看它的典型形态：

| 观察面 | 无约束进化的走向 |
|---|---|
| 训练任务（进化 split） | 分数持续上涨——真实、可复现，**不是**测量噪声 |
| 未见基准（OOD） | 分数缩水，极端情况归零 |

注意第一行那个加粗的「不是」：这是这个概念最容易误读的地方，第 3 节会专门处理。

## 2｜发生机制：选择压力只测一个分布

概念背后有一群真实的人真遇到过它。把他们的思考过程还原出来，比背定义有用。

RRSI 的作者（Google Cloud AI Research，arXiv 2609.24972，v1 2026-09-21 / v3 2026-10-04）〔A〕做的事是 harness 自进化——冻结模型权重，让 loop 去改模型外围的可编辑部件（prompt、skill、工具、记忆这类，也就是你已经机制级掌握的 harness 8 类部件）。他们面对的现象是：**无约束的进化在训练任务上大涨，一到没见过的基准上就缩水、甚至归零**〔R §⑤，论文动机自述，A〕。

追问下去，为什么？他们的推理链大致是：

1. harness 进化的选择压力，完全来自 verifier 打的分数。分数高的编辑被保留、被传播到下一代。
2. 而这条路线的 verifier 是 **benchmark 分数**——谱系总判断对路线 2 的定性原话：「路线 2 的 verifier 是 benchmark 分数，存在过拟合与评测可信度问题（批评层集中于此）」〔A/B 综合，判断句而非单源事实〕。
3. 能在训练任务上抬分的编辑有两类：**通用改进**（真的让 agent 更能干）和**任务特有模式**（吃透了这批任务的 quirks——测试用例的形态、基准的评分习惯、题面的捷径）。对选择压力来说，这两类毫无区别：都表现为分数上涨。
4. 进化每轮都在选择。轮次一多，任务特有模式被逐轮积累、放大——因为它们和通用改进一样高分，一样被传播。

这第 4 步你应该觉得眼熟。你自己的话（第二轮作答）：

> 「我认为 benchmark 奖励了坏的优化，且这个坏优化被传播出去，造成系统性错判。」

同一条传播机制，你已经用它描述过噪声累积。OOD 缩水是它的另一个实例——区别在传播的东西**不是「错」的，而是「真但不通用」的**：它在训练任务上的分数是真的、可复现的，所以任何「验一下是不是真改进」的检查都拦不住它。

到这里，作者们把一个旧镜头移了过来：ML 里早就有一个词描述「训练分涨、测试分掉」——过拟合。训练任务就是训练集，未见基准就是测试集。但 harness 进化比普通训练多一层：它的「训练」就是逐轮选择本身，**选择压力越有效，任务特有模式被积累得越快**。于是矛盾显形：进化需要选择压力（没有压力就没有方向），而压力只来自一个分布（压力越大，绑定这个分布越深）。他们的回答不是去掉进化，而是把约束装进进化的两端——正则化。这是 RRSI 的全部存在理由；它两端各装了什么，留到第 15 课。

## 3｜与你已会概念的两处精确区分

这个概念之所以值得单独补一课，是因为它长得像两个你已经会的东西，但都不是。误认会导致防御选错。

**区分一：OOD 缩水 ≠ 噪声累积→系统性假阳性。**

你已经机制级掌握噪声累积：0.5% 级的测量波动在逐轮接受下累积，loop 优化的是噪声不是目标——你在第三轮还给出了风险不对称的表述：「错误传播的风险远高于错失最优解的风险」。这套直觉防的是**分数是假的**。

OOD 缩水里，分数是真的。训练 split 上的涨分是可复现的真实改进，重跑还在，方差为零都拦不住它。问题不在分数的真假，在**分数测的是哪个分布**。判别问题因此从「这个增益过得了噪声阈值吗」变成「这个增益在未见分布上还存在吗」——前者你有完整协议直觉，后者是本课新装的语言。

**区分二：OOD 缩水 ≠ 你已会的两种失败模式。**

你的两失败模式：快但错 → 正确性 gate 拦截，拦不住就错误传播；正确但慢 → 停滞。注意这两个模式的共同前提：**verifier 测的是对的东西**——错有错的信号，慢有慢的信号。

OOD 缩水是第三种：候选在训练任务上**正确且快**，两道 gate 全绿，照样是坏候选。因为正确性 gate 和性能信号都在同一个分布上测。两失败模式里 verifier 测对了指标也可能被骗（那是第 6 课的 reward hacking）；OOD 缩水里 verifier **测对了指标、测错了分布**——不需要任何欺骗行为，诚实优化也会走到这里。

填空（第 3 节收口）：一个候选在训练任务上正确且快，两道 gate 全绿——由此可以得出它对未见任务______？（一个词填完，这句就是区分二的全部。）

## 4｜RRSI：这个概念的一次实测（数字给满，机制留给第 15 课）

RRSI 就是「给 harness 自进化加正则化、治 OOD 缩水」的那篇。按 R §⑤ 尽调所载〔A〕，事实层一次给满：

- **对象**：8 个基准（编码 / agentic 工作区 / 工程设计三类）上的 harness 自进化
- **存在理由（动机陈述）**：无约束进化在训练任务上大涨、OOD 基准上缩水甚至归零
- **正则化后的结果**：进化 split 最高 **+6.0 分**；5 个 OOD 基准最高 **+4.3 分**；产出的 harness 比无正则进化**省 30% policy token**
- **诚实读法**（R §⑤ 局限节原意）：① OOD 增益仍是「最高 +4.3 分」量级——绝对值不大。② 正则化超参（退火节奏、prune 阈值等）本身是新的设计面：治过拟合的手段自己引入了新自由度。③ 「+4.3」是 RRSI 正则化后在 OOD 侧的最高分；无约束基线在 OOD 侧的具体分数 R 未抄录，「归零」出自论文动机陈述——两者不在同一张对照表上，别把它们读成「从归零拉到 +4.3」的实测差值。

机制细节（时间退火预算、进化史鼓励未探索轨迹、critic 筛 benchmark 特有提案、pruner 删琐碎改动）一个都不展开——那是第 15 课的正文。本课只取它作一件事的存在证明：**OOD 缩水真实发生在 2026 年的 harness 自进化系统里，且正则化是已被实践的一条防御路线。**

## 5｜防御三件与两个留白

通用防御就三件，名单给你，一件一句结构——**为什么它们能对抗第 2 节那个成因**，推导留给你：

| 防御 | 结构（一句） | 它切断了成因链的哪一环？ |
|---|---|---|
| 进化-保留拆分 | 选择用的任务与检验用的任务分离；保留任务从不参与选择 | （你来推） |
| 正则化 | 对提案与选择加约束，抑制任务特有模式存活（RRSI 是代表） | （你来推） |
| 独立验证集 | 在从未参与进化的基准上做独立判定，作为接受与否的最终门槛 | （你来推） |

**你来推 ①**：进化-保留拆分里，「保留任务从不参与选择」是整件防御的承重点。如果保留任务以任何形式渗回了选择——哪怕只是拿它淘汰最差的候选——拆分还成立吗？loop 会往哪个方向退化？（提示：回想第 2 节第 3、4 步——选择压力对「分数上涨」是不分类别的。）

**你来推 ②**：你自己的部署协议（第一轮原话：「我会在大规模的 auc 上离线验证他的正确性，然后在部署到线上，以实际流量开实验观察全链路耗时的变化」）在结构上更接近三件中的哪一件？它和教科书形态差在哪一环？（这个推导没有标准答案，但答案会成为你后面给美团 RSI 做 verifier 设计时的自有素材。）

三件的关系不是互斥替代，也不是叠加越多越好——每件都有代价（保留任务牺牲了选择可用的信号量；正则化引入超参设计面，RRSI 自己承认这一点；独立验证集有评测成本与「验证集也会被过拟合」的下一层风险）。**哪个进美团 loop、以什么形态进，是你的设计判断，本课不替你收敛。**

最后一处值得现在就点亮的结构：谱系总判断说路线 1/3 的 verifier「客观可自动判定（编译、正确性、计时、吞吐）」、loop 最稳〔A/B 综合〕——但「客观」解决的是**指标真假**，不自动解决**分布错位**。你自己的离线压测 vs 线上灰度差异就是例证：吞吐是个完全客观的量，压测流量分布不等于线上流量分布时，它测的是一个真实却错位的分布。路线 2 的 benchmark 分数如此，路线 3 的离线吞吐也如此——这个观察留给你，它会直接接到第 21 课的美团 verifier 设计。

## 6｜本课关键概念清单（自述检验用）

学完这一课，下面 6 条你应该能不看笔记各用一两句自述——它们就是下一轮判档的 expectation 清单：

1. **OOD 缩水**：进化 loop 训练任务分涨、未见基准缩甚至归零；成因 = 提案过拟合任务特有模式
2. **形态**：训练 split 的涨是真实、可复现的改进——不是测量噪声
3. **成因结构**：选择压力只来自 verifier 所测的分布；任务特有模式与通用改进在选择眼里无差别，被逐轮积累放大
4. **与噪声累积的界线**：噪声 = 分数是假的；OOD 缩水 = 分数是真的、测错了分布
5. **与两失败模式的界线**：正确性 gate 与性能信号双绿灯，仍可能 OOD 缩水
6. **防御**（能述其一）：进化-保留拆分 / 正则化 / 独立验证集
