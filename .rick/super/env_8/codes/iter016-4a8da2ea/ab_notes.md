# ab_notes.md — 迭代 16 A/B 归因（导入期 BLAS 预热 vs 父本 iter015 无预热）

- 候选：`solution.py` = iter015 零开销预绑定通道（逐字不变）**+ 导入期 BLAS 状态预热块**
  （`RandomState(7)` 独立实例 → 两个 2048×2048 f32 dummy 阵 → 4 次整阵 `np.matmul` → `del`）。
  单变量：核心计算路径（seterr → `_matmul = np.matmul` 预绑定 → 单表达式 wrapper →
  自检块）与父本 codes/iter015-614d495c/solution.py 逐字一致（diff 已核对：
  仅 docstring 与预热块差异）。
- 对照：`probe_control.py` = 父本形态原样（无预热）；`probe_warm.py`/`probe_final.py` =
  builder 预演形态（3 次/4 次预热）。交付版取 4 次（probe_final 口径）。
- 假设：bench.py 先计时候选（K=3）后计时 ref——候选计时区是进程最早的 BLAS 调用，
  冷进程 ramp（call1 10.53ms / call2 8.37ms / call3 起稳态 ~6.65ms，builder 本迭代
  实测）可能让 k=3 中位数吞入爬坡尾部；ref 恒处稳态 → 候选单侧承受先计时顺序惩罚。
  预热把爬坡移到导入期（加载候选期间，非计时区）→ 候选与 ref 同处稳态。
- 环境：env_8 venv numpy 2.0.2，Apple M5 Max / Accelerate(vecLib)，@2048×2048 f32。
  ⚠️ **本窗口机器持续重载**：load avg 1m 5.1-5.7（两个 Wine 进程合计 ~270% CPU 背景跑），
  全部测量在此负载态下采集——均值整体抬到 ~6.9-7.3ms（vs 计划期稳态 6.65ms）。

1. **离散度收窄 ~2.3×**（σ 0.0237→0.0105），与计划预期（0.027→0.012）同向同量级
   ——score 离散度未收窄的证伪条件**不成立**。
2. **下尾惩罚消除**：control 打出 0.9547（首计时爬坡 7.756/7.707 漏进中位），
   warm 无 0.95 级下尾；warm 最低 0.9708 且其候选计时自身平稳。
3. warm 计时区唯一 ≥8ms 成员（run 3）位于末位计时（非早调用爬坡位）且同期对照更慢
   ——归因重载背景干扰而非 ramp 复现。
4. 均值 0.9956 vs 0.9894：无均值抬升（符合预期——本实验动的是测量稳定性，
   均值由机器漂移主导；本窗口整体重载，runtime 稳态 ~6.9-7.3ms 高于计划期 6.65ms）。

## 判定

- 假设「先计时顺序惩罚存在且可由导入期预热消除」在同窗口 A/B 下**成立**：
  对照可见爬坡尾形态 + 0.95 级下尾；候选平稳 + 离散度收窄 ~2.3×。
- 证伪条件复核：预热版计时区未见「早调用位」爬坡离群（唯一 ≥8ms 成员在末位、
  归因背景负载）；score 离散度显著收窄 → **假设未被证伪**。
- 本窗口重载（load 5.2-5.7）压制了绝对 runtime（6.8-7.3ms），未及 6.5-6.7ms 快窗带；
  runtime_ms 记录当次机器稳态，换精英判定留给框架终验在干净窗口的机会。
- 合法性自证：不缓存（每次全量重算、两遍逐位一致）、不触计时器（预热在导入期、
  非计时区）、不拖慢 ref（进程热态利好后计时 ref）、独立 RandomState(7) 不碰门禁
  seed（bench 先建 rng 后加载候选；correctness 每 seed 新建实例）、静态检查全净。
